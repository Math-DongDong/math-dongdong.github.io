# 아하수학 주제 페이지 제작 가이드

새로운 학습 주제를 만들 때 이 문서 하나만 보면 됩니다.
템플릿은 같은 폴더의 `_template.html` 이고, 완성 예시는 `representativevalue.html`(대푯값)입니다.

---

## 1. 폴더 구조

```
pages/
└── middleschool/
    ├── index.html                 ← 메인(주제 목록). 여기에 주제를 등록합니다
    └── ahamath/
        ├── _template.html         ← 복사해서 쓰는 템플릿 (수정하지 말고 원본 보관)
        ├── GUIDE.md               ← 이 문서
        ├── representativevalue.html   ← 완성 예시 (대푯값)
        ├── stemleaf.html          ← 앞으로 만들 파일들
        └── ...
```

파일 이름은 **영문 소문자**로 짓습니다. 한글 파일명은 서버·모바일에서 깨질 수 있습니다.

## 2. 새 주제 만들기 (3단계)

### ① 템플릿 복사

`_template.html` 을 복사해서 `ahamath/` 안에 새 이름으로 저장합니다.
예: `stemleaf.html`

### ② 내용 채우기

새 파일을 열어 `★` 표시가 붙은 자리만 고칩니다. (총 12곳, 아래 4번 참고)

### ③ 메인에 등록

`pages/middleschool/index.html` 의 `TOPICS` 배열에 항목을 하나 추가합니다.

```js
{
    id: 'stemleaf',                                  // 학습 페이지의 TOPIC_ID 와 반드시 같게
    unit: '중1. 자료의 정리와 해석',                   // 띄어쓰기·마침표까지 기존 것과 똑같이
    no: 2,                                           // 카드 왼쪽 번호
    title: '줄기와 잎 그림',
    desc: '흩어진 자료를 줄기와 잎으로 깔끔하게 정리해요.',
    goals: ['줄기와 잎', '자료 정리하기'],             // 회색 칩. 2~4개가 보기 좋습니다
    href: './ahamath/stemleaf.html',                 // 방금 만든 파일 경로
    status: 'ready'                                  // 완성 전이면 'soon'
}
```

`unit` 이 한 글자라도 다르면 **단원이 따로 분리되어** 표시됩니다. 복사해서 붙여넣으세요.

## 3. 화면 구성

한 주제는 네 개의 화면으로 이루어집니다. 학생은 버튼 하나로만 이동합니다.

```
[화면1] 개념 카드 → 예제 카드 → "여기까지 어땠나요?"
            │
            ├─ 아하! 이해했어요  ──→ [화면3] 기초 미션 (한 화면에 한 문제) ─→ [화면4] 결과
            ├─ 아직은.... 다시 볼래요  (정리 카드로 안내)
            └─ 도전! 한 걸음 더  ──→ [화면2] 심화 개념 → "여기까지 어땠나요?"
                                              └─ 아하! ─→ [화면3] 도전 미션 ─→ [화면4] 결과
```

- 결과 화면에서 기초를 끝냈으면 **[도전! 한 걸음 더]**, 도전만 끝냈으면 **[기초 미션도 남아 있어요]** 버튼이 뜹니다.
- 미션 화면에는 [이전] [다음 문제]만 있습니다. 개념으로 돌아가는 길은 **상단 ← 개념으로** 입니다.

## 4. ★ 수정 위치 체크리스트

| ★ | 위치 | 무엇을 |
|---|------|--------|
| 1 | `<title>` | `주제 이름 \| 아하수학` |
| 2 | 표지(hero-box) | 단원명·주제명·한 줄 소개 |
| 3 | 1단계 stage-sub | 이 단계에서 만나는 것 한 줄 |
| 4 | 개념 카드 `block-c1 …` | 개념 카드들 (필요한 만큼 복사) |
| 5 | 정리 카드 | 표로 용어 정리 |
| 6 | 예제 카드 `block-e1` | 예제 1~2개, ①②③ 풀이 |
| 7 | 게이트 안의 `href="#block-c6"` | 정리 카드 id 로 맞추기 |
| 8 | 심화 표지 | 심화 코스 소개 |
| 9 | 심화 개념 `block-a1 …` | 심화 개념 1~3개 |
| 10 | 심화 예제 `block-a2` | 심화 예제 |
| 11 | `TOPIC_ID` | 메인의 `id` 와 똑같이 |
| 12 | `QUESTIONS` | 문항 (기초 5 + 도전 2~3) |

**심화 코스가 없는 주제**라면 이렇게 하세요.
1. `<section class="view" id="view-cread">` 전체 삭제
2. 게이트의 `gateJump` 버튼 삭제 (안 지워도 자동으로 숨겨집니다)
3. `QUESTIONS` 에서 `x1, x2 …` 삭제

카드 개수는 자유입니다. `id="block-c7"`, `block-c8` … 처럼 번호만 이어 주면 됩니다.
문항 개수도 자유입니다. 진행 표시(`문제 3 / 5`)와 진행률은 자동으로 계산됩니다.

## 5. 시각 자료 사용법

스크롤을 내려 **화면 절반선을 넘어서면 저절로 재생**됩니다. 학생이 누를 것은 없습니다.
카드 안에 아래 한 줄만 넣으면 됩니다. `data-values` 의 숫자만 바꾸면 그림이 바뀝니다.

### ① 숫자 카드 보여주기 — `cards`
움직임 없이 자료를 카드로 보여줍니다.
```html
<div class="num-cards" data-vis="cards" data-values="2,5,6,4,3"></div>
```

### ② 막대가 평평해지기 — `level`
막대가 올라온 뒤 **모두 같은 높이(평균)** 로 맞춰지고 점선이 그려집니다.
```html
<div class="bar-chart" data-vis="level" data-values="2,5,6,4,3"></div>
<div class="bar-names"><span>가</span><span>나</span><span>다</span><span>라</span><span>마</span></div>
<button class="replay"><i class="bi bi-arrow-repeat"></i> 다시 보기</button>
```
`bar-names` 의 `<span>` 개수는 막대 개수와 같아야 합니다.

### ③ 큰 값 하나가 끼어들기 — `outlier`
기본 막대가 올라오고 → 점선(평균)이 그려지고 → `data-extra` 막대가 나타나며 → 점선이 위로 이동합니다.
```html
<div class="bar-chart" data-vis="outlier" data-values="2,5,6,4,3" data-extra="22"></div>
```

### ④ 카드가 줄 서기 — `sort`
`data-values` 순서로 놓였다가 `data-sorted` 순서로 다시 정렬되고, `data-mid` 번째 카드가 강조됩니다.
```html
<div class="num-cards" data-vis="sort"
     data-values="3,9,1,7,5" data-sorted="1,3,5,7,9" data-mid="2"></div>
```
- `data-mid` 는 **0부터 세는 번호**입니다. 5장 중 가운데는 `2`.
- 두 장을 강조하려면 `data-mid="2,3"`.

### ⑤ 같은 값끼리 블록 쌓기 — `stack`
값별로 기둥이 쌓이고 **가장 높은 기둥**이 파랗게 강조됩니다.
```html
<div class="stack-wrap" data-vis="stack" data-values="6,3,6,9,6,5"></div>
```
강조를 끄려면(예: 최빈값이 없는 자료) `data-nomode="1"` 을 붙입니다.

### 그 밖의 재료
```html
<div class="data-line">2, 3, 3, 4, 8</div>          <!-- 자료를 크게 보여주는 회색 줄 -->
<div class="formula">(평균) = (합) ÷ (개수)</div>     <!-- 점선 테두리 공식 -->
<div class="fact-box">꼭 기억할 문장</div>            <!-- 파란 강조 상자 -->
<table class="table-simple">…</table>                <!-- 정리표 -->
```

예제의 `solve-item` 세 개는 스크롤에 맞춰 ① ② ③ 순서로 나타납니다. 순서만 지키면 됩니다.

## 6. 문항 작성 규칙

```js
q1: {
    group: 'basic',                    // 'basic' = 기초 미션, 'challenge' = 도전 미션
    badge: '미션 1',                    // 문제 화면 제목
    title: '미션 1 · 평균',             // 다시 볼 문제 목록에 뜨는 이름
    stem: '문제 상황<br>무엇을 구할까요?',
    data: '2, 4, 4, 5, 10',            // 회색 줄에 들어갈 자료
    choices: [
        { id: 'a', text: '4컵', hint: '중앙값을 고르셨어요. 평균은 …' },
        { id: 'b', text: '5컵', correct: true },
        { id: 'c', text: '25컵', hint: '합에서 멈추셨네요. 개수로 나누어야 …' }
    ],
    ok: '2+4+4+5+10 = 25, 25 ÷ 5 = 5컵이에요.'
}
```

지켜야 할 것

- **선택지는 정확히 3개.** 정답 1개 + 학생이 가장 자주 하는 실수 2개.
- 오답 보기는 아무 숫자나 넣지 말고 **실제로 나올 법한 오답**으로 만듭니다.
  (합에서 멈추기 / 정렬 안 하고 가운데 고르기 / 가장 큰 값 고르기 …)
- `hint` 는 "틀렸어요"가 아니라 **왜 그렇게 생각했는지 짚어 주고 방향을 알려 주는 문장**으로 씁니다.
- `correct: true` 는 딱 하나에만 붙입니다.
- 정답 위치는 문항마다 섞습니다. (a, b, c 골고루)
- 마지막 기초 문항은 계산이 아니라 **생활 속 상황 판단** 문제로 두면 좋습니다.

채점 규칙 (건드릴 필요 없음)

- 오답을 고르면 그 보기만 잠기고 **몇 번이든 다시 고를 수 있습니다.**
- **첫 시도에 맞힌 것만** "한 번에 맞힘"으로 기록됩니다.
- 한 번에 못 맞힌 문항은 [다시 볼 문제] 목록으로 내려갑니다.
- 미션 화면에 들어올 때마다 **1번 문제부터 새로** 시작합니다. 이전 성취 기록은 사라지지 않습니다.

## 7. 글쓰기 어조

대상은 수학을 어려워하는 학생입니다.

- 선생님이 옆에서 말해 주듯 **다정한 존댓말 구어체**: `~해요`, `~해 볼까요?`
- 한자식 용어는 풀어서: "중심 경향" → "가운데쯤 되는 값"
- 새 용어가 처음 나오면 굵게 표시하고 뜻을 한 줄로 붙입니다.
- 한 카드에는 **한 가지 생각만** 담습니다. 길어지면 카드를 나눕니다.
- 예제 숫자는 **10 이하의 정수**를 기본으로 합니다.
- "틀렸다", "쉽죠?" 같은 표현은 쓰지 않습니다.

## 8. 저장 구조

각 주제는 브라우저에 아래 키로 저장됩니다.

```
ahamath.{TOPIC_ID}.v1
```

```json
{
  "gate": "aha",            // 기초 자가진단: aha | notYet | null
  "challengeGate": null,    // 심화 자가진단
  "best": {                 // 문항별 최고 기록
    "q1": "firstTry",       //   firstTry = 한 번에 맞힘
    "q2": "solved",         //   solved   = 여러 번 만에 맞힘
    "q3": "missed"          //   missed   = 아직 못 맞힘
  },
  "summary": { }            // 메인 페이지가 읽어 가는 요약
}
```

메인 카드의 **아하! 표시는 기초 미션을 모두 `firstTry` 로 맞혔을 때만** 켜집니다.
여러 번 만에 맞힌 것도 인정하고 싶다면 학습 페이지의 이 함수만 고치면 됩니다.

```js
function isMastered(flow) { return firstTryCount(FLOW[flow].ids) === FLOW[flow].ids.length; }
```

## 9. 자주 하는 실수

- `TOPIC_ID`(학습 페이지)와 `id`(메인 TOPICS)가 다름 → 메인 카드에 진행률이 안 뜹니다.
- `unit` 문자열이 미묘하게 다름 → 같은 단원인데 두 덩어리로 쪼개집니다.
- `href` 경로 오타 → 메인에서 눌러도 열리지 않습니다.
- 게이트의 `href="#block-c6"` 를 안 고침 → "정리 카드 다시 보기"가 엉뚱한 곳으로 갑니다.
- `bar-names` 의 `<span>` 개수와 막대 개수가 다름 → 이름이 밀려서 표시됩니다.
- `data-mid` 를 1부터 셈 → 강조가 한 칸 밀립니다. **0부터** 셉니다.
- 선택지에 `correct: true` 가 없거나 두 개임 → 다음 문제로 넘어가지 못합니다.

## 10. 완성 후 점검

- [ ] 스크롤만 내려서 끝까지 읽히는가 (중간에 눌러야 하는 것이 없는가)
- [ ] 시각 자료가 화면 절반쯤에서 재생되는가
- [ ] 게이트 세 버튼이 각각 제 위치로 가는가
- [ ] 미션 5문항을 한 번에 다 맞히면 결과에 초록 문구가 뜨고, 메인 카드가 아하!로 바뀌는가
- [ ] 일부러 틀렸을 때 [다시 볼 문제]에 그 문항이 나타나고, 눌렀을 때 그 문제들만 나오는가
- [ ] 도전까지 끝낸 뒤 기초가 남아 있으면 [기초 미션도 남아 있어요]가 뜨는가
- [ ] 휴대폰 세로 화면에서 글자가 잘리지 않는가

## 11. AI에게 초안을 맡길 때 쓰는 프롬프트

아래를 복사해 붙여넣고 대괄호만 채우면 됩니다.

```
첨부한 _template.html 과 GUIDE.md 를 그대로 따라서
[주제 이름] 학습 페이지를 만들어 주세요.

- 파일명: ahamath/[영문파일명].html
- TOPIC_ID: [영문id]
- 성취기준: [교육과정 성취기준 문장]
- 학습 순서: 첨부한 활동지의 질문 흐름을 100% 우선으로 따르고,
  교과서는 보조 자료로만 참고하세요.

지켜 주세요.
1. _template.html 의 ★ 표시 자리만 채우고 나머지 코드는 건드리지 말 것
2. 개념 카드는 한 카드에 한 생각만, 4~7장
3. 시각 자료는 GUIDE.md 5번의 다섯 종류 안에서만 고를 것
4. 예제는 1~2개, 숫자는 10 이하 정수, ①조건 확인 ②식 세우기 ③계산 구조
5. 기초 문항 5개 + 도전 문항 2~3개, 선택지는 정확히 3개
   (정답 1 + 자주 하는 실수 2), 오답마다 원인을 짚는 hint 필수
6. 어조는 다정한 존댓말 구어체, 한자식 용어는 쉬운 말로 풀어 쓸 것
7. 작업 전에 [구현 계획]을 짧은 불릿으로 먼저 제시할 것

마지막에, 교과서에는 있는데 활동지에 빠진 개념이 있으면
"선생님, 교과서에는 [개념명]이 있으나 활동지에는 빠져 있습니다.
추가할까요?" 형식으로 질문해 주세요.
```
