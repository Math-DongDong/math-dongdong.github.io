# 아하! 수학 주제 페이지 제작 가이드

새 학습 주제를 만들 때 이 문서 하나만 보면 됩니다.

- 템플릿 : `assets/template/ahamath/_template.html`
- 완성 예시 : `pages/middleschool/ahamath/1/` 안의 6개 학습 페이지

---

## 1. 폴더 구조

```
assets/
└── template/
     └── ahamath/
          ├── _template.html            ← 복사해서 쓰는 템플릿 (원본은 수정하지 말기)
          └── GUIDE.md                  ← 이 문서

pages/
└── middleschool/
     ├── index.html                    ← 메인(주제 목록). 여기에 주제를 등록합니다
     └── ahamath/
          └── 1/
               ├── coordinate.html       ← 순서쌍과 좌표
               ├── graph.html            ← 그래프
               ├── proportion.html       ← 정비례와 반비례
               ├── representativevalue.html ← 대푯값
               ├── frequency.html        ← 도수분포표와 히스토그램
               ├── relative.html         ← 상대도수와 그 그래프
               └── ...                   ← 앞으로 만들 파일들
```

파일 이름은 **영문 소문자**로 짓습니다. 한글 파일명은 서버·모바일에서 깨질 수 있습니다.

### 현재 등록된 주제

| id | 파일 | 주제 | 기초 / 도전 문항 |
|---|---|---|---|
| `coordinate` | `1/coordinate.html` | 순서쌍과 좌표 | 4 / 3 |
| `graph` | `1/graph.html` | 그래프 | 4 / 3 |
| `proportion` | `1/proportion.html` | 정비례와 반비례 | 4 / 3 |
| `daepyogap` | `1/representativevalue.html` | 대푯값 | 5 / 3 |
| `frequency` | `1/frequency.html` | 도수분포표와 히스토그램 | 4 / 2 |
| `relative` | `1/relative.html` | 상대도수와 그 그래프 | 4 / 2 |

> 줄기와 잎 그림은 따로 만들지 않고 `frequency.html` 의 도입부(개념 카드 1~4)에서 다룹니다.

## 2. 새 주제 만들기 (3단계)

### ① 템플릿 복사

`assets/template/ahamath/_template.html` 을 복사해 `pages/middleschool/ahamath/1/` 안에 새 이름으로 저장합니다. 예: `linear-equation.html`

### ② 내용 채우기

`★` 표시가 붙은 12곳만 고칩니다. (4번 표 참고)

### ③ 메인에 등록

`pages/middleschool/index.html` 의 `TOPICS` 배열에 항목을 추가합니다.

```js
{
    id: 'topicid',                       // 학습 페이지의 TOPIC_ID 와 반드시 같게
    unit: '중1. 자료의 정리와 해석',       // 띄어쓰기·마침표까지 기존 것과 똑같이
    no: 5,                               // 카드 왼쪽 번호
    title: '주제 이름',
    desc: '한 줄 소개',
    goals: ['핵심어1', '핵심어2'],        // 회색 칩. 2~4개
     href: './ahamath/1/topicid.html',
    status: 'ready',                     // 완성 전이면 'soon'
    basicTotal: 4,                       // 기초 미션 문항 수
    challengeTotal: 2                    // 도전 미션 문항 수 (없으면 0 → 칩이 사라짐)
}
```

`basicTotal`·`challengeTotal` 은 **아직 한 번도 들어가 보지 않은 학생**에게 `0 / 4` 처럼 보여 주기 위한 값입니다.
학생이 학습 페이지를 한 번이라도 열면 실제 문항 수로 자동으로 맞춰지니, 나중에 문항을 늘려도 카드가 깨지지 않습니다.

`unit` 문자열이 한 글자라도 다르면 **단원이 따로 분리되어** 표시됩니다. 복사해서 붙여넣으세요.

학습을 시작하지 않은 주제 카드는 제목과 설명만 표시합니다. `아직 시작하지 않았어요` 문구,
진행률 바, 기초·도전 미션 개수는 표시하지 않습니다. 학습 기록이 생긴 뒤에만 상태와 진행률이 나타납니다.

## 3. 화면 구조

```
[화면1] 개념 카드 → 예제 카드 → "여기까지 어땠나요?"
            │
            ├─ 아하! 이해했어요  ──→ [화면3] 기초 미션 (한 화면에 한 문제) ─→ [화면4] 결과
            ├─ 아직은.... 다시 볼래요  (정리 카드로 안내)
            └─ 도전! 한 걸음 더  ──→ [화면2] 심화 개념 → "여기까지 어땠나요?"
                                              └─ 아하! ─→ [화면3] 도전 미션 ─→ [화면4] 결과
```

- 결과 화면에서 기초를 끝냈으면 **[도전! 한 걸음 더]**, 도전만 끝냈으면 **[기초 미션도 남아 있어요]** 버튼이 뜹니다.
- 미션 화면에는 [이전] [다음 문제]만 있습니다. 개념으로 돌아가는 길은 **상단 ← 개념으로** 입니다.
- 상단 진행률바는 읽기 화면에서는 스크롤 위치, 미션 화면에서는 문항 진행을 보여 줍니다.
- 개념과 예제 화면에는 중간 안내 문구나 조작 단계가 없으며, 마지막 게이트에서만 다음 과정을 선택합니다.

## 4. ★ 수정 위치 체크리스트

| ★ | 위치 | 무엇을 |
|---|------|--------|
| 1 | `<title>` | `주제 이름 \| 아하! 수학` |
| 2 | 표지(hero-box) | 단원명·주제명·한 줄 소개 |
| 3 | 1단계 stage-sub | 이 단계에서 만나는 것 한 줄 |
| 4 | 개념 카드 `block-c1 …` | 개념 카드들 (필요한 만큼 복사) |
| 5 | 정리 카드 | 표로 용어 정리 |
| 6 | 예제 카드 `block-e1` | 예제 1~2개, ①②③ 풀이 |
| 7 | 게이트 안의 `href="#block-c4"` | 정리 카드 id 로 맞추기 |
| 8 | 심화 표지 | 심화 코스 소개 |
| 9 | 심화 개념 `block-a1 …` | 심화 개념 1~3개 |
| 10 | 심화 예제 `block-a2` | 심화 예제 |
| 11 | `TOPIC_ID` | 메인의 `id` 와 똑같이 |
| 12 | `QUESTIONS` | 문항 (기초 `q1…` 4~5 + 도전 `x1…` 2~3, 보기는 각 2개) |

`TOPIC_ID` 바로 아래의 `RECORD_VERSION` 은 새로 만들 때는 `1` 그대로 두면 됩니다.
나중에 **문항을 옮기거나 지워서 ID 의 뜻이 바뀔 때만** 숫자를 올리세요.

**심화 코스가 없는 주제**라면
1. `<section class="view" id="view-cread">` 전체 삭제
2. `QUESTIONS` 에서 `x1, x2 …` 삭제 → 게이트의 [도전] 버튼이 **자동으로 숨습니다**

카드 개수·문항 개수는 자유입니다. 진행 표시(`문제 3 / 5`)와 진행률은 자동 계산됩니다.

## 5. 시각 자료 카탈로그 (10종)

모두 **화면 절반선을 넘어서면 저절로 재생**됩니다. 학생이 누를 것은 없습니다.
카드 안에 아래 코드를 붙여넣고 숫자만 바꾸면 됩니다.
`<button class="replay">` 를 같은 `.vis` 안에 두면 "다시 보기"가 생깁니다.
한 카드에 시각 자료가 여러 개면 다시 보기 하나로 **함께** 재생됩니다.

### ① `cards` — 숫자 카드 보여주기
움직임 없이 자료를 카드로 나열합니다. 도입에서 "이게 자료예요"라고 보여줄 때.
```html
<div class="num-cards" data-vis="cards" data-values="2,5,6,4,3"></div>
```

### ② `level` — 막대가 평평해지기 (평균)
막대가 올라온 뒤 모두 같은 높이로 맞춰지고 평균선이 그려집니다.
```html
<div class="bar-chart" data-vis="level" data-values="2,5,6,4,3"></div>
<div class="bar-names"><span>가</span><span>나</span><span>다</span><span>라</span><span>마</span></div>
<button class="replay"><i class="bi bi-arrow-repeat"></i> 다시 보기</button>
```
`bar-names` 의 `<span>` 개수는 막대 개수와 같아야 합니다.

### ③ `outlier` — 큰 값 하나가 끼어들기
기본 막대 → 평균선 → `data-extra` 막대 등장 → 평균선이 위로 이동합니다.
```html
<div class="bar-chart" data-vis="outlier" data-values="2,5,6,4,3" data-extra="22"></div>
```

### ④ `sort` — 카드가 줄 서고 가운데 강조 (중앙값)
```html
<div class="num-cards" data-vis="sort"
     data-values="3,9,1,7,5" data-sorted="1,3,5,7,9" data-mid="2"></div>
```
- `data-mid` 는 **0부터 세는 번호**입니다. 5장 중 가운데는 `2`
- 두 장 강조는 `data-mid="2,3"` (짝수 개 자료의 중앙값)

### ⑤ `stack` — 같은 값끼리 블록 쌓기 (최빈값)
값별 기둥이 쌓이고 가장 높은 기둥이 강조됩니다.
```html
<div class="stack-wrap" data-vis="stack" data-values="6,3,6,9,6,5"></div>
```
강조를 끄려면 `data-nomode="1"` (최빈값이 없는 자료를 보여줄 때)

### ⑥ `stemleaf` — 줄기와 잎 그림
잎이 왼쪽부터 하나씩 채워집니다.
```html
<!-- 십의 자리를 줄기로 자동 분리 -->
<div class="stemleaf" data-vis="stemleaf"
     data-values="61,80,58,56,47,57,53,60,71,53,75,56"
     data-note="4|7은 47 kg"></div>

<!-- 줄기를 직접 지정 (시:분처럼 자릿수가 다를 때) -->
<div class="stemleaf" data-vis="stemleaf"
     data-rows="6=35,55;7=15,30,45;8=05,20,30,45"
     data-note="6|35는 6시 35분"></div>
```

### ⑦ `histogram` — 히스토그램 · 도수분포다각형
직사각형이 차례로 올라옵니다.
```html
<div class="histo" data-vis="histogram"
     data-counts="4,10,5,1" data-labels="0,5,10,15,20"
     data-ylabel="(명)" data-xlabel="(권)"></div>
```
- `data-labels` 는 계급의 **양 끝 값**이라 `data-counts` 보다 하나 많습니다
- `data-poly="1"` → 윗변 중점에 점을 찍고 선분으로 이어 **도수분포다각형**
- `data-missing="2"` → 2번째(0부터) 칸이 물음표 빗금 막대 = **찢어진 히스토그램**
- `data-counts` 에 소수를 넣으면 그대로 **상대도수 그래프**가 됩니다

### ⑧ `grid` — 전체 칸 중 일부 색칠 (비율)
"몇 개 중 몇 개"를 눈으로 보게 합니다. 나눗셈을 어려워하는 학생에게 특히 좋습니다.
```html
<div class="grid-vis" data-vis="grid"
     data-total="20" data-part="8"
     data-caption="1반 20명 중 8명" data-ratio="8 ÷ 20 = 0.4"></div>
<div class="grid-vis" data-vis="grid" data-tone="warm"
     data-total="30" data-part="9"
     data-caption="2반 30명 중 9명" data-ratio="9 ÷ 30 = 0.3"></div>
```
`data-tone="warm"` 은 두 번째 자료를 주황색으로 구분할 때 씁니다.

### ⑨ `segbar` — 합이 1인 띠 (상대도수의 합)
띠 하나가 전체(=1)임을 보여 줍니다.
```html
<div class="segbar-vis" data-vis="segbar"
     data-parts="0.1,0.15,0.4,0.25,0.1"
     data-labels="0~3,3~6,6~9,9~12,12~15"></div>
```
`data-parts` 의 합은 1이어야 합니다. 맨 아래 문구는 `data-totaltext` 로 바꿀 수 있습니다.

### ⑩ `dualpoly` — 두 자료 겹쳐 비교
두 집단의 그래프를 파란 선·주황 선으로 겹쳐 그립니다.
```html
<div class="dual" data-vis="dualpoly"
     data-a="0.1,0.15,0.4,0.25,0.1" data-b="0.1,0.2,0.3,0.3,0.1"
     data-labels="0,3,6,9,12,15" data-names="1반,2반"
     data-ylabel="(상대도수)" data-xlabel="(천 원)"></div>
```

### 그 밖의 재료
```html
<div class="data-line">2, 3, 3, 4, 8</div>            <!-- 자료를 크게 보여주는 회색 줄 -->
<div class="formula">(평균) = (합) ÷ (개수)</div>       <!-- 점선 테두리 공식 -->
<div class="fact-box">꼭 기억할 문장</div>              <!-- 파란 강조 상자 -->
<table class="table-simple center">…</table>           <!-- 정리표 (center = 가운데 정렬) -->
<td class="hl">8</td>                                  <!-- 표 안에서 주황색 강조 -->
```

문항 안에서도 표를 쓸 수 있습니다. `data` 는 HTML이 들어갑니다.
```js
data: '<table class="mini"><tr><th>계급</th><th>도수</th></tr><tr><td>0 ~ 5</td><td>4</td></tr></table>'
data: '<span class="mini-stem">① 보기<br>② 보기<br>③ 보기</span>'
```

## 6. 자료(숫자) 만들 때 규칙 ★중요

### 도입 자료는 "새 개념이 없으면 답이 틀리는" 자료로

가장 흔한 실패는 **새 개념을 써도 결론이 그대로인 자료**를 쓰는 것입니다.
학생은 "굳이 왜 이렇게 해?"라고 느끼고 개념의 필요성을 못 느낍니다.

| | 나쁜 예 | 좋은 예 |
|---|---|---|
| 상대도수 | 1반 3명(0.1) vs 2반 4명(0.2)<br>→ 도수도 2반, 비율도 2반 **결론 같음** | 1반 8명 / 20명 = **0.4**<br>2반 9명 / 30명 = **0.3**<br>→ 사람은 2반이 많은데 비율은 1반 **역전** |
| 중앙값 | 평균 5, 중앙값 5 → 차이 없음 | 2, 3, 3, 4, 8 → 평균 4, 중앙값 3 |
| 도수분포표 | 자료 5개 → 줄기와 잎으로 충분 | 자료 20개 이상 → 잎이 길어져 불편함이 보임 |

도입 카드를 쓰기 전에 스스로 물어보세요. **"이 자료면 새 개념 없이도 답이 같지 않나?"**

### 계산이 딱 떨어지게

- 나눗셈이 필요하면 총합을 **20, 25, 30, 50, 100, 200** 중에서 고르세요
- 예제 숫자는 **10 이하 정수**를 기본으로, 계급이 필요하면 **5 또는 10 단위**
- 소수는 되도록 소수 첫째 자리까지만

### 검산이 되게

- 도수의 합 = 자료의 개수
- 상대도수의 합 = 1
- 표에 쓴 도수와 그래프의 `data-counts` 가 같은지 꼭 대조하세요

### 자료를 재활용하되 충돌은 피하기

개념 → 예제 → 심화까지 **같은 맥락**을 이어 쓰면 학생이 덜 헷갈립니다.
다만 미션 문항이 개념 카드와 같은 상황인데 **숫자만 다르면** 오히려 혼란스러우니,
문항은 다른 소재(안경 쓴 학생 수, 신발 치수 등)로 바꾸세요.

## 7. 문항 작성 규칙

```js
q1: {
    group: 'basic',                    // 'basic' = 기초 미션, 'challenge' = 도전 미션
    badge: '미션 1',                    // 문제 화면 제목
    title: '미션 1<br>평균',            // 다시 볼 문제 목록에 뜨는 이름 (줄바꿈으로 두 줄)
    stem: '문제 상황<br>무엇을 구할까요?',
    data: '도수의 총합 20명<br>그 계급의 도수 5명',   // 회색 줄 (HTML 사용 가능)
    choices: [
        { id: 'a', text: '4컵', hint: '가운데 값을 고르셨어요. 평균은 모두 더한 다음 개수로 나눠요.' },
        { id: 'b', text: '5컵', correct: true }
    ],
    ok: '2+4+4+5+10 = 25, 25 ÷ 5 = 5컵이에요.'
}
```

### 문항 ID 규칙 ★중요

**기초 문항은 `q1, q2 …`, 도전 문항은 `x1, x2 …`** 로 짓습니다.
메인 페이지가 요약값을 못 읽을 때 이 접두사로 개수를 세기 때문에, 기초 문항에 `x`를 쓰면 개수가 도전 쪽으로 잡힙니다.
문항을 옮기거나 지워서 **번호가 밀리면 ID 도 다시 매기고**, 학습 페이지 위쪽의 `RECORD_VERSION` 숫자를 1 올리세요.
그래야 예전 기록이 엉뚱한 문항에 붙지 않습니다. (그 주제의 문항별 기록은 한 번 초기화됩니다)

### 선택지는 2개

- **정답 1개 + 학생이 실제로 하는 실수 1개.** 셋을 넣으면 힘이 약한 오답이 섞여 오히려 찍기 쉬워집니다
- 아무 숫자나 넣지 말고, **왜 그렇게 틀리는지 설명할 수 있는 오답**만 씁니다
  (합에서 멈추기 / 거꾸로 나누기 / 정렬 안 하고 가운데 고르기 / 0.15를 15로 읽기 / 가장 큰 값을 최빈값으로)
- 오답이 두 개 이상 떠오르면 **가장 흔하고 가장 많이 가르칠 것이 있는 하나**를 고릅니다
- **두 보기의 형식을 맞추세요.** "5권 이상 10권 미만" vs "9명"처럼 생김새가 다르면
  문제를 안 읽어도 형식만 보고 답을 고를 수 있습니다. 둘 다 구간, 둘 다 사람 수로
- `hint` 는 "틀렸어요"가 아니라 **어떤 생각을 했는지 짚고 방향을 알려 주는 문장**
- `correct: true` 는 하나에만. **정답 위치는 문항마다 첫째·둘째를 번갈아** 놓습니다
- 마지막 기초 문항은 계산이 아니라 **생활 속 판단** 문제로 두면 좋습니다

### 조건 상자(`data`)는 줄바꿈으로

가운데 점이나 전각 공백으로 붙이면 휴대폰에서 줄이 어색하게 끊깁니다. `<br>` 로 한 줄에 하나씩 적으세요.

```js
data: '도수의 총합 200명<br>상대도수 0.15'          // 좋음
data: '도수의 총합 200명　·　상대도수 0.15'          // 피하기
```

### 채점 규칙 (코드는 고칠 필요 없음)

- 오답을 고르면 그 보기만 잠기고 **몇 번이든 다시** 고를 수 있습니다
- **첫 시도에 맞힌 것만** "한 번에 맞힘(`firstTry`)"으로 기록됩니다. 두 번째에 맞힌 것은 개수에 들어가지 않습니다
- 한 번에 못 맞힌 문항은 [다시 볼 문제] 목록으로 갑니다
- 미션에 들어올 때마다 **1번 문제부터 새로** 시작하고, 시도 기록도 초기화됩니다.
  그래서 [다시 볼 문제]나 [아하! 이해했어요 → 기초 미션 풀기]로 다시 들어가
  **첫 클릭에 맞히면 그때 개수가 하나 올라갑니다**. 한 번 오른 기록은 나중에 틀려도 내려가지 않습니다
- [다시 볼 문제]로 들어오면 **그 문항들만** 모아서 풉니다

### 결과 화면 문구

정답을 골라야 다음 문제로 넘어가는 구조라 **모든 학생이 결과 화면에 도착**합니다.
그래서 문구는 성적과 무관한 칭찬 대신 `doneLeadText()` 가 네 갈래로 나눠 줍니다. (코드 수정 불필요)

| 이번에 한 번에 맞힌 수 | 문구 |
|---|---|
| 전부 | 한 문제도 헤매지 않았어요. 정말 잘했어요. |
| 절반 이상 | 끝까지 풀었어요. 아래 다시 볼 문제만 한 번 더 풀어 볼까요? |
| 일부 | 끝까지 포기하지 않았어요. 헷갈린 문제는 아래에 담아 두었어요. |
| 0개 | 끝까지 풀어냈어요. 아직 한 번에 맞힌 문제가 없으니 개념을 한 번 더 보고 올까요? |

## 8. 글쓰기 어조

대상은 수학을 어려워하는 학생입니다.

- 선생님이 옆에서 말해 주듯 **다정한 존댓말 구어체**: `~해요`, `~해 볼까요?`
- 한자식 용어는 풀어서: "중심 경향" → "가운데쯤 되는 값"
- 새 용어가 처음 나오면 굵게 표시하고 뜻을 한 줄로 붙이기
- 한 카드에 **한 가지 생각만**. 길어지면 카드를 나눕니다
- 카드 마지막 줄은 다음 카드로 이어 주는 한 문장으로
- "틀렸다", "쉽죠?", "당연히" 같은 표현은 쓰지 않습니다

## 9. 저장 구조

주제마다 브라우저에 이 키로 저장됩니다.

```
ahamath.{TOPIC_ID}.v1
```

```json
{
  "version": 1,             // RECORD_VERSION. 숫자가 다르면 best 를 비우고 다시 시작합니다
  "gate": "aha",            // 기초 자가진단: aha | notYet | null
  "challengeGate": null,    // 심화 자가진단
  "best": {                 // 문항별 최고 기록 (내려가지 않음)
    "q1": "firstTry",       //   firstTry = 한 번에 맞힘  ← 개수로 인정되는 것은 이것뿐
    "q2": "solved",         //   solved   = 여러 번 만에 맞힘
    "q3": "missed"          //   missed   = 아직 못 맞힘
  },
  "summary": {              // 메인 페이지가 읽어 가는 요약
    "basicFirstTry": 1, "basicTotal": 4,
    "challengeFirstTry": 0, "challengeTotal": 2,
    "mastered": false, "percent": 40
  }
}
```

### 개수를 세는 규칙

**`firstTry` 만 셉니다.** 메인 카드의 `기초 미션 2 / 4` 도, 결과 화면의 `기록에 쌓인 문항` 도 같은 기준입니다.
두 번째 시도에 맞힌 문항은 세지 않고, 다시 풀어 한 번에 맞히는 순간 올라갑니다.
메인 카드의 **아하! 표시(초록)는 기초 미션을 모두 `firstTry` 로 맞혔을 때** 켜지고, 진행률도 같은 기준입니다.

여러 번 만에 맞힌 것도 인정하려면 **두 곳을 함께** 고쳐야 합니다.
한쪽만 고치면 학습 페이지와 메인 카드의 숫자가 어긋납니다.

```js
// 학습 페이지
function firstTryCount(ids) { return ids.filter(function (id) { return bestOf(id) === 'firstTry'; }).length; }

// index.html
function countFirstTry(best, prefix) { … best[id] === 'firstTry' … }
```

### 페이지를 열 때 하는 정리 (`syncRecord`)

학습 페이지를 열면 **없어진 문항의 기록을 지우고 요약을 다시 계산**해 저장합니다.
문항을 늘리거나 줄여도 메인 카드의 `/ 4` 같은 숫자가 자동으로 맞춰집니다.
아직 기록이 없는 학생에게는 빈 기록을 만들지 않고, 마지막 학습 시각도 건드리지 않습니다.

## 10. 자주 하는 실수

- `TOPIC_ID`(학습 페이지)와 `id`(메인 TOPICS)가 다름 → 메인 카드에 진행률이 안 뜹니다
- 메인 TOPICS 의 `basicTotal`·`challengeTotal` 을 안 고침 → 처음 들어온 학생에게 `0 / 3` 처럼 엉뚱한 수가 보입니다
- 기초 문항 ID 를 `x`로 시작함 → 요약이 없을 때 도전 미션 개수로 잡힙니다. 기초는 `q`, 도전은 `x`
- 문항을 옮기고 `RECORD_VERSION` 을 안 올림 → 예전 기록이 다른 문항에 붙어 개수가 부풀려집니다
- `unit` 문자열이 미묘하게 다름 → 같은 단원이 두 덩어리로 쪼개집니다
- 게이트의 `href="#block-c4"` 를 안 고침 → "정리 카드 다시 보기"가 엉뚱한 곳으로
- `data-labels` 개수를 `data-counts` 와 같게 씀 → 계급의 양 끝 값이라 **하나 더** 많아야 합니다
- `bar-names` 의 `<span>` 개수와 막대 개수가 다름 → 이름이 밀립니다
- `data-mid` 를 1부터 셈 → 강조가 한 칸 밀립니다. **0부터** 셉니다
- `correct: true` 가 없거나 두 개 → 다음 문제로 넘어가지 못합니다
- 두 보기의 생김새가 다름(구간 vs 사람 수) → 문제를 안 읽어도 형식만 보고 맞힙니다
- 표의 숫자와 그래프의 `data-counts` 가 서로 다름 → 학생이 가장 먼저 발견합니다

## 11. 완성 후 점검

- [ ] 스크롤만 내려서 끝까지 읽히는가 (마지막 게이트 전에는 눌러야 하는 것이 없는가)
- [ ] 시각 자료가 화면 절반쯤에서 재생되는가
- [ ] 도입 자료가 **새 개념 없이는 답이 틀리는** 자료인가
- [ ] 게이트 세 버튼이 각각 제 위치로 가는가
- [ ] 문항마다 보기가 2개이고, 오답이 **설명할 수 있는 실수**인가
- [ ] 정답 위치가 첫째·둘째로 번갈아 놓였는가
- [ ] 기초 미션을 모두 한 번에 맞히면 결과에 초록 문구가 뜨고 메인 카드가 아하!로 바뀌는가
- [ ] 일부러 **두 번째에** 맞혔을 때 개수가 오르지 않고, [다시 볼 문제]에 남는가
- [ ] 그 문항을 다시 풀어 한 번에 맞히면 개수가 **하나 오르는가** (메인 카드까지)
- [ ] 일부러 다 헤맸을 때 결과 문구가 칭찬이 아니라 개념으로 안내하는가
- [ ] 도전까지 끝낸 뒤 기초가 남아 있으면 [기초 미션도 남아 있어요]가 뜨는가
- [ ] 표의 숫자와 그래프의 숫자가 일치하는가
- [ ] 휴대폰 세로 화면에서 글자와 그래프가 잘리지 않는가

## 12. AI에게 초안을 맡길 때 쓰는 프롬프트

아래를 복사해 붙여넣고 대괄호만 채우면 됩니다. 활동지와 교과서를 함께 첨부하세요.

```
첨부한 _template.html 과 GUIDE.md 를 그대로 따라서
[주제 이름] 학습 페이지를 만들어 주세요.

- 파일명: pages/middleschool/ahamath/1/[영문파일명].html
- TOPIC_ID: [영문id]
- 성취기준: [교육과정 성취기준 문장]
- 학습 순서: 첨부한 활동지의 질문 흐름을 100% 우선으로 따르고,
  교과서는 보조 자료로만 참고하세요.

지켜 주세요.
1. _template.html 의 ★ 표시 자리만 채우고 나머지 코드는 건드리지 말 것
2. 개념 카드는 한 카드에 한 생각만, 4~8장
3. 시각 자료는 GUIDE.md 5번의 10종 안에서만 고를 것
   (필요한 것이 없으면 새로 만들지 말고 먼저 물어볼 것)
4. 도입 자료는 GUIDE.md 6번을 지켜, 새 개념 없이는 결론이 달라지는
   자료로 만들 것. 계산은 딱 떨어지게, 합계는 검산되게
5. 예제는 1~2개, ①조건 확인 ②식 세우기 ③계산 구조
6. 기초 문항 4~5개(ID q1, q2 …) + 도전 문항 2~3개(ID x1, x2 …)
   선택지는 정확히 2개(정답 1 + 자주 하는 실수 1), 오답에는 원인을 짚는 hint 필수
   두 보기의 생김새를 맞추고, 정답 위치는 첫째·둘째를 번갈아 놓을 것
7. 문항의 title 과 조건 상자(data)는 가운데 점 대신 <br> 로 줄을 나눌 것
8. 어조는 다정한 존댓말 구어체, 한자식 용어는 쉬운 말로 풀어 쓸 것
9. 마지막에 index.html 의 TOPICS 에 넣을 항목을
   basicTotal / challengeTotal 까지 채워서 함께 제시할 것
10. 작업 전에 [구현 계획]을 짧은 불릿으로 먼저 제시할 것

마지막에, 교과서에는 있는데 활동지에 빠진 개념이 있으면
"선생님, 교과서에는 [개념명]이 있으나 활동지에는 빠져 있습니다.
추가할까요?" 형식으로 질문해 주세요.
```

새 페이지를 만든 뒤에는 `index.html`의 `href`가 `./ahamath/1/[파일명].html`인지,
학습 페이지의 목록 복귀 경로가 `../../index.html`인지 확인하세요.
