# 동동쌤's 웹 앱 🧮

> **동동쌤**이 직접 만든 교육용 웹 애플리케이션 모음입니다.  
> 학생들이 수학을 더 재미있고 쉽게 배울 수 있도록 다양한 인터랙티브 콘텐츠를 제공합니다.

---

## 📌 서비스 소개

| 카테고리 | 설명 |
|---|---|
| 🏫 **중학 수학** | 중학교 수학 개념을 게임 형식으로 재미있게 학습 |
| 🤖 **인공지능 수학** | AI·데이터 관련 수학 개념을 시각적으로 탐구 |
| 🏭 **산업 수학** | 실생활·산업 현장에 적용되는 수학 원리 학습 (Streamlit 앱) |
| ⚙️ **업무 자동화** | 실용적인 업무 자동화 도구 |
| 🤖 **동동봇** | 다양한 질문에 답변해 주는 AI 챗봇 (Streamlit 앱) |

---

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript
- **UI Framework**: Bootstrap 5
- **Font**: Pretendard
- **외부 서비스**: Streamlit (산업 수학, 동동봇)
