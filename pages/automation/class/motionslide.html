모션 슬라이드

PPT처럼 슬라이드를 직접 고치고, 오른쪽 AI 창에 주제를 적으면 Gemini가 모션이 들어간 슬라이드를 만들어 줍니다.

슬라이드는 AI(Gemini)가 만들어 줍니다. AI 생성을 이용하려면 먼저 [AI 설정]에서 API 키를 등록해 주세요.
학생은 [함께 보기]를 눌러 선생님 화면의 코드를 입력하세요.

최근 편집

아직 편집한 슬라이드가 없습니다. [새 프레젠테이션]으로 시작하거나 내보낸 HTML 파일을 불러오세요.

작업 내용은 고칠 때마다 이 브라우저(IndexedDB)에 자동 저장됩니다. 중요한 자료는 HTML로 내보내 두세요.

  • HTML (발표용)
  • PDF (A4 세로, 한 쪽에 2장)
  • 처음부터
  • 현재 쪽부터

AI가 고치는 중

어떻게 바꿀지 적으면 Gemini가 이 요소의 코드를 고칩니다. 결과는 슬라이드에 바로 보입니다. 조작해 보려면 Ctrl+E로 이 장부터 발표한 뒤 Esc로 돌아오세요.

요청 내용·참고 자료·코드는 Google Gemini API로 전송됩니다. 고친 결과는 바로 반영되고, 마음에 들지 않으면 [반영 취소]나 Ctrl+Z로 되돌립니다.

코드는 이 페이지와 분리된 격리 칸에서 실행됩니다(허용된 CDN의 라이브러리·글꼴만 불러올 수 있음). 슬라이드에 들어간 모습이 미리보기입니다. 되돌리려면 코드 칸 밖에서 Ctrl+Z를 누르세요.

아래 시나리오 칸에서 직접 고쳐도 되고, 여기에 어떻게 바꿀지 적으면 Gemini가 이 장의 화면 내용에 맞춰 다시 씁니다. 고친 결과는 시나리오 칸에 바로 들어갑니다.

요청 내용·참고 자료·이 장의 내용은 Google Gemini API로 전송됩니다. 다 썼으면 왼쪽 위 [←]로 AI 창으로 돌아갑니다.
