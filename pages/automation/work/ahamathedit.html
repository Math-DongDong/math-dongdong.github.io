HTML 화면 편집기

HTML을 불러와 PPT처럼 글자를 고치고, 요소를 끌어서 옮기거나 크기를 바꿀 수 있습니다.
모든 처리는 브라우저 안에서만 실행됩니다.

HTML 파일을 끌어다 놓거나 클릭해서 선택하세요

.html, .htm 파일 지원

상대 경로 이미지·CSS가 깨질 때 원본 주소를 입력하세요. 저장 파일에는 포함되지 않습니다.
끄면 스크립트를 잠시 멈추고 편집하며, 저장할 때 원래대로 되돌립니다.

사용 방법

  • 클릭하면 선택되고, 끌면 이동합니다. 테두리의 핸들로 크기를 조절합니다. (Shift: 비율 유지)
  • 더블클릭 또는 Enter로 글자를 고칩니다. 글자 일부를 드래그한 뒤 서식을 바꾸면 그 부분에만 적용됩니다.
  • 방향키로 1px(Shift: 10px)씩 이동하고, Delete로 삭제, Ctrl+Z/Y로 되돌리기, Ctrl+D로 복제합니다.
편집할 요소를 클릭하세요.
