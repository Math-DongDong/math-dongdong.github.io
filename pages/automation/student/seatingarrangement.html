학생 자리배치 앱

구글 스프레드시트와 연동하여 교실 자리배치를 원클릭으로 손쉽게 생성, 관리, 인쇄하세요.

버튼 한 번으로 랜덤 자리배치

빈자리와 고정석을 반영해 학생들을 무작위로 배치하고, 매번 새로운 자리 구성을 빠르게 만들 수 있습니다.

원하는 학생의 자리 고정

학생을 선택한 뒤 원하는 좌석을 지정하면 랜덤 배치나 번호순 배치에서도 해당 자리를 유지할 수 있습니다.

교실에 맞는 빈자리 설정

사용하지 않는 책상을 클릭해 빈자리로 바꾸고, 통로나 교실 구조에 맞춰 배치 공간을 조정할 수 있습니다.

번호순으로 한 번에 배치

학생 명단의 번호 순서대로 자리를 자동 정렬해 학기 초 자리 배치나 시험 대형을 빠르게 준비합니다.

자석처럼 간편한 학생 이동

학생을 드래그해 원하는 자리로 옮기고, 자석처럼 가까운 학생과 함께 이동하는 방식도 선택할 수 있습니다.

교사 시점과 학생 시점 전환

교탁에서 바라보는 교사 시점과 학생이 바라보는 학생 시점을 전환해 실제 교실 방향에 맞게 자리배치를 확인합니다.

자리배치 저장 및 이력 불러오기

완성한 자리배치를 저장하고, 배치 이력에서 이전 결과를 다시 불러와 필요할 때 재사용할 수 있습니다.

자리배치 결과 바로 인쇄

완성된 자리배치를 깔끔한 인쇄 화면으로 확인하고 교탁 부착용이나 학생 안내용 자료로 출력할 수 있습니다.

자리배치 앱 복사 및 배포 가이드

구글 시트 템플릿 복사하기
1
구글 시트 템플릿 내 드라이브로 복사하기

우측 상단의 [구글 시트 템플릿 복사하기] 버튼을 클릭한 후, 브라우저에 나타나는 [사본 만들기] 버튼을 누르면 본인의 구글 드라이브로 템플릿 시트가 즉시 복사됩니다.

2
'학생명단' 탭에서 우리 반 명단 수정하기

복사된 구글 시트 하단의 [학생명단] 탭을 선택하고, 우리 반 학생들의 번호와 이름을 입력합니다.

A열 번호 (1, 2, 3...)  |  B열 학생 이름  |  C열 비고 (선택사항)

기존 샘플 학생 명단을 지우고 실제 학생 명단을 붙여넣기만 하면 준비 완료됩니다.

3
웹 앱(Web App)으로 배포하기

스프레드시트 상단 메뉴에서 [확장 프로그램] > [Apps Script]를 클릭하여 스크립트 편집기 창을 엽니다.

  1. 우측 상단의 파란색 [배포] > [새 배포]를 클릭합니다.
  2. 설정(톱니바퀴) 아이콘을 눌러 유형을 [웹 앱]으로 선택합니다.
  3. 다음 사용자 권한으로 실행: 나(내 계정) 선택
  4. 액세스 권한이 있는 사용자: 모든 사용자(Anyone) 또는 나만 선택 후 [배포] 클릭
  5. (최초 1회 권한 승인) [액세스 승인] > 계정 선택 > [고급] > [~으로 이동(안전하지 않음)] > [허용] 진행
4
배포된 웹 앱 URL로 접속 및 북마크

배포 완료 화면에 생성된 웹 앱 URL을 복사하여 웹 브라우저 주소창에 입력하거나 북마크(즐겨찾기)에 등록합니다. PC, 태블릿, 스마트폰 어디서나 실시간으로 접속하여 자리배치 기능을 이용할 수 있습니다.

/**
 * 학생 명단 가져오기
 */
function getStudents() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName('학생명단');
  if (!sheet) return [];

  const data = sheet.getDataRange().getValues();
  if (data.length <= 1) return [];

  const students = [];
  for (let i = 1; i < data.length; i++) {
    if (data[i][1]) { // 이름이 있는 경우만
      students.push({
        id: Number(data[i][0]) || i,
        name: String(data[i][1]).trim(),
        note: data[i][2] ? String(data[i][2]) : ''
      });
    }
  }
  return students;
}

 * 최종 배치 결과 저장하기

function saveResult(title, layoutJson) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = ss.getSheetByName('배치이력');
  if (!sheet) {
    setupDatabase();
    sheet = ss.getSheetByName('배치이력');
  }

  const now = Utilities.formatDate(new Date(), 'Asia/Seoul', 'yyyy-MM-dd HH:mm:ss');
  sheet.appendRow([now, title, layoutJson]);
  return '저장 완료';
}

/**
 * 이전 배치 이력 목록 가져오기
 */
function getHistoryList() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName('배치이력');
  if (!sheet) return [];

  const data = sheet.getDataRange().getValues();
  if (data.length <= 1) return [];

  const list = [];
  for (let i = data.length - 1; i >= 1; i--) {
    list.push({
      rowIndex: i + 1,
      date: Utilities.formatDate(new Date(data[i][0]), 'Asia/Seoul', 'yyyy-MM-dd HH:mm'),
      title: data[i][1],
      json: data[i][2]
    });
  }
  return list;
}

/**
 * [내부용] 분리규칙 시트를 찾고, 없으면 헤더와 함께 새로 만든다.
 * - 학생번호목록 열은 '텍스트' 서식으로 고정
 *   (예: "3, 7" 이 숫자 37 이나 소수 3.7 로 바뀌는 것을 방지)
 */
function getOrCreateRuleSheet_() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = ss.getSheetByName(RULE_SHEET_NAME);
  if (!sheet) sheet = ss.insertSheet(RULE_SHEET_NAME);

  if (sheet.getLastRow() === 0) {
    sheet.getRange(1, 1, 1, RULE_HEADERS.length).setValues([RULE_HEADERS])
      .setBackground('#E11D48').setFontColor('#FFFFFF').setFontWeight('bold');
    sheet.getRange(2, 1, Math.max(1, sheet.getMaxRows() - 1), 1).setNumberFormat('@');
    sheet.setFrozenRows(1);
    sheet.setColumnWidth(1, 130);
    sheet.setColumnWidth(2, 240);
    sheet.setColumnWidth(3, 150);
    sheet.setColumnWidth(4, 150);
  }
  return sheet;
}

/**
 * [내부용] "3, 7, 12" 같은 문자열에서 학생 번호만 뽑아 중복 없는 숫자 배열로 변환
 */
function parseIdList_(text) {
  const ids = [];
  String(text || '').split(/[^0-9]+/).forEach(function(t) {
    const n = Number(t);
    if (t !== '' && !isNaN(n) && ids.indexOf(n) === -1) ids.push(n);
  });
  return ids;
}

/**
 * 저장된 분리 규칙 목록 가져오기 (웹 앱 랜덤 배치 + 고급설정 화면 공용)
 * @return {Array<{ids:number[], dirs:string[]}>}
 *   dirs 는 방향 코드 배열 ('v'=상하, 'h'=좌우, 'd'=대각선)
 * - 학생 '번호'만 내보내고 이름은 보내지 않음
 * - 사용자가 시트에서 직접 '상하, 대각선' 처럼 수정해도 읽을 수 있음
 */
function getSeparationRules() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(RULE_SHEET_NAME);
  if (!sheet || sheet.getLastRow() <= 1) return [];

  // 화면에 보이는 그대로(문자열) 읽어 숫자 자동 변환 문제를 피함
  const data = sheet.getRange(2, 1, sheet.getLastRow() - 1, RULE_HEADERS.length).getDisplayValues();

  // 한글 라벨 → 방향 코드 역변환표
  const labelToCode = {};
  Object.keys(DIR_LABELS).forEach(function(code) { labelToCode[DIR_LABELS[code]] = code; });
  labelToCode['대각'] = 'd';

  const rules = [];
  data.forEach(function(row) {
    const ids = parseIdList_(row[0]);
    const dirs = [];
    String(row[2] || '').split(/[,\/\s]+/).forEach(function(t) {
      const code = labelToCode[t.trim()];
      if (code && dirs.indexOf(code) === -1) dirs.push(code);
    });
    if (ids.length >= 2 && dirs.length) rules.push({ ids: ids, dirs: dirs });
  });
  return rules;
}

/**
 * 분리 규칙 전체 저장 (기존 규칙을 지우고 전달받은 목록으로 덮어씀)
 * - 규칙이 바뀌었으므로 이전 랜덤 배치 결과 기록은 초기화
 * @param {Array<{ids:number[], dirs:string[]}>} rules
 * @return {number} 실제 저장된 규칙 수
 */
function saveSeparationRules(rules) {
  const lock = LockService.getScriptLock();
  lock.waitLock(10000); // 동시에 저장해도 데이터가 꼬이지 않도록 잠금
  try {
    const sheet = getOrCreateRuleSheet_();

    // 시트에 이름도 같이 적어 두면 사람이 보기 편하므로 번호→이름 매핑 준비
    const nameMap = {};
    getStudents().forEach(function(s) { nameMap[s.id] = s.name; });

    const now = Utilities.formatDate(new Date(), 'Asia/Seoul', 'yyyy-MM-dd HH:mm:ss');
    const rows = [];

    (rules || []).forEach(function(r) {
      const ids = parseIdList_((r.ids || []).join(','));
      const dirs = ['v', 'h', 'd'].filter(function(code) { return (r.dirs || []).indexOf(code) !== -1; });
      if (ids.length < 2 || !dirs.length) return; // 잘못된 규칙은 건너뜀

      rows.push([
        ids.join(', '),
        ids.map(function(id) { return nameMap[id] || ('#' + id); }).join(', '),
        dirs.map(function(code) { return DIR_LABELS[code]; }).join(', '),
        now
      ]);
    });

    // 기존 규칙 행 비우기 (헤더는 유지)
    const last = sheet.getLastRow();
    if (last > 1) sheet.getRange(2, 1, last - 1, RULE_HEADERS.length).clearContent();

    if (rows.length) {
      sheet.getRange(2, 1, rows.length, RULE_HEADERS.length).setNumberFormat('@').setValues(rows);
    }

    // 규칙이 바뀌었으니 예전 결과 기록은 의미가 없어 삭제
    PropertiesService.getScriptProperties().deleteProperty(LAST_CHECK_KEY);
    return rows.length;
  } finally {
    lock.releaseLock();
  }
}

 * - 기록은 구글 시트 [⚙️ 고급설정] 창에서만 확인 가능
 * @param {{ruleCount:number, unmet:Array<{a:number, b:number, dir:string}>}} result
 *   unmet : 지키지 못한 학생 쌍 (학생 번호 + 방향 코드)
 */
function reportPlacementResult(result) {
  result = result || {};
  const nameMap = {};
  getStudents().forEach(function(s) { nameMap[s.id] = s.name; });

  const data = {
    time: Utilities.formatDate(new Date(), 'Asia/Seoul', 'yyyy-MM-dd HH:mm'),
    ruleCount: Number(result.ruleCount) || 0,
    unmet: (result.unmet || []).slice(0, 30).map(function(u) {
      return {
        a: nameMap[u.a] || ('#' + u.a),
        b: nameMap[u.b] || ('#' + u.b),
        dir: DIR_LABELS[u.dir] || ''
      };
    })
  };
  PropertiesService.getScriptProperties().setProperty(LAST_CHECK_KEY, JSON.stringify(data));
  return true;
}

/**
 * [내부용] 최근 랜덤 배치 결과 읽기 (기록이 없으면 null)
 */
function getLastPlacementCheck_() {
  const raw = PropertiesService.getScriptProperties().getProperty(LAST_CHECK_KEY);
  if (!raw) return null;
  try {
    return JSON.parse(raw);
  } catch (e) {
    return null;
  }
}

    // 상수 : 책상 크기와 자석 스냅 감도 (모두 픽셀 단위)
    // ==========================================================
    const SEAT_W = 104;   // 책상 가로
    const SEAT_H = 66;    // 책상 세로
    const GAP_X  = 16;    // 책상 사이 기본 좌우 간격
    const GAP_Y  = 18;    // 책상 사이 기본 상하 간격
    const SNAP   = 14;    // 자석이 작동하는 거리(이 안으로 들어오면 착 붙음)
    const MARGIN = 40;    // 캔버스 사방 여백 (좌/위로도 끌 수 있도록 확보)
    const BORDER = 2;     // 책상 테두리 두께 (붙을 때 겹치는 양)

    // ==========================================================
    // 상수 : 배치 조건 (교사가 구글 시트 [고급설정]에서 관리)
    // ※ 이 화면은 학생들이 함께 볼 수 있으므로, 조건과 관련된 내용은
    //    어떠한 문구·표시·알림으로도 화면에 드러내지 않습니다.
    // ==========================================================
    // 두 책상의 중심 거리가 '책상 크기 × 이 값' 이내이면 이웃으로 판정
    const NEIGHBOR_RANGE = 1.6;

    // ==========================================================
    // 전역 상태
    // ==========================================================
    let students = [];
    let gridData = [];          // 좌석 데이터 (x, y 는 항상 '교사 시점' 기준 물리 좌표)
    let rows = 6, cols = 5;
    let toolMode = 'magnet';    // 'magnet' | 'disable' | 'fix'
    let viewMode = 'teacher';   // 'teacher' | 'student'
    let snapEnabled = true;     // 자석 붙이기 사용 여부
    let groupMove = false;      // 붙은 책상 묶음 통째로 이동 여부
    let screenScale = 1;        // 화면 배율
    let canvasW = 0, canvasH = 0;
    let renderOffset = { x: 0, y: 0 };  // 인쇄 시 여백을 잘라내기 위한 렌더 오프셋
    let deskEls = {};           // id -> DOM 요소 (드래그 중 직접 조작용)
    let dragState = null;

    let separationRules = [];   // 랜덤 배치 직전에 서버에서 받아오는 조건 (화면 표시 없음)
    let isShuffling = false;    // 랜덤 배치 진행 중 (중복 클릭 방지)

    const BTN_IDLE = 'py-2 rounded-xl border border-slate-300 bg-white text-slate-600 font-bold text-xs flex items-center justify-center gap-1 transition';
    const BTN_ACTIVE = {
      disable: 'py-2 rounded-xl border border-red-500 bg-red-50 text-red-700 font-bold text-xs flex items-center justify-center gap-1 transition shadow-sm',
      fix:     'py-2 rounded-xl border border-amber-500 bg-amber-50 text-amber-700 font-bold text-xs flex items-center justify-center gap-1 transition shadow-sm',
      magnet:  'py-2 rounded-xl border border-sky-500 bg-sky-50 text-sky-700 font-bold text-xs flex items-center justify-center gap-1 transition shadow-sm',
      view:    'py-2 rounded-xl border border-indigo-500 bg-indigo-50 text-indigo-700 font-bold text-xs flex items-center justify-center gap-1 transition shadow-sm'
    };
    const BOARD_BASE = 'bg-slate-800 text-white font-bold text-center py-2 rounded-xl shadow-inner tracking-widest text-xs md:text-sm flex items-center justify-center gap-2 w-full shrink-0';

    // 초기 진입

      updateViewButtons();
      setToolMode('magnet');
      loadStudents();

    // 이름 등에 들어간 특수문자가 HTML 로 해석되지 않도록 변환
    function escapeHtml(t) {
      return String(t == null ? '' : t).replace(/[&<>"']/g, function(c) {
        return { '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' }[c];
      });
    }

    // 배열 무작위 섞기 (Fisher-Yates)
    function shuffleArray(arr) {
      for (let i = arr.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1));
        [arr[i], arr[j]] = [arr[j], arr[i]];
      }
      return arr;
    }

    // 커스텀 알림 모달
    // ==========================================================
    function showAlert(message, title = '알림', type = 'info') {
      const modal = document.getElementById('customAlertModal');
      const box = document.getElementById('customAlertBox');
      const iconBox = document.getElementById('alertIconContainer');
      const icon = document.getElementById('alertIcon');

      document.getElementById('alertTitle').innerText = title;
      document.getElementById('alertMessage').innerText = message;

      if (type === 'success') {
        iconBox.className = 'w-14 h-14 rounded-full flex items-center justify-center mx-auto mb-4 text-2xl bg-emerald-100 text-emerald-600';
        icon.className = 'fa-solid fa-check';
      } else if (type === 'warning') {
        iconBox.className = 'w-14 h-14 rounded-full flex items-center justify-center mx-auto mb-4 text-2xl bg-amber-100 text-amber-600';
        icon.className = 'fa-solid fa-triangle-exclamation';

        iconBox.className = 'w-14 h-14 rounded-full flex items-center justify-center mx-auto mb-4 text-2xl bg-indigo-100 text-indigo-600';

    // ==========================================================
    // 서버 통신 (학생 명단)

    function loadStudents() {
      google.script.run.withSuccessHandler(function(data) {
        students = data;
        document.getElementById('totalStudentsCount').innerText = students.length;
        document.getElementById('studentListCount').innerText = students.length;
        updateFixStudentSelect();
        renderStudentList();
        initGrid();
        fitToScreen(); // 모바일 등 화면이 좁으면 자동으로 배율 맞춤
      }).getStudents();
    }

    function renderStudentList() {
      const container = document.getElementById('studentListContainer');
      let html = `<table class="w-full text-[11px] text-left border-collapse print-student-table">
        <thead><tr class="bg-slate-100 text-slate-600 border-b border-slate-300">
          <th class="py-0.5 px-1 w-8 text-center whitespace-nowrap">번호</th>
          <th class="py-0.5 px-1 whitespace-nowrap">이름</th>
        </tr></thead><tbody>`;
      students.forEach((s, idx) => {
        const bg = idx % 2 === 0 ? 'bg-white' : 'bg-slate-50/60';
        html += `<tr class="${bg} border-b border-slate-200/80 whitespace-nowrap">
          <td class="py-0.5 px-1 font-bold text-slate-400 text-center border-r border-slate-100">${s.id}</td>
          <td class="py-0.5 px-1 font-bold text-slate-800">${escapeHtml(s.name)}</td></tr>`;
      });
      html += `</tbody></table>`;
      container.innerHTML = html;
    }

    function updateFixStudentSelect() {
      const select = document.getElementById('studentSelectForFix');
      select.innerHTML = '<option value="">-- 고정할 학생 선택 --</option>';
      students.forEach(s => {
        select.innerHTML += `<option value="${s.id}">${escapeHtml(s.name)} (${s.id}번)</option>`;
      });
    }

    // 좌석 데이터 생성 / 정규화
    // ==========================================================

    /**
     * 행/열 입력값에 따라 좌석 생성
     * @param {boolean} forceReset true 면 기존 위치·상태를 모두 버림
     * (기본은 false : 이미 옮겨둔 책상 위치와 상태를 최대한 보존)
     */
    function initGrid(forceReset) {
      const rIn = parseInt(document.getElementById('rowsInput').value);
      const cIn = parseInt(document.getElementById('colsInput').value);
      if (!rIn || rIn < 1 || !cIn || cIn < 1) return;

      const prev = {};
      if (!forceReset) gridData.forEach(s => { prev[s.id] = s; });

      rows = rIn; cols = cIn;
      const newGrid = [];

      for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
          const id = `r${r}_c${c}`;
          const old = prev[id];
          const seat = {
            id: id, row: r, col: c,
            status: old ? old.status : 'normal',
            student: old ? old.student : null,
            x: (old && typeof old.x === 'number') ? old.x : MARGIN + c * (SEAT_W + GAP_X),
            y: (old && typeof old.y === 'number') ? old.y : MARGIN + r * (SEAT_H + GAP_Y)
          };
          // 새로 생긴 책상이 기존 책상과 겹치면 빈자리를 찾아 살짝 밀어 놓음
          if (!old) findFreeSpot(seat, newGrid);
          newGrid.push(seat);
        }
      }
      gridData = newGrid;
      normalizePositions();
      renderGrid();
    }

    // 겹치지 않는 위치 탐색 (아래 → 오른쪽 순서로 밀기)
    function findFreeSpot(seat, placed) {
      let guard = 0;
      while (guard++ < 200 && placed.some(o => Math.abs(o.x - seat.x) < SEAT_W && Math.abs(o.y - seat.y) < SEAT_H)) {
        seat.y += SEAT_H + GAP_Y;
        if (seat.y > MARGIN + (rows + 2) * (SEAT_H + GAP_Y)) {
          seat.y = MARGIN;
          seat.x += SEAT_W + GAP_X;
        }
      }
    }

    function resetGrid() {
      initGrid(true);
      fitToScreen();
      showAlert('책상 위치, 삭제/고정 상태, 배정된 학생이 모두 초기화되었습니다.', '배치 초기화 완료', 'success');
    }

    // 전체 좌표를 좌상단 MARGIN 기준으로 정렬 (음수 좌표 방지 + 여백 확보)
    function normalizePositions() {
      if (!gridData.length) return;
      const minX = Math.min(...gridData.map(s => s.x));
      const minY = Math.min(...gridData.map(s => s.y));
      const dx = MARGIN - minX, dy = MARGIN - minY;
      gridData.forEach(s => { s.x = Math.round(s.x + dx); s.y = Math.round(s.y + dy); });
    }

    // 실제 책상들이 차지하는 영역 크기
    function getContentBounds() {
      if (!gridData.length) return { minX: 0, minY: 0, w: SEAT_W, h: SEAT_H };
      const minX = Math.min(...gridData.map(s => s.x));
      const minY = Math.min(...gridData.map(s => s.y));
      const maxX = Math.max(...gridData.map(s => s.x + SEAT_W));
      const maxY = Math.max(...gridData.map(s => s.y + SEAT_H));
      return { minX: minX, minY: minY, w: maxX - minX, h: maxY - minY };
    }

    /**
     * 시점에 따른 화면 뼈대(복도/창가 라벨, 칠판 위치)
     * - 교사 시점 : 칠판 아래, 왼쪽=복도 / 오른쪽=창가
     * - 학생 시점 : 180도 회전 → 칠판 위, 왼쪽=창가 / 오른쪽=복도
     */
    function renderLayoutFrame() {
      const labelBar = document.getElementById('sideLabelBar');
      const board = document.getElementById('boardBar');
      const grid = document.getElementById('gridContainer');

      const corridor = (dir) => dir === 'left'
        ? `<div class="flex items-center gap-1 text-indigo-700 bg-indigo-50 px-2.5 py-0.5 rounded-full border border-indigo-200"><i class="fa-solid fa-arrow-left"></i> 복도 쪽</div>`
        : `<div class="flex items-center gap-1 text-indigo-700 bg-indigo-50 px-2.5 py-0.5 rounded-full border border-indigo-200">복도 쪽 <i class="fa-solid fa-arrow-right"></i></div>`;
      const windowSide = (dir) => dir === 'left'
        ? `<div class="flex items-center gap-1 text-emerald-700 bg-emerald-50 px-2.5 py-0.5 rounded-full border border-emerald-200"><i class="fa-solid fa-arrow-left"></i> 창가 쪽</div>`
        : `<div class="flex items-center gap-1 text-emerald-700 bg-emerald-50 px-2.5 py-0.5 rounded-full border border-emerald-200">창가 쪽 <i class="fa-solid fa-arrow-right"></i></div>`;

      board.innerHTML = `<i class="fa-solid fa-chalkboard"></i> 칠 판 (앞 / 교탁 위치)`;

      if (viewMode === 'teacher') {
        labelBar.innerHTML = corridor('left')
          + `<div class="text-[11px] text-slate-400 font-normal text-center">[ 교사 시선 / 교탁에서 학생을 바라본 배치 ]</div>`
          + windowSide('right');
        board.className = BOARD_BASE + ' mt-3 mb-1';
        board.style.order = '3'; grid.style.order = '2';
      } else {
        labelBar.innerHTML = windowSide('left')
          + `<div class="text-[11px] text-slate-400 font-normal text-center">[ 학생 시선 / 자리에서 칠판을 바라본 배치 ]</div>`
          + corridor('right');
        board.className = BOARD_BASE + ' mb-3 mt-1';
        board.style.order = '2'; grid.style.order = '3';
      }
    }

    // 렌더링

    // 상하좌우로 다른 책상과 맞닿아 있는지 판정 (붙은 모서리 각지게 처리용)
    function getJoinInfo(seat) {
      const j = { l: false, r: false, t: false, b: false };
      gridData.forEach(o => {
        if (o.id === seat.id) return;
        const sameRow = Math.abs(o.y - seat.y) < 3;
        const sameCol = Math.abs(o.x - seat.x) < 3;
        if (sameRow && Math.abs((o.x + SEAT_W) - seat.x) < 3) j.l = true;
        if (sameRow && Math.abs((seat.x + SEAT_W) - o.x) < 3) j.r = true;
        if (sameCol && Math.abs((o.y + SEAT_H) - seat.y) < 3) j.t = true;
        if (sameCol && Math.abs((seat.y + SEAT_H) - o.y) < 3) j.b = true;
      });
      return j;
    }

    /**
     * 배치도 전체 그리기
     * @param {object} opts { tight:true } 면 여백 없이 딱 맞게 그림 (인쇄용)
     */
    function renderGrid(opts) {
      opts = opts || {};
      renderLayoutFrame();

      const canvas = document.getElementById('seatCanvas');
      canvas.innerHTML = '';
      deskEls = {};

      const b = getContentBounds();
      if (opts.tight) {
        renderOffset = { x: b.minX, y: b.minY };
        canvasW = b.w; canvasH = b.h;
      } else {
        renderOffset = { x: 0, y: 0 };
        canvasW = b.minX + b.w + MARGIN;
        canvasH = b.minY + b.h + MARGIN;
      }
      canvas.style.width = canvasW + 'px';
      canvas.style.height = canvasH + 'px';
      canvas.classList.toggle('rot180', viewMode === 'student');

      let available = 0;
      gridData.forEach(seat => {
        const el = createDeskElement(seat);
        canvas.appendChild(el);
        deskEls[seat.id] = el;
        if (seat.status !== 'disabled') available++;
      });

      document.getElementById('availableDesksCount').innerText = available;
      applyCanvasScale(opts.scale !== undefined ? opts.scale : screenScale);
    }

    // 책상 카드 1개 생성
    function createDeskElement(seat) {
      const j = getJoinInfo(seat);
      const el = document.createElement('div');

      // 붙은 면은 테두리 2px 을 겹쳐 하나의 선처럼 보이게 만듦
      let left = seat.x - renderOffset.x, top = seat.y - renderOffset.y;
      let w = SEAT_W, h = SEAT_H;
      if (j.l) { left -= BORDER; w += BORDER; }
      if (j.t) { top -= BORDER; h += BORDER; }
      el.style.left = left + 'px';
      el.style.top = top + 'px';
      el.style.width = w + 'px';
      el.style.height = h + 'px';

      let cls = 'seat-card border-2 select-none';
      if (j.l) cls += ' jl'; if (j.r) cls += ' jr';
      if (j.t) cls += ' jt'; if (j.b) cls += ' jb';

      const inner = document.createElement('div');
      inner.className = 'seat-inner' + (viewMode === 'student' ? ' rot180' : '');

      if (seat.status === 'disabled') {
        cls += ' is-disabled bg-slate-100 border-dashed border-slate-300 text-slate-400';
        inner.innerHTML = `<i class="fa-solid fa-xmark text-base"></i>
          <span class="text-[10px] font-semibold mt-0.5">빈자리</span>`;
      } else if (seat.status === 'fixed') {
        cls += ' bg-amber-50 border-amber-400 text-amber-900 shadow-sm';
        inner.innerHTML = `<span class="absolute top-1 left-1 text-[8px] bg-amber-200 px-1 py-0.5 rounded font-bold no-print">고정</span>
          <div class="seat-name text-sm md:text-base font-extrabold">${seat.student ? escapeHtml(seat.student.name) : ''}</div>`;
      } else {
        cls += ' bg-white border-indigo-200 hover:border-indigo-400 shadow-sm text-slate-700';
        if (seat.student) {
          inner.innerHTML = `<div class="seat-name text-base md:text-lg font-bold text-indigo-900">${escapeHtml(seat.student.name)}</div>`;
        } else {
          inner.innerHTML = `<span class="text-xs text-slate-300 font-semibold">빈 책상</span>`;
        }
      }

      if (toolMode === 'magnet') cls += ' draggable';
      el.className = cls;
      el.appendChild(inner);

      // 이동 모드일 때만 드래그, 그 외 모드에서는 클릭 동작
      if (toolMode === 'magnet') {
        el.addEventListener('pointerdown', (e) => startDrag(e, seat, el));
      } else {
        el.onclick = () => handleSeatClick(seat);
      }
      return el;
    }

    // 캔버스 배율 적용 (화면 확대/축소 + 인쇄 축소 공용)
    function applyCanvasScale(s) {
      const scaler = document.getElementById('seatScaler');
      const box = document.getElementById('seatScalerBox');
      scaler.style.transformOrigin = 'top left';
      scaler.style.transform = (s === 1) ? 'none' : `scale(${s})`;
      box.style.width = Math.ceil(canvasW * s) + 'px';
      box.style.height = Math.ceil(canvasH * s) + 'px';
    }

    function setScreenScale(s) {
      screenScale = Math.min(1.6, Math.max(0.4, Math.round(s * 100) / 100));
      applyCanvasScale(screenScale);
      document.getElementById('scaleLabel').innerText = Math.round(screenScale * 100) + '%';
    }

    // 화면 폭에 맞춰 자동 축소
    function fitToScreen() {
      const container = document.getElementById('gridContainer');
      const avail = container.clientWidth - 4;
      if (avail <= 0 || canvasW <= 0) return;
      setScreenScale(Math.min(1, avail / canvasW));
    }

    // ==========================================================
    // 클릭 동작 (삭제 / 고정석)
    // ==========================================================
    function handleSeatClick(seat) {
      if (toolMode === 'disable') {
        if (seat.status === 'disabled') {
          seat.status = 'normal';
        } else {
          seat.status = 'disabled';
          seat.student = null;
        }
      } else if (toolMode === 'fix') {
        if (seat.status === 'fixed') {
          seat.status = 'normal';
          seat.student = null;
        } else {
          const studentId = document.getElementById('studentSelectForFix').value;
          if (!studentId) {
            showAlert('상단 드롭다운에서 고정할 학생을 먼저 선택해 주세요.', '고정석 설정 안내', 'warning');
            return;
          }
          const selected = students.find(s => s.id == studentId);
          gridData.forEach(s => {
            if (s.student && s.student.id == studentId) { s.status = 'normal'; s.student = null; }
          });
          seat.status = 'fixed';
          seat.student = selected;
        }
      }
      renderGrid();
    }

    // 화면 좌표(포인터) → 캔버스 내부 모델 좌표로 변환
    // (배율 확대/축소 및 학생 시점 180도 회전을 모두 역보정)
    function pointerToModel(e) {
      const canvas = document.getElementById('seatCanvas');
      const rect = canvas.getBoundingClientRect();
      const s = (canvas.offsetWidth > 0) ? (rect.width / canvas.offsetWidth) : 1;
      const lx = (e.clientX - rect.left) / s;
      const ly = (e.clientY - rect.top) / s;
      if (viewMode === 'student') {
        return { x: canvas.offsetWidth - lx, y: canvas.offsetHeight - ly };
      }
      return { x: lx, y: ly };
    }

    // 서로 맞닿아 있는 책상 묶음(모둠) 찾기 - 너비 우선 탐색
    function getCluster(seat) {
      const cluster = [seat];
      const queue = [seat];
      while (queue.length) {
        const cur = queue.shift();
        gridData.forEach(o => {
          if (cluster.includes(o)) return;
          const hTouch = Math.abs(o.y - cur.y) < 3 &&
            (Math.abs((o.x + SEAT_W) - cur.x) < 3 || Math.abs((cur.x + SEAT_W) - o.x) < 3);
          const vTouch = Math.abs(o.x - cur.x) < 3 &&
            (Math.abs((o.y + SEAT_H) - cur.y) < 3 || Math.abs((cur.y + SEAT_H) - o.y) < 3);
          if (hTouch || vTouch) { cluster.push(o); queue.push(o); }
        });
      }
      return cluster;
    }

    /**
     * 자석 스냅 계산
     * 이동 중인 책상의 목표 좌표(px, py) 주변에서 가장 가까운 '붙을 자리'를 찾는다.
     * 후보 : ① 좌우 밀착 ② 상하 밀착 ③ 기본 간격 유지 ④ 행/열 정렬
     */
    function computeSnap(px, py, movingIds) {
      if (!snapEnabled) return { x: px, y: py, snapped: false };

      const others = gridData.filter(s => movingIds.indexOf(s.id) === -1);
      let snapped = false;

      // 1차 : 세로(Y) 스냅 결정
      let bestY = { d: SNAP + 1, v: py };
      others.forEach(o => {
        if (Math.abs(px - o.x) < SEAT_W * 0.85) {           // 가로로 겹칠 때만 위/아래 밀착 허용
          [o.y + SEAT_H, o.y - SEAT_H, o.y + SEAT_H + GAP_Y, o.y - SEAT_H - GAP_Y].forEach(v => {
            const d = Math.abs(py - v); if (d < bestY.d) bestY = { d: d, v: v };
          });
        }
        if (Math.abs(py - o.y) < SEAT_H * 0.9) {            // 같은 줄로 높이 맞추기
          const d = Math.abs(py - o.y); if (d < bestY.d) bestY = { d: d, v: o.y };
        }
      });
      const ny = (bestY.d <= SNAP) ? bestY.v : py;
      if (bestY.d <= SNAP) snapped = true;

      // 2차 : 확정된 Y를 기준으로 가로(X) 스냅 결정
      let bestX = { d: SNAP + 1, v: px };
      others.forEach(o => {
        if (Math.abs(ny - o.y) < SEAT_H * 0.85) {           // 세로로 겹칠 때만 좌우 밀착 허용
          [o.x + SEAT_W, o.x - SEAT_W, o.x + SEAT_W + GAP_X, o.x - SEAT_W - GAP_X].forEach(v => {
            const d = Math.abs(px - v); if (d < bestX.d) bestX = { d: d, v: v };
          });
        }
        if (Math.abs(px - o.x) < SEAT_W * 0.9) {            // 같은 열로 줄 맞추기
          const d = Math.abs(px - o.x); if (d < bestX.d) bestX = { d: d, v: o.x };
        }
      });
      const nx = (bestX.d <= SNAP) ? bestX.v : px;
      if (bestX.d <= SNAP) snapped = true;

      return { x: nx, y: ny, snapped: snapped };
    }

    // 드래그 시작
    function startDrag(e, seat, el) {
      if (toolMode !== 'magnet') return;
      e.preventDefault();

      const p = pointerToModel(e);
      const moving = groupMove ? getCluster(seat) : [seat];

      dragState = {
        seat: seat,
        offX: p.x - seat.x,
        offY: p.y - seat.y,
        rel: moving.map(s => ({ s: s, dx: s.x - seat.x, dy: s.y - seat.y })),
        ids: moving.map(s => s.id),
        moved: false,
        startX: e.clientX,
        startY: e.clientY
      };

      // 드래그 중에는 붙어있던 표현(모서리 겹침)을 일시 해제해 낱개로 표시
      dragState.rel.forEach(r => {
        const d = deskEls[r.s.id];
        if (!d) return;
        d.classList.remove('jl', 'jr', 'jt', 'jb');
        d.classList.add('dragging');
        d.style.width = SEAT_W + 'px';
        d.style.height = SEAT_H + 'px';
        d.style.left = r.s.x + 'px';
        d.style.top = r.s.y + 'px';
      });

      el.setPointerCapture(e.pointerId);
      el.addEventListener('pointermove', onDragMove);
      el.addEventListener('pointerup', onDragEnd);
      el.addEventListener('pointercancel', onDragEnd);
    }

    // 드래그 중
    function onDragMove(e) {
      if (!dragState) return;
      if (Math.abs(e.clientX - dragState.startX) > 3 || Math.abs(e.clientY - dragState.startY) > 3) {
        dragState.moved = true;
      }
      const p = pointerToModel(e);
      let nx = p.x - dragState.offX;
      let ny = p.y - dragState.offY;

      // 자석 스냅 적용
      const snap = computeSnap(nx, ny, dragState.ids);
      nx = snap.x; ny = snap.y;

      // 묶음 전체 기준으로 캔버스 밖으로 나가지 않게 제한
      const relXs = dragState.rel.map(r => r.dx);
      const relYs = dragState.rel.map(r => r.dy);
      const minRelX = Math.min(...relXs), maxRelX = Math.max(...relXs);
      const minRelY = Math.min(...relYs), maxRelY = Math.max(...relYs);
      nx = Math.max(-minRelX, Math.min(canvasW - SEAT_W - maxRelX, nx));
      ny = Math.max(-minRelY, Math.min(canvasH - SEAT_H - maxRelY, ny));

      // 위치 반영 (드래그 중에는 재렌더링 없이 DOM 만 직접 갱신)
      dragState.rel.forEach(r => {
        r.s.x = nx + r.dx;
        r.s.y = ny + r.dy;
        const d = deskEls[r.s.id];
        if (d) {
          d.style.left = r.s.x + 'px';
          d.style.top = r.s.y + 'px';
          d.classList.toggle('snapped', snap.snapped);
        }
      });
    }

    // 드래그 종료 → 좌표 정리 후 전체 재렌더링(붙은 모양 계산)
    function onDragEnd(e) {
      if (!dragState) return;
      const el = deskEls[dragState.seat.id];
      if (el) {
        el.removeEventListener('pointermove', onDragMove);
        el.removeEventListener('pointerup', onDragEnd);
        el.removeEventListener('pointercancel', onDragEnd);
      }
      dragState = null;
      normalizePositions();
      renderGrid();
    }

    // ★ 배치 조건 처리 (화면에는 어떤 표시도 하지 않음)
    // ==========================================================

    /**
     * 두 책상의 위치 관계 판정 (자유 배치 좌표 기준)
     * @return 'h'(좌우) | 'v'(상하) | 'd'(대각선) | null(이웃 아님)
     * - 중심 좌표 차이가 책상 크기의 절반 미만이면 '같은 줄/같은 열'로 봄
     * - 책상 크기 × NEIGHBOR_RANGE 이내면 '바로 옆'으로 봄
     */
    function getSeatRelation(a, b) {
      const dx = Math.abs(a.x - b.x), dy = Math.abs(a.y - b.y);
      const alignX = SEAT_W * 0.5, alignY = SEAT_H * 0.5;
      const nearX = SEAT_W * NEIGHBOR_RANGE, nearY = SEAT_H * NEIGHBOR_RANGE;

      if (dx < alignX && dy < alignY) return null;          // 거의 겹친 경우는 무시
      if (dy < alignY) return dx < nearX ? 'h' : null;      // 같은 줄 → 좌우
      if (dx < alignX) return dy < nearY ? 'v' : null;      // 같은 열 → 상하
      return (dx < nearX && dy < nearY) ? 'd' : null;       // 비스듬히 → 대각선
    }

    // 학생 두 명을 순서 상관없이 같은 키로 묶음 (예: 7|3 → "3|7")
    function pairKey(a, b) {
      a = Number(a); b = Number(b);
      return a < b ? a + '|' + b : b + '|' + a;
    }

    /**
     * 조건을 '학생 쌍 → 금지 방향' 지도로 변환
     * 3명 이상 묶인 조건은 그 안의 모든 쌍에 같은 방향 금지를 적용
     */
    function buildRuleMap() {
      const map = {};
      separationRules.forEach(r => {
        for (let i = 0; i < r.ids.length; i++) {
          for (let j = i + 1; j < r.ids.length; j++) {
            if (r.ids[i] == r.ids[j]) continue;
            const k = pairKey(r.ids[i], r.ids[j]);
            if (!map[k]) map[k] = {};
            r.dirs.forEach(d => { map[k][d] = true; });
          }
        }
      });
      return map;
    }

    function isBlocked(map, a, b, dir) {
      const entry = map[pairKey(a, b)];
      return !!(entry && entry[dir]);
    }

    // 현재 배치에서 조건을 지키지 못한 쌍 목록 (서버 기록용, 화면 표시 없음)
    function findViolations() {
      const map = buildRuleMap();
      if (!Object.keys(map).length) return [];
      const seats = gridData.filter(s => s.status !== 'disabled' && s.student);
      const list = [];
      for (let i = 0; i < seats.length; i++) {
        for (let j = i + 1; j < seats.length; j++) {
          const dir = getSeatRelation(seats[i], seats[j]);
          if (dir && isBlocked(map, seats[i].student.id, seats[j].student.id, dir)) {
            list.push({ a: seats[i].student.id, b: seats[j].student.id, dir: dir });
          }
        }
      }
      return list;
    }

    /**
     * 조건을 지키는 랜덤 배치 탐색 (Min-Conflict 지역 탐색 + 재시작)
     * 1) 학생을 무작위로 앉힌다
     * 2) 조건을 어긴 학생 하나를 골라, 다른 자리(빈 책상 포함)와 맞바꿨을 때
     *    위반이 가장 줄어드는 자리로 옮긴다 (동점이면 무작위)
     * 3) 막히면 가끔 무작위로 흔들어 빠져나오고, 그래도 안 되면 처음부터 다시
     * - 고정석 학생은 움직이지 않지만 이웃 검사에는 포함
     * - 최대 약 1.2초 탐색 후 가장 좋았던 결과를 반환
     * @return {{assign: Array, violations: number}} assign[i] = seats[i] 에 앉을 학생
     */
    function solveSeparation(pool, seats) {
      const slotIds = seats.map(s => s.id);
      const base = pool.slice();
      while (base.length < slotIds.length) base.push(null); // 남는 책상은 빈자리(null)
      shuffleArray(base);

      const map = buildRuleMap();
      if (!Object.keys(map).length) return { assign: base, violations: 0 }; // 조건 없으면 단순 셔플

      // 사용 가능한 모든 책상(고정석 포함)의 이웃 지도 미리 계산
      const active = gridData.filter(s => s.status !== 'disabled');
      const neighbors = {};
      active.forEach(s => { neighbors[s.id] = []; });
      for (let i = 0; i < active.length; i++) {
        for (let j = i + 1; j < active.length; j++) {
          const dir = getSeatRelation(active[i], active[j]);
          if (dir) {
            neighbors[active[i].id].push({ id: active[j].id, dir: dir });
            neighbors[active[j].id].push({ id: active[i].id, dir: dir });
          }
        }
      }

      // 고정석 학생 (움직이지 않음)
      const fixedMap = {};
      gridData.forEach(s => { if (s.status === 'fixed' && s.student) fixedMap[s.id] = s.student; });

      const cur = {}; // 움직일 수 있는 자리 → 학생
      const who = id => (id in cur) ? cur[id] : (fixedMap[id] || null);

      // 특정 자리에 앉은 학생이 이웃과 몇 건 충돌하는지
      const seatCost = id => {
        const st = who(id);
        if (!st || !neighbors[id]) return 0;
        let c = 0;
        neighbors[id].forEach(n => {
          const o = who(n.id);
          if (o && isBlocked(map, st.id, o.id, n.dir)) c++;
        });
        return c;
      };
      // 전체 위반 쌍 수 (각 쌍이 양쪽에서 두 번 세어지므로 / 2)
      const totalCost = () => active.reduce((sum, s) => sum + seatCost(s.id), 0) / 2;
      const swap = (a, b) => { const t = cur[a]; cur[a] = cur[b]; cur[b] = t; };
      const pick = arr => arr[Math.floor(Math.random() * arr.length)];

      let best = null, bestCost = Infinity;
      const deadline = Date.now() + 1200;
      let attempt = 0;

      while (bestCost > 0 && (attempt === 0 || Date.now() < deadline)) {
        if (attempt++ > 0) shuffleArray(base);     // 재시작 시 새로 섞기
        slotIds.forEach((id, i) => { cur[id] = base[i]; });

        for (let it = 0; it < 400; it++) {
          if ((it & 31) === 0 && Date.now() > deadline) break;
          const conflicted = slotIds.filter(id => seatCost(id) > 0);
          if (!conflicted.length) break;           // 움직일 수 있는 자리 중 충돌 없음

          const s1 = pick(conflicted);
          let bestDelta = Infinity, cands = [];
          slotIds.forEach(s2 => {
            if (s2 === s1 || cur[s1] === cur[s2]) return;
            const before = seatCost(s1) + seatCost(s2);
            swap(s1, s2);
            const after = seatCost(s1) + seatCost(s2);
            swap(s1, s2);
            const d = after - before;
            if (d < bestDelta) { bestDelta = d; cands = [s2]; }
            else if (d === bestDelta) cands.push(s2);
          });
          if (!cands.length) break;

          if (bestDelta <= 0) swap(s1, pick(cands));                 // 개선(또는 동점)이면 이동
          else if (Math.random() < 0.3) swap(s1, pick(slotIds.filter(id => id !== s1))); // 막혔을 때 흔들기
        }

        const c = totalCost();
        if (c < bestCost) { bestCost = c; best = slotIds.map(id => cur[id]); }
      }

      return { assign: best, violations: bestCost };
    }

    /**
     * 랜덤 배치 결과를 서버에 '조용히' 기록
     * - 화면에는 아무것도 띄우지 않음
     * - 교사는 구글 시트 [⚙️ 고급설정] 창에서 결과를 확인
     */
    function reportResultSilently() {
      if (!separationRules.length) return;
      google.script.run
        .withFailureHandler(function() { /* 기록 실패는 화면에 알리지 않음 */ })
        .reportPlacementResult({
          ruleCount: separationRules.length,
          unmet: findViolations()
        });
    }

    /**
     * 실제 좌표를 읽어 번호 순서를 정한다.
     * 창가(오른쪽) 세로줄부터 → 각 줄에서 칠판 앞(아래)부터 1번
     */
    function getOrderedSeatsByPosition() {
      const normal = gridData.filter(s => s.status === 'normal');
      const sorted = normal.slice().sort((a, b) => b.x - a.x);
      const bands = [];
      sorted.forEach(s => {
        let band = null;
        for (let i = 0; i < bands.length; i++) {
          if (Math.abs(bands[i].x - s.x) < SEAT_W * 0.6) { band = bands[i]; break; }
        }
        if (!band) { band = { x: s.x, items: [] }; bands.push(band); }
        band.items.push(s);
      });
      const result = [];
      bands.forEach(b => {
        b.items.sort((a, c) => c.y - a.y); // 아래(칠판 앞)부터
        result.push.apply(result, b.items);
      });
      return result;
    }

    /**
     * [랜덤 배치 시작!]
     * - 버튼을 누르면 이름이 돌아가는 연출을 '즉시' 시작하고,
     *   그동안 서버에서 최신 조건을 받아 최종 배치를 계산한다.
     * - 연출이 최소 횟수(약 1초) 이상 돌았고 계산도 끝났으면 결과로 확정.
     * - 화면상으로는 평범한 무작위 배치와 완전히 똑같이 보인다.
     */
    function randomizeSeats() {
      if (isShuffling) return;

      const fixedIds = gridData.filter(s => s.status === 'fixed' && s.student).map(s => s.student.id);
      const pool = students.filter(s => fixedIds.indexOf(s.id) === -1);
      const availableSeats = gridData.filter(s => s.status === 'normal');

      if (pool.length > availableSeats.length) {
        showAlert(`배치할 학생(${pool.length}명)이 이용 가능한 책상 수(${availableSeats.length}개)보다 많습니다.\n책상 수를 늘리시거나 삭제된 책상을 복원해 주세요.`, '책상 수 부족', 'warning');
        return;
      }

      isShuffling = true;
      let result = null;

      // ① 최신 조건을 받아 최종 배치 계산 (연출과 동시에 진행)
      google.script.run
        .withSuccessHandler(function(rules) {
          separationRules = (rules || []).map(r => ({ ids: r.ids.map(Number), dirs: r.dirs.slice() }));
          result = solveSeparation(pool, availableSeats);
        })
        .withFailureHandler(function() {
          result = solveSeparation(pool, availableSeats); // 실패 시 기존 조건(없으면 일반 셔플)
        })
        .getSeparationRules();

      // ② 돌아가는 연출
      let step = 0;
      const interval = setInterval(() => {
        // 서버 응답이 너무 늦으면(약 5초) 기존 조건으로 바로 계산
        if (!result && step > 60) result = solveSeparation(pool, availableSeats);

        if (step > 10 && result) {
          clearInterval(interval);
          availableSeats.forEach((seat, idx) => { seat.student = result.assign[idx] || null; });
          isShuffling = false;
          renderGrid();
          reportResultSilently();
          return;
        }

        availableSeats.forEach(seat => {
          seat.student = pool.length ? pool[Math.floor(Math.random() * pool.length)] : null;
        });
        renderGrid();
        step++;
      }, 80);
    }

    // 번호순 배치
    function sortByNumberSeats() {
      const fixedIds = gridData.filter(s => s.status === 'fixed' && s.student).map(s => s.student.id);
      const sortedStudents = students.filter(s => fixedIds.indexOf(s.id) === -1).sort((a, b) => a.id - b.id);
      const targetSeats = getOrderedSeatsByPosition();

      if (sortedStudents.length > targetSeats.length) {
        showAlert(`배치할 학생(${sortedStudents.length}명)이 이용 가능한 책상 수(${targetSeats.length}개)보다 많습니다.\n책상 수를 늘리시거나 삭제된 책상을 복원해 주세요.`, '책상 수 부족', 'warning');
        return;
      }

      gridData.forEach(s => { if (s.status === 'normal') s.student = null; });
      targetSeats.forEach((seat, idx) => { if (sortedStudents[idx]) seat.student = sortedStudents[idx]; });

      } else {

            ? 'bg-rose-600 border-rose-600 text-white shadow-sm'
            : 'bg-white border-slate-300 text-slate-600 hover:border-rose-300 hover:text-rose-600';

    // 방향 알약 HTML (small=true 면 규칙 목록용 작은 크기)
    function dirPillHtml(code, on, handler, small) {
      const m = DIR_META[code];
      const size = small ? 'px-2 py-0.5 text-[10px]' : 'px-3 py-1.5 text-xs';
      const cls = on
        ? 'bg-rose-600 border-rose-600 text-white shadow-sm'
        : 'bg-white border-slate-300 text-slate-400 hover:text-slate-600 hover:border-slate-400';
      return `<button type="button" onclick="${handler}" class="rounded-full border font-bold transition flex items-center gap-1 ${size} ${cls}">
        <i class="fa-solid ${m.icon}"></i> ${m.label}</button>`;
    }

    function renderDirPills() {
      document.getElementById('ruleDirPills').innerHTML =

      renderDirPreview();

    function toggleRuleDir(code) {

      if (i === -1) ruleDirs.push(code); else ruleDirs.splice(i, 1);
      hideFormMsg();
      renderDirPills();

    // 가운데 '나'를 기준으로 금지되는 칸을 빨갛게 표시
    function renderDirPreview() {
      const layout = ['d', 'v', 'd', 'h', 'me', 'h', 'd', 'v', 'd'];
      document.getElementById('ruleDirPreview').innerHTML = layout.map(k => {
        if (k === 'me') {

    function showFormMsg(msg, type) {
      const el = document.getElementById('ruleFormMsg');
      el.className = 'text-[11px] font-semibold ' + (type === 'info' ? 'text-indigo-600' : 'text-red-500');

    // ==========================================================
    // 규칙 추가 / 수정 / 삭제
    // ==========================================================
    /**
     * [규칙 추가] : 검증 후 목록 맨 위에 추가
     * 같은 학생 묶음이 이미 있으면 새로 만들지 않고 방향만 합침
     */
    function addRuleFromForm() {
      if (ruleSelectIds.length < 2) { showFormMsg('떨어뜨릴 학생을 2명 이상 선택해 주세요.'); return false; }
      if (!ruleDirs.length) { showFormMsg('피해야 할 방향을 하나 이상 선택해 주세요.'); return false; }

      const ids = ruleSelectIds.slice().sort((a, b) => a - b);
      const dirs = DIR_ORDER.filter(d => ruleDirs.indexOf(d) !== -1);
      const key = ids.join(',');
      const dup = rules.find(r => r.ids.slice().sort((a, b) => a - b).join(',') === key);

      if (dup) {
        dup.dirs = DIR_ORDER.filter(d => dup.dirs.indexOf(d) !== -1 || dirs.indexOf(d) !== -1);
        showFormMsg('이미 있는 학생 묶음이라 방향만 합쳐 두었어요.', 'info');
      } else {
        rules.unshift({ ids: ids, dirs: dirs });
        hideFormMsg();
        showToast('규칙을 추가했어요. [저장하기]를 눌러 마무리하세요.', 'info');
      }

      ruleSelectIds = [];
      document.getElementById('ruleStudentSearch').value = '';
      renderStudentChips();
      renderRuleList();
      return true;
    }

    function renderRuleList() {
      const box = document.getElementById('ruleListContainer');
      document.getElementById('ruleListCount').innerText = rules.length;

      if (!rules.length) {
        box.innerHTML = `<div class="text-center py-6 text-xs text-slate-400 border border-dashed border-slate-200 rounded-xl">
          아직 등록된 분리 규칙이 없습니다.</div>`;
        updateDirty();
        return;
      }

      box.innerHTML = rules.map((r, idx) => {
        const names = r.ids.map(id => {
          const st = findStudent(id);
          return st
            ? `<span class="bg-slate-100 text-slate-700 text-[11px] font-bold px-2 py-0.5 rounded-full">${escapeHtml(st.name)}</span>`
            : `<span class="bg-slate-50 text-slate-400 text-[11px] font-semibold px-2 py-0.5 rounded-full border border-dashed border-slate-300">#${id} (명단 없음)</span>`;
        }).join('');
        const pills = DIR_ORDER.map(code =>
          dirPillHtml(code, r.dirs.indexOf(code) !== -1, `toggleRuleDirInList(${idx}, '${code}')`, true)).join('');

        return `<div class="border border-slate-200 rounded-xl p-3 bg-white">
          <div class="flex justify-between items-start gap-2 mb-2">
            <div class="flex flex-wrap items-center gap-1">
              <span class="text-[10px] font-extrabold text-rose-500 mr-0.5">#${idx + 1}</span>${names}
            </div>
            <button type="button" onclick="removeRule(${idx})" class="w-7 h-7 shrink-0 rounded-lg text-slate-400 hover:text-red-500 hover:bg-red-50 transition">
              <i class="fa-solid fa-trash-can text-xs"></i>
            </button>
          </div>
          <div class="flex flex-wrap items-center gap-1.5">
            <span class="text-[10px] text-slate-400 font-semibold mr-0.5">금지 방향</span>${pills}
          </div>
        </div>`;
      }).join('');
      updateDirty();
    }

    // 목록에서 방향 알약 토글 (최소 1개는 유지)
    function toggleRuleDirInList(idx, code) {
      const r = rules[idx];
      if (!r) return;
      const i = r.dirs.indexOf(code);
      if (i !== -1) {
        if (r.dirs.length === 1) { showToast('방향은 최소 1개 이상 선택되어 있어야 해요.', 'warning'); return; }
        r.dirs.splice(i, 1);
      } else {
        r.dirs.push(code);
        r.dirs = DIR_ORDER.filter(d => r.dirs.indexOf(d) !== -1);
      }
      renderRuleList();
    }

    function removeRule(idx) {
      rules.splice(idx, 1);
      renderRuleList();
      showToast('규칙을 삭제했어요. [저장하기]를 눌러야 반영됩니다.', 'info');
    }

    function saveRules() {
      // 학생을 골라 놓고 [규칙 추가]를 깜빡한 경우 자동으로 추가
      if (ruleSelectIds.length >= 2 && ruleDirs.length) addRuleFromForm();

      const btn = document.getElementById('btnSave');
      btn.disabled = true;
      btn.innerHTML = `<i class="fa-solid fa-spinner fa-spin"></i> 저장 중...`;
      const payload = rules.map(r => ({ ids: r.ids.slice(), dirs: r.dirs.slice() }));

      google.script.run
        .withSuccessHandler(function(count) {
          btn.disabled = false;
          btn.innerHTML = `<i class="fa-solid fa-floppy-disk"></i> 저장하기`;
          savedSnapshot = JSON.stringify(rules);
          lastCheck = null;          // 규칙이 바뀌었으므로 이전 결과는 초기화됨
          updateDirty();
          renderLastCheck();
          showDialog({
            type: 'success',
            title: '저장 완료',
            message: count
              ? `분리 규칙 ${count}개가 [분리규칙] 탭에 저장되었습니다.\n웹 앱에서 [랜덤 배치 시작!]을 누르면 화면에 아무 표시 없이 조용히 적용됩니다.`
              : '분리 규칙이 모두 비워졌습니다.\n이제 [랜덤 배치]는 조건 없이 섞습니다.',
            buttons: [
              { label: '계속 편집', style: 'secondary' },
              { label: '창 닫기', style: 'primary', onClick: () => google.script.host.close() }
            ]
          });
        })
        .withFailureHandler(function(err) {
          btn.disabled = false;
          btn.innerHTML = `<i class="fa-solid fa-floppy-disk"></i> 저장하기`;
          showDialog({
            type: 'warning',
            title: '저장 실패',
            message: '분리 규칙을 저장하는 중 문제가 발생했습니다.\n잠시 후 다시 시도해 주세요.\n\n' + (err && err.message ? err.message : '')
          });
        })
        .saveSeparationRules(payload);
    }
