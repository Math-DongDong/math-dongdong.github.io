학생 소감문 관리 앱

구글 스프레드시트와 연동하여 소감문 제출부터 피드백, 기록 변환, 엑셀 정리까지 한곳에서 관리하세요.

바로 쓰는 소감문

학생은 학번으로 로그인해 활동을 고르고 소감문을 제출합니다.
이미 제출한 활동은 불러와서 고칠 수 있습니다.

내가 작성한 글 확인

제출한 글을 모아 보고 체크, 수정, 삭제할 수 있습니다.

간편한 활동 추가

교사 화면에서 날짜와 활동명을 입력해 활동을 추가하면 학생 화면의 활동 목록에 바로 나타납니다.

제출 현황 및 소감문 조회

활동명을 누르면 명단 전체의 제출 여부를 보여 주고, 학생이 쓴 소감문을 모아서 조회합니다.

피드백 일괄 생성

표에서 소감문을 선택하고 [AI 피드백 생성]을 누르면 Gemini가 교사 시점의 피드백을 만들어 저장합니다. 또는 직접 피드백을 제공할 수도 있습니다.

학생 소감문을 교사 시점 기록으로 변환

학생이 1인칭으로 쓴 소감문을 교사가 관찰한 시점의 문장으로 한 번에 바꿉니다. 변환한 글은 교사만 볼 수 있고 [고치기]로 직접 다듬을 수 있습니다.

글 모아 보기와 엑셀 저장

학생마다 교사 시점으로 생성된 글을 날짜순으로 이어 붙여 표로 보여 줍니다.
이후 복사하거나 엑셀 파일로 내려받을 수 있습니다.

비밀번호 초기화 기능

학번을 골라 초기 비밀번호로 되돌립니다.
학생이 초기 비밀번호로 로그인하면 새 비밀번호로 바꾸도록 안내합니다.

중요한 Key는 스크립트 속성에 보관

교사 비밀번호, 학생 초기 비밀번호, Gemini API 키는 시트가 아닌 스크립트 속성에만 저장되어 시트나 웹 앱 화면에 드러나지 않습니다.
[환경설정] 창에서 단계별로 등록하고 연결 테스트까지 할 수 있습니다.

소감문 관리 앱 복사 및 배포 가이드

구글 시트 템플릿 복사하기
1
구글 시트 템플릿 내 드라이브로 복사하기

우측 상단의 [구글 시트 템플릿 복사하기] 버튼을 클릭한 후, 브라우저에 나타나는 [사본 만들기] 버튼을 누르면 본인의 구글 드라이브로 템플릿 시트와 앱 코드가 함께 복사됩니다.

2
[DB 세팅 및 초기화]로 시트 구조 준비하기

복사한 시트를 새로고침하면 상단에 [📚 소감문 관리] 메뉴가 생깁니다. [📚 소감문 관리] > [DB 세팅 및 초기화]를 누르면 시트 구조를 점검하고, 필요한 탭과 열을 버튼 한 번으로 만들어 줍니다.

  1. (최초 1회 권한 승인) [계속] > 계정 선택 > [고급] > [~(으)로 이동(안전하지 않음)] > [허용] 진행
  2. 예시 데이터로 새로 시작하려면 [전체 초기화], 이미 입력한 데이터를 지키려면 [안전 세팅]을 누릅니다.
  3. 실행 전에 백업 시트 만들기를 켜 두면 기존 탭이 백업 탭으로 복사된 뒤 실행됩니다.
3
[환경설정]에서 비밀번호와 AI 키 등록하기

[📚 소감문 관리] > [환경설정]을 열면 단계별 등록 창이 나타납니다. 여기서 등록한 값은 시트가 아닌 스크립트 속성에만 저장되어 시트나 웹 앱 화면에 드러나지 않습니다.

  • 교사 비밀번호 필수 웹 앱에서 [교사]로 로그인할 때 씁니다.
  • 학생 초기 비밀번호 선택 등록하지 않으면 1234를 씁니다.
  • Gemini API 키 선택 Google AI Studio에서 발급합니다. 등록하지 않으면 AI 기능만 꺼지고 나머지 기능은 그대로 쓸 수 있습니다.
  • Gemini 모델 이름 선택 비워 두면 gemini-3.5-flash-lite를 씁니다. 모델이 바뀌면 이름만 새로 입력하세요.
  • AI 요청 간격 선택 비워 두면 4초입니다. 요청 한도 안내가 자주 뜨면 간격을 늘리세요.

Gemini API 키는 등록한 뒤 [연결 테스트] 버튼으로 바로 확인할 수 있습니다.

4
'환경설정' 탭에 우리 반 학번 입력하기

시트 하단의 [환경설정] 탭을 선택하고 A열에 학생들의 학번을 입력합니다. 이름은 저장하지 않고 학번으로만 학생을 구분합니다.

A열 학번 (1101, 1102...)  |  B열 패스워드 (비워 두면 초기 비밀번호)  |  C열 창체활동  |  D열 날짜

활동(C열, D열)은 웹 앱 교사 화면의 [활동 추가]에서 날짜와 활동명만 입력해도 자동으로 채워집니다.

5
웹 앱(Web App)으로 배포하기

스프레드시트 상단 메뉴에서 [확장 프로그램] > [Apps Script]를 클릭하여 스크립트 편집기 창을 엽니다.

  1. 우측 상단의 파란색 [배포] > [새 배포]를 클릭합니다.
  2. 설정(톱니바퀴) 아이콘을 눌러 유형을 [웹 앱]으로 선택합니다.
  3. 다음 사용자 권한으로 실행: 나(내 계정) 선택
  4. 액세스 권한이 있는 사용자: 학생들이 구글 로그인 없이 쓰려면 모든 사용자(Anyone) 선택 후 [배포] 클릭
  5. (권한 승인 창이 뜨면) [액세스 승인] > 계정 선택 > [고급] > [~(으)로 이동(안전하지 않음)] > [허용] 진행

코드를 고친 뒤에는 [배포] > [배포 관리]에서 연필 아이콘을 누르고 버전을 [새 버전]으로 바꿔 배포해야 웹 앱에 반영됩니다. 웹 앱 주소는 그대로 유지됩니다.

6
웹 앱 주소 공유하고 로그인하기

배포 완료 화면에 생성된 웹 앱 URL을 복사해 학급 게시판이나 QR 코드로 학생들에게 공유합니다. PC, 태블릿, 스마트폰 어디서나 접속할 수 있습니다.

  • 학생: 로그인 화면에서 [학생]을 고르고 학번과 비밀번호로 들어갑니다. 초기 비밀번호로 들어오면 새 비밀번호로 바꾸도록 안내합니다.
  • 교사: 로그인 화면에서 [교사]를 고르고 3단계에서 등록한 교사 비밀번호로 들어갑니다.
만 13세 미만 학생 접속 안내 (필독) 구글 계정 정책으로 인해 만 13세 미만의 학생은 앱스스크립트(Apps Script) 웹 앱 사용이 제한될 수 있습니다.
접속이 되지 않을 경우 인터넷 브라우저를 시크릿 모드(비공개 모드)로 바꾸어 접속하거나, 카카오톡 대화방으로 전달된 링크를 클릭(카카오톡 인앱 브라우저)하여 접속하면 제한 없이 정상적으로 소감문 작성 페이지를 이용할 수 있습니다.

데이터 관리 & 팁

모든 기록은 구글 시트에 자동으로 쌓입니다
  • 학생소감문 탭: 학생이 제출한 소감문과 교사가 쓴 피드백, 교사 시점 글이 한 줄씩 저장되어 시트에서 바로 확인하고 인쇄할 수 있습니다.
  • 프롬프트 탭: AI 창의 프롬프트 보관함에 저장한 프롬프트가 쌓입니다. 구분을 피드백, 교사시점, 공통으로 적으면 해당 AI 창에 나타납니다.
  • 명단과 활동 수정: 전학이나 활동 변경이 생기면 환경설정 탭만 고친 뒤 웹 앱의 [새로고침]을 누르면 바로 반영됩니다.
  • 엑셀로 정리: 교사 화면의 [교사 시점 글 모아 보기]에서 학기처럼 원하는 활동 날짜 범위를 골라, 학생별로 이어 붙인 글을 엑셀 파일로 내려받을 수 있습니다.
AI 기능을 쓸 때 확인하세요
  • Gemini에는 학번을 보내지 않고 활동명과 소감문 내용만 보냅니다.
  • 무료 API 키로 보낸 내용은 구글 서비스 개선에 쓰일 수 있으니, 소감문에 이름이나 연락처 같은 개인정보가 없는지 확인하세요.
  • AI가 만든 피드백은 저장과 동시에 학생 화면에 보입니다. 표에서 한 번 훑어보고 [고치기]로 다듬어 주세요.
  • 요청 한도 안내가 자주 뜨면 [환경설정]의 AI 요청 간격을 늘리세요. 한도에 걸린 글은 잠시 기다렸다가 자동으로 다시 시도합니다.
안전하게 쓰기 위한 장치
  • 비밀번호를 5번 틀리면 5분 동안 로그인이 잠깁니다.
  • [DB 세팅 및 초기화]와 [환경설정]은 구글 시트 편집 권한이 있는 사람만 열 수 있습니다.
  • 교사 시점 글은 교사 화면에서만 보이고 학생에게는 전달되지 않습니다.

/**
 * [로그인 확인]
 *  - id가 '관리자모드'이면 교사 로그인, 그 밖에는 학번으로 학생 로그인
 *  - 같은 계정으로 비밀번호를 5번 틀리면 5분 동안 잠급니다. (무작위 대입 방지)
 *  - 성공하면 세션 토큰을 발급합니다. 브라우저는 이후 모든 요청에 이 토큰을 함께 보냅니다.
 */
function verifyLogin(id, password) {
  const loginId = normalizeId_(id);
  const pw = toText_(password);
  if (!loginId || !pw) return { success: false, message: '학번과 비밀번호를 모두 입력하세요.' };
  if (loginId.length > 30) return { success: false, message: '학번 또는 비밀번호가 맞지 않아요.' };

  const isAdmin = loginId === ADMIN_LOGIN_ID;
  const cache = CacheService.getScriptCache();
  const failKey = 'LOGIN_FAIL_' + (isAdmin ? 'ADMIN' : loginId);
  const failCount = Number(cache.get(failKey) || 0);
  if (failCount >= LOGIN_MAX_FAIL) {
    return {
      success: false,
      message: '비밀번호를 ' + LOGIN_MAX_FAIL + '번 틀려서 ' + LOGIN_LOCK_MIN + '분 동안 로그인할 수 없어요. 잠시 후 다시 시도하세요.'
    };
  }

  // 실패 횟수를 1 늘리고, 남은 기회를 알려 주는 안내 문구를 만듭니다.
  const fail = (message) => {
    const count = failCount + 1;
    cache.put(failKey, String(count), LOGIN_LOCK_MIN * 60);
    const left = LOGIN_MAX_FAIL - count;
    return {
      success: false,
      message: left > 0 ? message + ' (남은 기회 ' + left + '번)' : message + ' ' + LOGIN_LOCK_MIN + '분 동안 로그인이 잠깁니다.'
    };
  };

  // ── 교사 로그인: 비밀번호는 시트가 아닌 스크립트 속성에서 확인 ──
  if (isAdmin) {
    const adminPw = getAppProperty_('ADMIN_PASSWORD');
    if (!adminPw) {
      return {
        success: false,
        message: '관리자가 아직 교사 비밀번호를 등록하지 않았습니다. 구글 시트 상단 [📚 소감문 관리] > [환경설정] 메뉴에서 등록해 주세요.'
      };
    }
    if (pw !== adminPw) return fail('교사 비밀번호가 맞지 않아요.');
    cache.remove(failKey);
    return { success: true, role: 'admin', token: createSession_({ role: 'admin' }) };
  }

  // ── 학생 로그인: [환경설정] A열(학번)으로 찾기 ──
  const student = readStudents_().list.filter(s => s.id === loginId)[0];
  const defaultPw = getDefaultStudentPassword_();
  const realPw = student ? (student.password || defaultPw) : '';   // 패스워드 칸이 비어 있으면 초기 비밀번호로 로그인
  if (!student || pw !== realPw) return fail('학번 또는 비밀번호가 맞지 않아요.');

  cache.remove(failKey);
  return {
    success: true,
    role: 'student',
    token: createSession_({ role: 'student', studentId: student.id }),
    studentId: student.id,
    isDefault: realPw === defaultPw
  };
}

/**
 * [소감문 저장] form.uniqueId가 있으면 수정, 없으면 새로 제출
 *  - 한 학생은 활동(날짜)마다 소감문을 하나만 낼 수 있습니다. (중복 제출 방지)
 *  - 활동명은 브라우저가 보낸 값을 믿지 않고 [환경설정] 시트에서 다시 찾습니다.
 *  - 여러 학생이 동시에 제출해도 행이 겹치지 않도록 잠금(Lock)을 겁니다.
 */
function saveReflection(token, form) {
  const session = requireSession_(token, 'student');
  form = form || {};
  const date = toText_(form.date);
  const content = String(form.content == null ? '' : form.content).replace(/\s+$/, '');
  const uniqueId = toText_(form.uniqueId);

  if (!date || !content.trim()) return { success: false, message: '활동을 고르고 소감문 내용을 입력하세요.' };
  if (content.length > MAX_CONTENT_LENGTH) {
    return { success: false, message: '소감문은 ' + MAX_CONTENT_LENGTH + '자까지 쓸 수 있어요. (지금 ' + content.length + '자)' };
  }

  return withLock_(() => {
    const settingTable = getTable_('환경설정');
    const student = readStudents_(settingTable).list.filter(s => s.id === session.studentId)[0];
    if (!student) return { success: false, message: '학생 명단에서 내 학번을 찾을 수 없어요. 선생님께 알려 주세요.' };

    const ref = readReflections_();
    const mine = ref.list.filter(r => r.studentId === student.id);
    const target = uniqueId ? mine.filter(r => r.uniqueId === uniqueId)[0] : null;
    if (uniqueId && !target) return { success: false, message: '수정할 글을 찾지 못했어요. 목록을 새로 불러온 뒤 다시 시도하세요.' };

    // 활동 목록에서 날짜로 활동명을 찾습니다. (목록에서 지워진 활동의 글은 기존 활동명 유지)
    const found = readActivities_(settingTable).filter(a => a.date === date)[0];
    const activity = found ? found.activity : (target && target.date === date ? target.activity : '');
    if (!activity) return { success: false, message: '고른 날짜의 활동을 찾지 못했어요. 새로고침한 뒤 다시 고르세요.' };

    const other = mine.filter(r => r.date === date && (!target || r.uniqueId !== target.uniqueId))[0];
    if (other) {
      return { success: false, duplicate: true, uniqueId: other.uniqueId, message: date + ' 활동의 소감문은 이미 냈어요. 낸 글을 수정하세요.' };
    }

    // ID = 날짜_학번 (혹시 겹치면 _2, _3을 붙여 항상 고유하게)
    const used = {};
    ref.list.forEach(r => { if (r.uniqueId && (!target || r.uniqueId !== target.uniqueId)) used[r.uniqueId] = true; });
    const newId = uniqueId_(date + '_' + student.id, used);
    const sheet = ref.table.sheet;
    const c = ref.table.col;

    if (target) {
      // [수정] 제출일시와 체크 상태는 그대로 두고 나머지만 바꿉니다.
      setTextCell_(sheet.getRange(target.rowNum, c['ID'] + 1), newId);
      sheet.getRange(target.rowNum, c['창체활동'] + 1).setValue(safeText_(activity));
      sheet.getRange(target.rowNum, c['날짜'] + 1).setValue(date);
      sheet.getRange(target.rowNum, c['소감문'] + 1).setValue(safeText_(content));
      return { success: true, message: '수정한 내용을 저장했어요.' };
    }

    // [신규] 헤더 순서에 맞춰 한 행을 만든 뒤 마지막 행 아래에 기록합니다.
    const tz = getSs_().getSpreadsheetTimeZone();
    const row = new Array(ref.table.headers.length).fill('');
    row[c['ID']] = newId;
    row[c['제출일시']] = Utilities.formatDate(new Date(), tz, 'yyyy. M. d a h:mm:ss');
    row[c['창체활동']] = safeText_(activity);
    row[c['날짜']] = date;
    row[c['체크']] = '';
    row[c['학번']] = student.id;
    row[c['소감문']] = safeText_(content);

    const rowNum = sheet.getLastRow() + 1;
    // ID·학번 칸은 값을 넣기 전에 '텍스트' 서식을 지정해야 앞자리 0이 사라지지 않습니다.
    sheet.getRange(rowNum, c['ID'] + 1).setNumberFormat('@');
    sheet.getRange(rowNum, c['학번'] + 1).setNumberFormat('@');
    sheet.getRange(rowNum, 1, 1, row.length).setValues([row]);
    return { success: true, message: '제출했어요.' };
  });
}

/** [활동 추가] [환경설정] 시트의 창체활동·날짜 열 맨 아래에 새 활동을 적습니다. */
function addSetting(token, date, activity) {
  requireSession_(token, 'admin');
  const d = toText_(date);
  const act = toText_(activity);
  if (!/^\d{4}-\d{2}-\d{2}$/.test(d) || !act) return { success: false, message: '날짜와 활동명을 모두 입력하세요.' };

  return withLock_(() => {
    const t = getTable_('환경설정');
    const exist = readActivities_(t).filter(a => a.date === d)[0];
    if (exist) {
      return { success: false, message: d + '에는 이미 \'' + exist.activity + '\' 활동이 있어요. 날짜 하나에 활동 하나만 등록할 수 있어요.' };
    }
    // 창체활동·날짜 열에서 마지막으로 값이 있는 행 바로 아래에 적습니다. (학생 명단 열과는 따로 셈)
    let lastFilled = 1;
    t.rows.forEach((r, i) => {
      if (toText_(r[t.col['창체활동']]) || String(r[t.col['날짜']]).trim()) lastFilled = i + 2;
    });
    const rowNum = lastFilled + 1;
    t.sheet.getRange(rowNum, t.col['창체활동'] + 1).setValue(safeText_(act));
    t.sheet.getRange(rowNum, t.col['날짜'] + 1).setValue(d);
    return { success: true, message: '\'' + act + '\' 활동을 추가했어요.' };
  });
}

/** 교사가 쓰는 칸(피드백·교사시점)에 글을 저장하는 공통 처리 */
function saveTeacherText_(uniqueId, column, value, label) {
  const text = String(value == null ? '' : value).trim();
  if (text.length > MAX_TEACHER_TEXT_LENGTH) {
    return { success: false, message: label + josa_(label, '은/는') + ' ' + MAX_TEACHER_TEXT_LENGTH + '자까지 쓸 수 있어요. (지금 ' + text.length + '자)' };
  }
  return withLock_(() => {
    const ref = readReflections_();
    const col = ref.table.col[column];
    if (col === undefined) return { success: false, message: missingColumnGuide_(column) };
    const target = ref.list.filter(r => r.uniqueId === toText_(uniqueId))[0];
    if (!target) return { success: false, message: '글을 찾지 못했어요. 새로고침한 뒤 다시 시도하세요.' };
    ref.table.sheet.getRange(target.rowNum, col + 1).setValue(text ? safeText_(text) : '');
    return { success: true, text: text, message: label + josa_(label, '을/를') + (text ? ' 저장했어요.' : ' 지웠어요.') };
  });
}

/**
 * [AI 일괄 작업] 선택한 소감문을 Gemini에 보내 결과를 시트에 저장합니다.
 *  - task: 'feedback'(학생에게 보이는 피드백) 또는 'teacherView'(교사 시점으로 바꾼 글)
 *  - 한 번에 최대 AI_BATCH_SIZE개까지 받습니다. 화면은 [환경설정]의 요청 간격을 지키려고 한 개씩 보냅니다.
 *  - 학번은 보내지 않고 활동명과 소감문 내용만 보냅니다.
 *  - 글마다 결과를 돌려줍니다: { uniqueId, status: 'done' | 'skipped' | 'error', text, message, retryable, fatal }
 *      retryable : 잠시 뒤 다시 시도하면 되는 오류 (요청 한도, 서버 혼잡, 일시적 연결 오류)
 *      fatal     : API 키나 모델 문제라서 계속 보내도 소용없는 오류
 *  - requested(실제로 AI에 보낸 글 수)와 intervalSec(지금 요청 간격)도 함께 돌려줍니다.
 */
function generateAiText(token, task, uniqueIds, prompt, skipExisting) {
  requireSession_(token, 'admin');
  const config = AI_TASKS[task];
  if (!config) return { success: false, message: '알 수 없는 AI 작업이에요.' };
  const apiKey = getAppProperty_('GEMINI_API_KEY');
  if (!apiKey) {
    return { success: false, message: 'Gemini API 키가 등록되지 않았어요. 구글 시트 상단 [📚 소감문 관리] > [환경설정]에서 등록해 주세요.' };
  }
  const teacherPrompt = toText_(prompt);
  if (!teacherPrompt) return { success: false, message: '프롬프트를 입력하세요.' };
  if (teacherPrompt.length > MAX_PROMPT_LENGTH) {
    return { success: false, message: '프롬프트는 ' + MAX_PROMPT_LENGTH + '자까지 쓸 수 있어요.' };
  }

  const ref = readReflections_();
  if (ref.table.col[config.column] === undefined) return { success: false, message: missingColumnGuide_(config.column) };
  const byId = {};
  ref.list.forEach(r => { byId[r.uniqueId] = r; });

  const ids = (Array.isArray(uniqueIds) ? uniqueIds : []).map(toText_).filter(id => id).slice(0, AI_BATCH_SIZE);
  const results = [];
  const targets = [];
  ids.forEach(id => {
    const r = byId[id];
    if (!r) results.push({ uniqueId: id, status: 'error', message: '글을 찾지 못했어요. 삭제됐을 수 있어요.' });
    else if (skipExisting && r[config.field].trim()) results.push({ uniqueId: id, status: 'skipped', message: '이미 써 둔 글이 있어요.' });
    else if (!r.content.trim()) results.push({ uniqueId: id, status: 'skipped', message: '소감문 내용이 비어 있어요.' });
    else targets.push(r);
  });
  const reply = () => ({ success: true, results: results, requested: targets.length, intervalSec: getAiIntervalSec_() });

  // ① Gemini에 요청합니다.
  const model = getGeminiModel_();
  let responses = [];
  if (targets.length) {
    try {
      responses = UrlFetchApp.fetchAll(targets.map(r =>
        buildGeminiRequest_(apiKey, model, config.system, buildAiPrompt_(teacherPrompt, r))));
    } catch (e) {
      targets.forEach(r => results.push({ uniqueId: r.uniqueId, status: 'error', retryable: true, message: 'AI 서버에 연결하지 못했어요. 잠시 뒤 다시 시도하세요.' }));
      return reply();
    }
  }
  const generated = [];
  responses.forEach((res, i) => {
    const parsed = parseGeminiResponse_(res, model);
    const id = targets[i].uniqueId;
    if (parsed.text) generated.push({ uniqueId: id, text: parsed.text.slice(0, MAX_TEACHER_TEXT_LENGTH) });
    else results.push({ uniqueId: id, status: 'error', message: parsed.message, retryable: !!parsed.retryable, fatal: !!parsed.fatal });
  });

  // ② 시트에 저장합니다. AI를 기다리는 사이 행 위치가 바뀌었을 수 있어 ID로 다시 찾습니다.
  if (generated.length) {
    withLock_(() => {
      const fresh = readReflections_();
      const rowById = {};
      fresh.list.forEach(r => { rowById[r.uniqueId] = r.rowNum; });
      generated.forEach(g => {
        if (!rowById[g.uniqueId]) {
          results.push({ uniqueId: g.uniqueId, status: 'error', message: 'AI가 답하는 사이에 글이 삭제됐어요.' });
          return;
        }
        fresh.table.sheet.getRange(rowById[g.uniqueId], fresh.table.col[config.column] + 1).setValue(safeText_(g.text));
        results.push({ uniqueId: g.uniqueId, status: 'done', text: g.text });
      });
    });
  }
  return reply();
}

/** 사용할 Gemini 모델 이름 ([환경설정]에 없으면 기본 모델) */
function getGeminiModel_() {
  return getAppProperty_('GEMINI_MODEL') || DEFAULT_GEMINI_MODEL;
}

/** AI 요청 간격(초): [환경설정]에 없거나 형식이 맞지 않으면 기본 간격 */
function getAiIntervalSec_() {
  const raw = getAppProperty_('AI_REQUEST_INTERVAL');
  if (!/^\d+$/.test(raw)) return DEFAULT_AI_INTERVAL_SEC;
  return Math.min(Number(raw), MAX_AI_INTERVAL_SEC);
}

/** AI에게 보낼 본문: 교사의 요청 + 활동 + 학생 소감문 (학번·ID는 넣지 않습니다) */
function buildAiPrompt_(teacherPrompt, r) {
  return '[교사의 요청]\n' + teacherPrompt +
    '\n\n[활동]\n' + r.date + ' ' + r.activity +
    '\n\n[학생 소감문]\n' + r.content;
}

/** Gemini generateContent 요청을 만듭니다. API 키는 주소가 아닌 헤더에 넣어 주소 기록에 남지 않게 합니다. */
function buildGeminiRequest_(apiKey, model, systemText, userText) {
  const body = { contents: [{ role: 'user', parts: [{ text: userText }] }] };
  if (systemText) body.systemInstruction = { parts: [{ text: systemText }] };
  return {
    url: GEMINI_API_BASE + encodeURIComponent(model) + ':generateContent',
    method: 'post',
    contentType: 'application/json',
    headers: { 'x-goog-api-key': apiKey },
    payload: JSON.stringify(body),
    muteHttpExceptions: true
  };
}

/** Gemini 응답 해석: 성공하면 { text }, 실패하면 { message, retryable, fatal } */
function parseGeminiResponse_(res, model) {
  const code = res.getResponseCode();
  let body = {};
  try { body = JSON.parse(res.getContentText()); } catch (e) { body = {}; }
  const apiMessage = body.error && body.error.message ? String(body.error.message) : '';

  if (code === 200) {
    const candidate = (body.candidates || [])[0];
    const parts = candidate && candidate.content && candidate.content.parts ? candidate.content.parts : [];
    const text = cleanAiText_(parts.filter(p => !p.thought).map(p => p.text || '').join(''));
    if (text) return { text: text };
    const reason = (body.promptFeedback && body.promptFeedback.blockReason) || (candidate && candidate.finishReason) || '';
    return { message: 'AI가 답을 만들지 못했어요' + (reason ? ' (' + reason + ')' : '') + '. 글 내용이나 프롬프트를 확인해 주세요.' };
  }
  if (code === 400 && /api key/i.test(apiMessage)) {
    return { fatal: true, message: 'API 키가 올바르지 않아요. [환경설정]에서 Gemini API 키를 다시 확인하세요.' };
  }
  if (code === 401 || code === 403) {
    return { fatal: true, message: '이 API 키로는 Gemini를 쓸 수 없어요. Google AI Studio에서 키 상태를 확인하세요.' };
  }
  if (code === 404) {
    return { fatal: true, message: '\'' + model + '\' 모델을 찾을 수 없어요. [환경설정]의 Gemini 모델 이름을 확인하세요.' };
  }
  if (code === 429) {
    return { retryable: true, message: '요청 한도를 넘었어요. 잠시 뒤 다시 시도하거나 [환경설정]에서 AI 요청 간격을 늘려 주세요.' };
  }
  if (code >= 500) return { retryable: true, message: 'AI 서버가 잠시 바빠요. 잠시 뒤 다시 시도하세요.' };
  return { message: 'AI 요청이 실패했어요. (' + code + (apiMessage ? ': ' + apiMessage.slice(0, 120) : '') + ')' };
}

/** AI 답에서 마크다운 기호(**굵게**, # 제목)와 앞뒤 공백을 정리합니다. */
function cleanAiText_(text) {
  return String(text || '').replace(/\*\*(.+?)\*\*/g, '$1').replace(/^\s*#+\s*/gm, '').trim();
}


/** [프롬프트 보관함 읽기] 이 AI 작업에서 쓸 수 있는 프롬프트 목록 (시트에서 직접 고친 내용도 바로 반영) */

}

/** [프롬프트 저장] 이 작업에서 보이는 프롬프트 중 같은 이름이 있으면 덮어쓰고, 없으면 새 줄로 추가합니다. */
function savePrompt(token, task, name, text) {
  requireSession_(token, 'admin');
  const type = PROMPT_TYPES[task];
  if (!type) return { success: false, message: '알 수 없는 AI 작업이에요.' };
  const cleanName = toText_(name);
  const cleanText = String(text == null ? '' : text).trim();
  if (!cleanName) return { success: false, message: '저장할 이름을 입력하세요.' };
  if (cleanName.length > MAX_PROMPT_NAME_LENGTH) return { success: false, message: '이름은 ' + MAX_PROMPT_NAME_LENGTH + '자까지 쓸 수 있어요.' };
  if (!cleanText) return { success: false, message: '프롬프트 내용을 입력하세요.' };
  if (cleanText.length > MAX_PROMPT_LENGTH) return { success: false, message: '프롬프트는 ' + MAX_PROMPT_LENGTH + '자까지 쓸 수 있어요.' };

  return withLock_(() => {
    const table = getOptionalTable_('프롬프트');
    if (!table) return { success: false, message: missingPromptSheetGuide_() };
    const c = table.col;
    const now = Utilities.formatDate(new Date(), getSs_().getSpreadsheetTimeZone(), 'yyyy. M. d a h:mm:ss');
    const found = findPromptRow_(table, type, cleanName);
    if (found) {
      table.sheet.getRange(found.rowNum, c['프롬프트'] + 1).setValue(safeText_(cleanText));
      table.sheet.getRange(found.rowNum, c['수정일시'] + 1).setValue(now);
    } else {
      const row = table.headers.map(() => '');
      row[c['구분']] = type;
      row[c['이름']] = safeText_(cleanName);
      row[c['프롬프트']] = safeText_(cleanText);
      row[c['수정일시']] = now;
      table.sheet.getRange(table.sheet.getLastRow() + 1, 1, 1, row.length).setValues([row]);
    }
    const result = promptListResult_(task);
    result.message = '\'' + cleanName + '\' 프롬프트를 ' + (found ? '덮어썼어요.' : '보관함에 저장했어요.');
    result.overwritten = !!found;
    return result;
  });
}

/** [프롬프트 삭제] 이 작업에서 보이는 프롬프트 중 이름이 같은 줄을 시트에서 지웁니다. */

  });
}

/** 없어도 되는 시트 읽기: 시트가 없으면 null (있는데 헤더가 틀리면 getTable_이 안내와 함께 오류) */
function getOptionalTable_(sheetName) {
  return getSs_().getSheetByName(sheetName) ? getTable_(sheetName) : null;
}

function missingPromptSheetGuide_() {
  return '\'프롬프트\' 시트가 없어요. 구글 시트 상단 [📚 소감문 관리] > [DB 세팅 및 초기화]에서 [안전 세팅]을 실행하면 예시 프롬프트와 함께 만들어져요.';
}

/** [프롬프트] 시트의 모든 줄 (이름과 내용이 모두 빈 줄은 건너뜀) */
function readPrompts_(table) {
  const c = table.col;
  const tz = getSs_().getSpreadsheetTimeZone();
  const list = [];
  table.rows.forEach((r, i) => {
    const name = toText_(r[c['이름']]);
    const text = r[c['프롬프트']] == null ? '' : String(r[c['프롬프트']]).trim();
    if (!name && !text) return;
    list.push({
      rowNum: i + 2,
      type: toText_(r[c['구분']]),
      name: name || '(이름 없음, ' + (i + 2) + '행)',
      text: text,
      updatedAt: formatDateTime_(r[c['수정일시']], tz)
    });
  });
  return list;
}

/** 이 구분에서 보이는 프롬프트인지: 같은 구분이거나, 구분이 '공통'이거나 비어 있으면 보임 */
function isVisiblePrompt_(p, type) {
  return p.type === type || p.type === COMMON_PROMPT_TYPE || p.type === '';
}

/** 이름이 같은 줄 찾기 (같은 구분의 줄을 공통 줄보다 먼저) */
function findPromptRow_(table, type, name) {
  const matches = readPrompts_(table).filter(p => isVisiblePrompt_(p, type) && p.name === name);
  matches.sort((a, b) => (a.type === type ? 0 : 1) - (b.type === type ? 0 : 1));
  return matches[0] || null;
}

/** 화면에 보낼 목록: 내용이 있는 프롬프트만, 시트에 적힌 순서대로 */
function promptListResult_(task) {
  const type = PROMPT_TYPES[task];
  if (!type) return { success: false, message: '알 수 없는 AI 작업이에요.' };
  const table = getOptionalTable_('프롬프트');
  if (!table) return { success: true, ready: false, prompts: [], message: missingPromptSheetGuide_() };
  const prompts = readPrompts_(table)
    .filter(p => p.text && isVisiblePrompt_(p, type))
    .map(p => ({ name: p.name, type: p.type || COMMON_PROMPT_TYPE, text: p.text, updatedAt: p.updatedAt }));
  return { success: true, ready: true, prompts: prompts };
}

/**
 * [진단] 시트를 바꾸지 않고 현재 상태만 살펴봅니다.
 *  - 시트 존재 여부, 빠진 헤더, 시트에 적힌 관리자 패스워드 감지
 *  - 구조가 정상이면 명단·활동 데이터까지 점검 (빈 명단, 학번 중복, 같은 날짜 활동 중복)
 */
function diagnoseDatabase() {
  assertSheetEditor_();
  const ss = getSs_();
  const sheets = SHEET_SCHEMA.map(schema => {
    const sheet = ss.getSheetByName(schema.name);
    const item = {
      name: schema.name, expected: schema.headers, headers: [], exists: !!sheet,
      dataRows: 0, status: 'ok', tasks: [], warnings: []
    };
    if (!sheet) {
      item.status = 'missing';
      item.tasks.push('시트를 새로 만들고 1행에 헤더를 씁니다.' + (schema.seedWhenCreated ? ' 예시 ' + schema.dummyRows.length + '행도 함께 넣습니다.' : ''));
      return item;
    }
    const rawHeaders = readHeaderRow_(sheet);
    item.headers = rawHeaders.filter(h => h);
    item.dataRows = Math.max(0, sheet.getLastRow() - 1);
    if (!item.headers.length) {
      item.tasks.push('1행에 헤더를 씁니다.');
    } else {
      missingHeaders_(schema, rawHeaders).forEach(h => item.tasks.push('\'' + h + '\' 열을 추가합니다. 기존 열과 데이터는 그대로 둡니다.'));
    }
    if (schema.name === '환경설정' && findLegacyAdminCol_(rawHeaders) > -1) {
      item.tasks.push('시트에 적힌 관리자 패스워드를 스크립트 속성으로 옮기고, 시트에서는 지웁니다.');
    }
    if (item.tasks.length) item.status = 'fix';
    return item;
  });

  const setting = sheets.filter(s => s.name === '환경설정')[0];
  const data = analyzeData_();
  if (data.setting) {
    const d = data.setting;
    if (!d.students) setting.warnings.push('학생 명단이 비어 있어요. 학번 열에 학번을 입력하세요.');
    if (d.dupIds.length) setting.warnings.push('학번이 겹치는 학생이 있어요: ' + summarizeList_(d.dupIds));
    if (d.dupDates.length) setting.warnings.push('같은 날짜에 활동이 두 개 이상 있어요: ' + summarizeList_(d.dupDates) + ' (첫 번째 활동만 사용)');
  }

  return {
    sheets: sheets,
    adminPasswordRegistered: !!getAppProperty_('ADMIN_PASSWORD'),
    legacyAdminPassword: data.legacyAdminPassword
  };
}

/**
 * [실행]
 *  - mode 'safe'  : 기존 열과 데이터는 그대로 두고, 없는 시트와 빠진 열만 만듭니다.
 *  - mode 'reset' : 두 시트의 내용을 모두 지우고 예시 데이터로 다시 채웁니다. (되돌릴 수 없음)
 *  - withBackup   : true면 실행 전에 두 시트를 '백업_시트명_날짜' 시트로 복제합니다.
 */
function runDatabaseSetup(mode, withBackup) {
  assertSheetEditor_();
  if (mode !== 'safe' && mode !== 'reset') throw new Error('알 수 없는 세팅 방식입니다.');

  return withLock_(() => {
    const ss = getSs_();
    const logs = [];
    if (withBackup) backupSheets_(logs);

    // 시트에 적힌 관리자 패스워드는 어떤 방식이든 가장 먼저 스크립트 속성으로 옮깁니다. (보안 + 교사 로그인 유지)
    const settingSheet = ss.getSheetByName('환경설정');
    if (settingSheet) migrateLegacyAdminPassword_(settingSheet, logs);

    const defaultPw = getDefaultStudentPassword_();
    SHEET_SCHEMA.forEach(schema => {
      let sheet = ss.getSheetByName(schema.name);
      const isNew = !sheet;
      if (isNew) {
        sheet = ss.insertSheet(schema.name);
        logs.push('[' + schema.name + '] 시트를 새로 만들었습니다.');
      }

      if (mode === 'reset') {
        sheet.clear();
        sheet.getRange(1, 1, 1, schema.headers.length).setValues([schema.headers]);
        styleSheet_(sheet, schema, true);   // 텍스트 서식을 먼저 지정해야 예시 학번의 앞자리 0이 보존됩니다.
        const rows = schema.dummyRows.map(row => row.map(v => (v === DEFAULT_PW_MARK ? defaultPw : v)));
        if (rows.length) sheet.getRange(2, 1, rows.length, schema.headers.length).setValues(rows);
        logs.push('[' + schema.name + '] 내용을 모두 지우고 예시 데이터 ' + rows.length + '행을 넣었습니다.');
      } else {
        applyHeaderFix_(sheet, schema, logs);
        styleSheet_(sheet, schema, isNew);
        if (isNew && schema.seedWhenCreated && schema.dummyRows.length) {
          sheet.getRange(2, 1, schema.dummyRows.length, schema.headers.length).setValues(schema.dummyRows);
          logs.push('[' + schema.name + '] 예시 ' + schema.dummyRows.length + '행을 넣었습니다.');
        }
      }
    });

    if (!logs.length) logs.push('모든 시트가 이미 올바른 구조라서 바뀐 내용이 없습니다.');
    return { success: true, logs: logs };
  }, 30000);
}

/** 1행(헤더)을 문자열 배열로 읽습니다. */
function readHeaderRow_(sheet) {
  const lastCol = sheet.getLastColumn();
  if (lastCol < 1) return [];
  return sheet.getRange(1, 1, 1, lastCol).getValues()[0].map(h => String(h).trim());
}

/** 스키마에는 있는데 시트 1행에는 없는 헤더 목록 */
function missingHeaders_(schema, headers) {
  return schema.headers.filter(h => headers.indexOf(h) === -1);
}

/** 예전 구조의 '관리자 패스워드' 열 위치(0부터)를 찾습니다. 없으면 -1 */
function findLegacyAdminCol_(headers) {
  for (let i = 0; i < headers.length; i++) {
    const h = String(headers[i]).replace(/\s/g, '');
    if (h === '관리자패스워드' || h === '관리자비밀번호') return i;
  }
  return -1;
}

/** [안전 세팅] 빠진 헤더를 스키마 순서에 맞는 자리에 끼워 넣습니다. (기존 열과 데이터는 건드리지 않음) */
function applyHeaderFix_(sheet, schema, logs) {
  const tag = '[' + schema.name + '] ';
  if (readHeaderRow_(sheet).every(h => !h)) {
    sheet.getRange(1, 1, 1, schema.headers.length).setValues([schema.headers]);
    logs.push(tag + '1행에 헤더를 썼습니다.');
    return;
  }
  missingHeaders_(schema, readHeaderRow_(sheet)).forEach(name => {
    const headers = readHeaderRow_(sheet);
    const k = schema.headers.indexOf(name);
    // 스키마에서 바로 앞 순서인 헤더를 찾아 그 오른쪽에 새 열을 넣습니다. (없으면 맨 앞)
    let anchor = 0;
    for (let j = k - 1; j >= 0; j--) {
      const idx = headers.indexOf(schema.headers[j]);
      if (idx > -1) { anchor = idx + 1; break; }
    }
    if (anchor === 0) sheet.insertColumnBefore(1);
    else sheet.insertColumnAfter(anchor);
    sheet.getRange(1, anchor + 1).setValue(name);
    logs.push(tag + '\'' + name + '\' 열을 ' + columnLetter_(anchor + 1) + '열에 추가했습니다.');
  });
}

/** 틀 고정, 텍스트 서식 지정. fullStyle이면 헤더 꾸미기·열 너비·줄바꿈까지 적용합니다. */
function styleSheet_(sheet, schema, fullStyle) {
  const headers = readHeaderRow_(sheet);
  const maxRows = sheet.getMaxRows();
  sheet.setFrozenRows(1);
  schema.textColumns.forEach(name => {
    const idx = headers.indexOf(name);
    if (idx > -1 && maxRows > 1) sheet.getRange(2, idx + 1, maxRows - 1, 1).setNumberFormat('@');
  });
  if (!fullStyle) return;
  sheet.getRange(1, 1, 1, schema.headers.length)
    .setFontWeight('bold').setBackground('#E1EBE6').setHorizontalAlignment('center');
  schema.columnWidths.forEach((w, i) => sheet.setColumnWidth(i + 1, w));
  ['소감문', '피드백', '교사시점', '프롬프트'].forEach(name => {
    const idx = headers.indexOf(name);
    if (idx > -1 && maxRows > 1) sheet.getRange(2, idx + 1, maxRows - 1, 1).setWrap(true);
  });
}

/** 예전 E2의 '관리자 패스워드'를 스크립트 속성으로 옮기고 시트에서는 지웁니다. */
function migrateLegacyAdminPassword_(sheet, logs) {
  const idx = findLegacyAdminCol_(readHeaderRow_(sheet));
  if (idx === -1) return;
  const col = idx + 1;
  const lastRow = Math.max(sheet.getLastRow(), 2);
  const values = sheet.getRange(1, col, lastRow, 1).getValues().map(r => toText_(r[0]));
  const legacyPw = values[1];
  const props = PropertiesService.getScriptProperties();

  if (legacyPw && !props.getProperty('ADMIN_PASSWORD')) {
    props.setProperty('ADMIN_PASSWORD', legacyPw);
    logs.push('[환경설정] 시트에 있던 관리자 패스워드를 스크립트 속성으로 옮겼습니다. 교사 로그인은 기존 비밀번호 그대로 쓰면 됩니다.');
  } else if (legacyPw) {
    logs.push('[환경설정] 스크립트 속성에 교사 비밀번호가 이미 있어서, 시트의 관리자 패스워드는 옮기지 않고 지웠습니다.');
  }

  // 그 열에 다른 데이터가 없으면 열째 삭제, 있으면 헤더와 비밀번호 칸만 비웁니다.
  const hasOtherData = values.slice(2).some(v => v !== '');
  if (!hasOtherData && sheet.getMaxColumns() > 1) sheet.deleteColumn(col);
  else sheet.getRange(1, col, 2, 1).clearContent();
  logs.push('[환경설정] \'관리자 패스워드\' 열을 시트에서 정리했습니다.');
}

/** 실행 전 백업: 두 시트를 같은 파일 안에 '백업_시트명_날짜' 이름으로 복제합니다. */
function backupSheets_(logs) {

  SHEET_SCHEMA.forEach(schema => {

  });
}

/** 진단용 데이터 점검 (시트를 바꾸지 않음) */
function analyzeData_() {
  const ss = getSs_();
  const result = { setting: null, legacyAdminPassword: false };

  const settingSheet = ss.getSheetByName('환경설정');
  if (settingSheet) {
    const idx = findLegacyAdminCol_(readHeaderRow_(settingSheet));
    if (idx > -1) result.legacyAdminPassword = toText_(settingSheet.getRange(2, idx + 1).getValue()) !== '';
  }

  let st = null;
  try { st = getTable_('환경설정'); } catch (e) { st = null; }
  if (!st) return result;

  const tz = ss.getSpreadsheetTimeZone();
  const students = readStudents_(st).list;
  const idCount = {};
  students.forEach(s => { idCount[s.id] = (idCount[s.id] || 0) + 1; });
  const dateCount = {};
  st.rows.forEach(r => {
    const d = formatDate_(r[st.col['날짜']], tz);
    if (d && toText_(r[st.col['창체활동']])) dateCount[d] = (dateCount[d] || 0) + 1;
  });

  result.setting = {
    students: students.length,
    dupIds: Object.keys(idCount).filter(k => idCount[k] > 1),
    dupDates: Object.keys(dateCount).filter(k => dateCount[k] > 1)
  };
  return result;
}

/**
 * 시트 전체를 읽어 '헤더 이름 → 열 번호' 지도와 함께 돌려줍니다.
 *  - col['학번'] = 0 처럼 0부터 시작하는 열 번호
 *  - rows는 2행부터의 데이터 (rows[i]는 시트의 i+2행)
 */
function getTable_(sheetName) {
  const guide = '구글 시트 상단 [📚 소감문 관리] > [DB 세팅 및 초기화]에서 [안전 세팅]을 실행해 주세요.';
  const sheet = getSs_().getSheetByName(sheetName);
  if (!sheet) throw new Error('\'' + sheetName + '\' 시트가 없습니다. ' + guide);

  const lastRow = sheet.getLastRow();
  const lastCol = sheet.getLastColumn();
  const values = (lastRow > 0 && lastCol > 0) ? sheet.getRange(1, 1, lastRow, lastCol).getValues() : [];
  const headers = values.length ? values[0].map(h => String(h).trim()) : [];
  const col = {};
  headers.forEach((h, i) => { if (h && col[h] === undefined) col[h] = i; });

  const schema = getSchema_(sheetName);
  const optional = schema.optionalHeaders || [];   // 없어도 되는 열 (예: 피드백)
  const missing = schema.headers.filter(h => col[h] === undefined && optional.indexOf(h) === -1);
  if (missing.length) throw new Error('\'' + sheetName + '\' 시트에 [' + missing.join(', ') + '] 열이 없습니다. ' + guide);
  return { sheet: sheet, headers: headers, col: col, rows: values.slice(1) };
}

/** 학생 명단 읽기: 학번이 있는 행만 [{id, password, rowNum}] */
function readStudents_(table) {
  const t = table || getTable_('환경설정');
  const list = [];
  t.rows.forEach((r, i) => {
    const id = normalizeId_(r[t.col['학번']]);
    if (!id) return;
    list.push({ id: id, password: toText_(r[t.col['패스워드']]), rowNum: i + 2 });
  });
  return { table: t, list: list };
}

/** 활동 목록 읽기: [{date, activity}] 최근 날짜가 위. 같은 날짜가 여러 번이면 첫 번째만 씁니다. */
function readActivities_(table) {
  const t = table || getTable_('환경설정');
  const tz = getSs_().getSpreadsheetTimeZone();
  const seen = {};
  const list = [];
  t.rows.forEach(r => {
    const activity = toText_(r[t.col['창체활동']]);
    const date = formatDate_(r[t.col['날짜']], tz);
    if (!activity || !date || seen[date]) return;
    seen[date] = true;
    list.push({ date: date, activity: activity });
  });
  return list.sort((a, b) => (a.date < b.date ? 1 : a.date > b.date ? -1 : 0));
}

/** 소감문 전체 읽기 (rowNum 포함, 서버 내부용). 피드백·교사시점 열이 없으면 빈 값으로 둡니다. */
function readReflections_() {
  const t = getTable_('학생소감문');
  const tz = getSs_().getSpreadsheetTimeZone();
  const textAt = (row, name) => {
    const idx = t.col[name];
    return idx === undefined || row[idx] == null ? '' : String(row[idx]);
  };
  const list = [];
  t.rows.forEach((r, i) => {
    const item = {
      rowNum: i + 2,
      uniqueId: toText_(r[t.col['ID']]),
      timestamp: formatDateTime_(r[t.col['제출일시']], tz),
      activity: toText_(r[t.col['창체활동']]),
      date: formatDate_(r[t.col['날짜']], tz),
      check: toText_(r[t.col['체크']]),
      studentId: normalizeId_(r[t.col['학번']]),
      content: textAt(r, '소감문'),
      feedback: textAt(r, '피드백'),
      teacherView: textAt(r, '교사시점')
    };
    if (item.uniqueId || item.content) list.push(item);
  });
  return { table: t, list: list };
}

/** 정렬: 날짜 최신순, 같은 날짜면 나중에 적힌 행이 위 */
function byDateDesc_(a, b) {
  if (a.date !== b.date) return a.date < b.date ? 1 : -1;
  return b.rowNum - a.rowNum;

/** 세션 만들기: 토큰(무작위 UUID)을 키로 캐시에 역할 정보를 저장합니다. */
function createSession_(data) {
  const token = Utilities.getUuid();
  CacheService.getScriptCache().put(SESSION_PREFIX + token, JSON.stringify(data), SESSION_TTL_SEC);
  return token;
}

/**
 * 세션 확인: 토큰이 없거나 만료되면 'SESSION_EXPIRED' 오류를 던집니다.
 * (브라우저는 이 오류를 받으면 로그인 화면으로 돌아갑니다)
 * role을 넘기면 그 역할이 아닐 때 거부합니다.
 */
function requireSession_(token, role) {
  const cache = CacheService.getScriptCache();
  const key = SESSION_PREFIX + String(token || '');
  const raw = token ? cache.get(key) : null;
  if (!raw) throw new Error('SESSION_EXPIRED');
  const session = JSON.parse(raw);
  if (role && session.role !== role) throw new Error('이 기능을 쓸 권한이 없어요.');
  cache.put(key, raw, SESSION_TTL_SEC);   // 사용할 때마다 유지 시간 연장
  return session;
}

/** 여러 사람이 동시에 저장해도 데이터가 꼬이지 않도록 스크립트 잠금을 걸고 실행합니다. */
function withLock_(fn, waitMs) {
  const lock = LockService.getScriptLock();
  if (!lock.tryLock(waitMs || 15000)) {
    throw new Error('지금 저장하는 사람이 많아요. 잠시 후 다시 시도하세요.');
  }
  try {
    return fn();
  } finally {
    lock.releaseLock();
  }
}

/** 마스킹: 비밀번호나 짧은 값은 길이까지 숨기고, 긴 키는 앞뒤 4자만 보여 줍니다. (예: AIza••••••••4f2c) */
function maskValue_(value, type) {
  const v = String(value || '');
  if (!v) return '';
  if (type === 'password' || v.length < 12) return '••••••••';
  return v.slice(0, 4) + '••••••••' + v.slice(-4);
}

/** 날짜 값을 'yyyy-MM-dd' 문자열로 (시트의 시간대 기준). 2026.3.12 같은 텍스트 날짜도 맞춰 줍니다. */
function formatDate_(value, tz) {
  if (value === '' || value == null) return '';
  if (Object.prototype.toString.call(value) === '[object Date]') {
    return isNaN(value.getTime()) ? '' : Utilities.formatDate(value, tz || getSs_().getSpreadsheetTimeZone(), 'yyyy-MM-dd');
  }
  const s = String(value).trim();
  const m = s.match(/^(\d{4})\s*[.\-\/]\s*(\d{1,2})\s*[.\-\/]\s*(\d{1,2})/);
  return m ? m[1] + '-' + ('0' + m[2]).slice(-2) + '-' + ('0' + m[3]).slice(-2) : s;
}

/** 제출일시 표시용 문자열 */
function formatDateTime_(value, tz) {
  if (Object.prototype.toString.call(value) === '[object Date]') {
    return isNaN(value.getTime()) ? '' : Utilities.formatDate(value, tz, 'yyyy-MM-dd HH:mm');
  }
  return toText_(value);
}

/** 값을 앞뒤 공백 없는 문자열로 */
function toText_(value) {
  return value == null ? '' : String(value).trim();
}

/** 학번 정리: 숫자로 저장된 1101도 '1101' 문자열로 맞춥니다. */
function normalizeId_(value) {
  if (value == null) return '';
  if (typeof value === 'number') return String(Math.round(value));
  return String(value).trim();
}

/**
 * 시트에 글을 쓸 때 수식·숫자·날짜로 바뀌지 않게 보호합니다.
 * 예) '=IMPORTXML(...)'(수식 주입), '- 느낀 점'(#ERROR!), '2026.3.12'(날짜로 변환) → 맨 앞에 ' 를 붙여 글자로 저장
 */
function safeText_(value) {
  const s = value == null ? '' : String(value);
  const risky = /^[=+\-@']/.test(s) ||
    /^\s*[\d.,]+\s*%?\s*$/.test(s) ||
    /^\s*\d{1,4}\s*[.\-\/]\s*\d{1,2}(\s*[.\-\/]\s*\d{1,4})?\.?\s*$/.test(s) ||
    /^\s*(true|false)\s*$/i.test(s);
  return risky ? '\'' + s : s;
}

/** 텍스트 서식을 지정한 뒤 값을 씁니다. (학번·비밀번호·ID의 앞자리 0 보존) */
function setTextCell_(range, value) {
  range.setNumberFormat('@').setValue(String(value));
  return range;
}

/** base가 이미 쓰였으면 _2, _3을 붙여 고유한 ID를 만듭니다. */
function uniqueId_(base, used) {
  let id = base;
  let n = 2;
  while (used[id]) id = base + '_' + (n++);
  return id;
}

/**
 * 받침에 맞는 조사를 고릅니다. (예: josa_('비밀번호', '을/를') → '를', josa_('학번', '으로/로') → '으로')
 * '으로/로'는 받침이 ㄹ이면 '로'를 씁니다. (예: '서울로')
 */
function josa_(word, pair) {
  const parts = pair.split('/');
  const w = String(word);
  const code = w.charCodeAt(w.length - 1);
  if (code < 0xAC00 || code > 0xD7A3) return parts[1];
  const batchim = (code - 0xAC00) % 28;
  if (pair === '으로/로') return batchim === 0 || batchim === 8 ? parts[1] : parts[0];
  return batchim === 0 ? parts[1] : parts[0];
}

/** 열 번호 → 열 문자 (1 → A, 27 → AA) */
function columnLetter_(n) {
  let s = '';
  while (n > 0) {
    const m = (n - 1) % 26;
    s = String.fromCharCode(65 + m) + s;
    n = Math.floor((n - 1) / 26);
  }
  return s;
}

  /** '2026-03-12' → '3월 12일 (목)' */
  function formatDateKo(dateStr) {
    const m = String(dateStr).match(/^(\d{4})-(\d{2})-(\d{2})$/);
    if (!m) return String(dateStr);
    const day = new Date(Number(m[1]), Number(m[2]) - 1, Number(m[3])).getDay();
    return `${Number(m[2])}월 ${Number(m[3])}일 (${WEEKDAYS[day]})`;
  }

  function setBtnBusy(btn, busy, busyText) {

  /** google.script.run을 Promise로 감싸서 await로 쓸 수 있게 합니다. */
  function callServer(fnName, ...args) {
    return new Promise((resolve, reject) => {
      google.script.run.withSuccessHandler(resolve).withFailureHandler(reject)[fnName](...args);
    });
  }

  /**
   * 서버 호출 + 로딩 표시 + 공통 오류 처리
   * 오류가 나면 모달로 안내하고 null을 돌려주므로, 호출한 쪽은 `if (!res) return;`만 쓰면 됩니다.
   */
  async function request(fnName, args) {
    setLoading(true);
    try {
      return await callServer(fnName, ...(args || []));
    } catch (err) {
      const msg = String((err && err.message) || err || '').replace(/^(Error|Exception):\s*/, '');
      if (msg.indexOf('SESSION_EXPIRED') > -1) handleSessionExpired();

      return null;
    } finally {
      setLoading(false);
    }
  }

  const BTN_VARIANT = { primary: 'btn-primary', danger: 'btn-danger', ghost: 'btn-ghost', yellow: 'btn-yellow' };

  /**
   * 모달을 열고, 누른 버튼의 value로 끝나는 Promise를 돌려줍니다.
   *  - title, message(글자), html(입력칸 등), iconHtml(위쪽 그림), center(가운데 정렬)
   *  - buttons: [{ text, value, variant }]  (마지막 버튼이 주요 버튼)
   *  - dismissValue: 바깥을 누르거나 ESC로 닫을 때의 값
   *  - beforeClose(value): false를 돌려주면 닫지 않습니다. (입력 검사, 서버 저장에 사용)
   */
  function openModal(o) {
    o = Object.assign({
      title: '', message: '', html: '', iconHtml: '', center: false, wide: false, locked: false,
      buttons: [{ text: '확인', value: true, variant: 'primary' }], dismissValue: null, beforeClose: null
    }, o);
    if (modalState) { const prev = modalState; modalState = null; prev.resolve(null); }

    const panel = $('modalPanel');
    panel.classList.toggle('text-center', o.center);
    panel.classList.toggle('max-w-sm', !o.wide);
    panel.classList.toggle('max-w-2xl', o.wide === true);
    panel.classList.toggle('max-w-4xl', o.wide === 'xl');
    $('modalIcon').innerHTML = o.iconHtml;
    $('modalIcon').classList.toggle('hidden', !o.iconHtml);
    $('modalTitle').textContent = o.title;
    $('modalMessage').textContent = o.message;
    $('modalMessage').classList.toggle('hidden', !o.message);
    $('modalBody').innerHTML = o.html;
    renderModalButtons(o.buttons);
    // 글자 입력칸에서 Enter를 누르면 주요(마지막) 버튼을 누른 것으로 처리
    $('modalBody').querySelectorAll('input:not([type="checkbox"]):not([data-enter="off"])').forEach(input => {
      input.addEventListener('keydown', e => {
        if (e.key === 'Enter') { e.preventDefault(); $('modalButtons').lastElementChild.click(); }
      });
    });

    $('modalRoot').classList.remove('hidden');
    $('modalRoot').classList.add('flex');
    return new Promise(resolve => {
      modalState = { resolve: resolve, beforeClose: o.beforeClose, dismissValue: o.dismissValue, locked: o.locked };
      setTimeout(() => {
        const target = $('modalBody').querySelector('input:not([disabled]), select:not([disabled]), textarea:not([disabled])') || $('modalButtons').lastElementChild;
        if (target) target.focus();
      }, 60);
    });
  }

  function renderModalButtons(buttons) {
    const wrap = $('modalButtons');
    wrap.innerHTML = '';
    buttons.forEach(b => {
      const el = document.createElement('button');
      el.type = 'button';
      el.className = `btn flex-1 py-3 ${BTN_VARIANT[b.variant] || 'btn-ghost'}`;
      el.textContent = b.text;
      el.addEventListener('click', () => closeModal(b.value));
      wrap.appendChild(el);
    });
  }

  /** 열려 있는 모달의 제목·버튼·잠금 상태를 바꿉니다. (AI 진행 화면처럼 모달을 연 채로 내용이 바뀔 때) */
  function updateModal(o) {
    if (!modalState) return;
    if (o.title !== undefined) $('modalTitle').textContent = o.title;
    if (o.buttons) renderModalButtons(o.buttons);
    if (o.locked !== undefined) modalState.locked = o.locked;
    if (o.beforeClose !== undefined) modalState.beforeClose = o.beforeClose;
  }

  async function closeModal(value) {
    const state = modalState;
    if (!state) return;
    if (state.beforeClose && value !== false && value !== null) {
      const buttons = Array.from($('modalButtons').querySelectorAll('button'));
      buttons.forEach(b => { b.disabled = true; });
      let pass;
      try { pass = await state.beforeClose(value); }
      finally { buttons.forEach(b => { b.disabled = false; }); }
      if (pass === false || modalState !== state) return;   // 검사 실패, 또는 그사이 다른 모달이 열림
    }
    modalState = null;
    $('modalRoot').classList.add('hidden');
    $('modalRoot').classList.remove('flex');
    state.resolve(value);
  }

  // ───────── 학번·비밀번호 기억하기 (이 브라우저에만 저장) ─────────
  /**
   * 저장 형식: {id, pw}를 글자마다 섞어 16진수로 바꿔 둡니다.
   * 암호화가 아니라, 브라우저 저장소를 열어 봤을 때 비밀번호가 그대로 보이지 않게 하는 정도예요.
   * 그래서 공용 컴퓨터에서는 켜지 말라고 안내합니다.
   */
  function packLogin(data) {
    const s = JSON.stringify(data);
    let out = '';
    for (let i = 0; i < s.length; i++) out += (s.charCodeAt(i) ^ (0x5A + i % 11)).toString(16).padStart(4, '0');
    return out;
  }

  function unpackLogin(raw) {
    let s = '';
    for (let i = 0; i + 4 <= raw.length; i += 4) s += String.fromCharCode(parseInt(raw.slice(i, i + 4), 16) ^ (0x5A + (i / 4) % 11));
    const data = JSON.parse(s);
    return data && typeof data.id === 'string' ? { id: data.id, pw: String(data.pw || '') } : null;
  }

  /** 기억해 둔 정보 읽기 (없거나 내용이 깨졌으면 null) */
  function readRemembered() {
    try {
      const raw = localStorage.getItem(REMEMBER_KEY);
      return raw ? unpackLogin(raw) : null;
    } catch (e) {
      return null;
    }
  }

  /** 기억해 두기 (브라우저가 저장을 막으면 false) */
  function writeRemembered(id, pw) {
    try { localStorage.setItem(REMEMBER_KEY, packLogin({ id: id, pw: pw })); return true; }
    catch (e) { return false; }
  }

  async function login() {
    const isAdmin = loginRole === 'admin';
    const id = isAdmin ? ADMIN_LOGIN_ID : $('loginId').value.trim();
    const pw = $('loginPw').value;
    if (!id || !pw) {
      return showAlert(isAdmin ? '교사 비밀번호를 입력하세요.' : '학번과 비밀번호를 입력하세요.', { title: '비어 있는 칸이 있어요' });
    }

    const btn = $('loginBtn');
    setBtnBusy(btn, true, '확인하는 중');
    const res = await request('verifyLogin', [id, pw]);
    setBtnBusy(btn, false);
    if (!res) return;
    if (!res.success) {
      // 기억해 둔 비밀번호가 더는 맞지 않으면(선생님이 초기화한 경우 등) 그 값은 지웁니다.
      const saved = !isAdmin ? readRemembered() : null;
      if (saved && saved.pw === pw) clearRemembered();
      return showAlert(res.message, { title: '로그인하지 못했어요' });
    }

    $('loginPw').value = '';
    sessionToken = res.token;
    if (res.role === 'admin') {
      showPage('page-admin');
      loadAdminData();
      return;
    }

    currentStudent = { id: res.studentId };
    if ($('rememberMe').checked) {
      if (!writeRemembered(res.studentId, pw)) showToast('이 브라우저에서는 로그인 정보를 기억할 수 없어요.', true);
    } else {
      clearRemembered();
    }
    proceedStudentLogin();
    if (res.isDefault) {
      const change = await showConfirm('아직 초기 비밀번호를 쓰고 있어요. 다른 사람이 내 학번으로 글을 내지 못하도록 지금 바꿀까요?', {
        title: '비밀번호를 바꿔 주세요', confirmText: '지금 바꾸기', cancelText: '다음에'
      });
      if (change) openPwModal(true);
    }
  }

  /** 다시 로그인한 같은 학생에게 쓰던 글을 되돌려 줍니다. */
  function restoreDraft() {
    if (!pendingDraft) return;
    const draft = pendingDraft;
    pendingDraft = null;
    if (draft.studentId !== currentStudent.id) return;
    const idx = draft.uniqueId ? myReflections.findIndex(r => r.uniqueId === draft.uniqueId) : -1;
    if (idx > -1) editItem(idx);
    $('selectDate').value = draft.date;
    autoFillActivity();
    $('inputContent').value = draft.content;
    updateCharCount();
    showToast('쓰던 글을 되살렸어요.');
  }

  function renderMyProgress() {
    const dates = new Set(activityData.map(a => a.date));
    const done = new Set(myReflections.map(r => r.date).filter(d => dates.has(d))).size;
    const total = activityData.length;
    $('myProgressText').textContent = `${done} / ${total}`;
    $('myProgressBar').style.width = total ? `${Math.round(done / total * 100)}%` : '0%';
    $('myCount').textContent = myReflections.length;
    const feedbackCount = myReflections.filter(r => r.feedback).length;
    $('myFeedbackBadge').textContent = `피드백 ${feedbackCount}`;
    $('myFeedbackBadge').classList.toggle('hidden', !feedbackCount);
  }

  /** 활동 선택 목록 만들기. extra: 목록에서 지워진 활동의 글을 고칠 때 임시로 넣는 항목 */
  function renderDateOptions(extra) {
    const select = $('selectDate');
    const keep = select.value;
    const submitted = new Set(myReflections.map(r => r.date));
    let html = '<option value="">활동을 고르세요</option>';
    activityData.forEach(a => {
      html += `<option value="${esc(a.date)}">[${esc(a.date.replace(/-/g, '.'))}] ${esc(a.activity)}${submitted.has(a.date) ? ' (제출함)' : ''}</option>`;
    });
    if (extra && !activityData.some(a => a.date === extra.date)) {
      html += `<option value="${esc(extra.date)}">[${esc(extra.date.replace(/-/g, '.'))}] ${esc(extra.activity)} (목록에서 빠진 활동)</option>`;
    }
    select.innerHTML = html;
    select.value = keep;
    if (select.value !== keep) select.value = '';
  }

  function autoFillActivity() {
    const date = $('selectDate').value;
    const editingId = $('editUniqueId').value;
    const matched = activityData.find(a => a.date === date);
    const editing = editingId ? myReflections.find(r => r.uniqueId === editingId) : null;
    $('inputActivity').value = matched ? matched.activity : (editing && editing.date === date ? editing.activity : '');
    const dup = date ? myReflections.find(r => r.date === date && r.uniqueId !== editingId) : null;
    $('dupNotice').classList.toggle('hidden', !dup);
  }

  async function submitReflection() {
    const date = $('selectDate').value;
    const content = $('inputContent').value;
    const uniqueId = $('editUniqueId').value;
    if (!date) return showAlert('소감문을 쓸 활동을 먼저 고르세요.', { title: '활동을 고르지 않았어요' });
    if (!content.trim()) return showAlert('소감문 내용을 입력하세요.', { title: '내용이 비어 있어요' });
    if (myReflections.some(r => r.date === date && r.uniqueId !== uniqueId)) return offerEditDuplicate(date);

    const ok = await showConfirm(uniqueId ? '고친 내용으로 저장할까요?' : '이 소감문을 제출할까요? 제출한 뒤에도 고칠 수 있어요.', {
      title: uniqueId ? '수정한 내용 저장' : '소감문 제출', confirmText: uniqueId ? '저장하기' : '제출하기'
    });
    if (!ok) return;

    const btn = $('submitBtn');
    setBtnBusy(btn, true, uniqueId ? '저장하는 중' : '제출하는 중');
    const res = await request('saveReflection', [sessionToken, { date: date, content: content, uniqueId: uniqueId }]);
    setBtnBusy(btn, false);
    if (!res) return;   // 실패해도 쓴 내용은 입력칸에 그대로 남아 있습니다.
    if (!res.success) {
      if (res.duplicate) { await loadStudentData(); return offerEditDuplicate(date); }
      return showAlert(res.message, { title: '저장하지 못했어요' });
    }

    const activity = $('inputActivity').value;
    resetForm();
    if (uniqueId) showToast(res.message);
    else showStampModal('제출했어요', `${formatDateKo(date)} ${activity}`);
    moveTab('list');
    loadStudentData();
  }

    if (idx > -1) editItem(idx);
  }

      return;
    }
    const total = allStudentsList.length;
    box.innerHTML = activityData.map((a, i) => {
      const done = countSubmitted(a.date);
      const pct = total ? Math.round(done / total * 100) : 0;
      const active = !!currentDetail && currentDetail.date === a.date;
      return `
        <button type="button" onclick="viewActivityDetail(${i})" aria-pressed="${active}"
          class="w-full rounded-lg border px-3 py-2.5 text-left transition focus-visible:outline-none focus-visible:ring-4 focus-visible:ring-chalk-yellow/70 ${active ? 'border-board bg-board text-chalk' : 'border-line bg-white hover:border-board/50'}">
          <div class="flex items-center justify-between gap-2">
            <span class="text-xs ${active ? 'text-chalk/80' : 'text-ink-muted'}">${esc(formatDateKo(a.date))}</span>
            <span class="text-xs font-bold ${active ? 'text-chalk-yellow' : 'text-board'}">${done}/${total}</span>
          </div>
          <div class="mt-0.5 truncate text-sm font-bold">${esc(a.activity)}</div>
          <div class="mt-2 h-1 overflow-hidden rounded-full ${active ? 'bg-black/25' : 'bg-page'}">
            <div class="h-full rounded-full ${active ? 'bg-chalk-yellow' : 'bg-board'}" style="width:${pct}%"></div>
          </div>
        </button>`;
    }).join('');
  }

  function viewActivityDetail(index) {
    const act = activityData[index];
    if (!act) return;
    currentDetail = act;
    detailFilter = 'all';
    selectedIds = new Set();
    $('filterId').value = '';
    renderActivityTags();
    renderDetailTable();
    if (window.innerWidth < 1024) $('adminTableTitle').scrollIntoView({ behavior: 'smooth', block: 'start' });
  }

  function setDetailFilter(mode) {
    detailFilter = mode;
    renderDetailTable();
  }

  /** 활동 하나를 골랐을 때: 명단 전체를 기준으로 제출/미제출과 피드백을 표시 */
  function renderDetailTable() {
    const act = currentDetail;
    $('adminTableTitle').textContent = `${formatDateKo(act.date)} ${act.activity}`;

    const roster = new Set(allStudentsList);
    const records = adminAllData.filter(r => r.date === act.date);
    const rows = allStudentsList.map(id => ({ id: id, record: records.find(r => r.studentId === id) || null, outside: false }));
    // 명단에 없는 학번(전학 등)의 글도 빠뜨리지 않고 아래에 보여 줍니다.
    records.filter(r => !roster.has(r.studentId)).forEach(r => rows.push({ id: r.studentId, record: r, outside: true }));

    const total = allStudentsList.length;
    const done = rows.filter(r => r.record && !r.outside).length;
    $('submitStats').textContent = `${done} / ${total}명 제출 (${total ? Math.round(done / total * 100) : 0}%)`;

    const counts = {
      all: rows.length,
      done: rows.filter(r => r.record).length,
      none: rows.filter(r => !r.record).length,
      nofb: rows.filter(r => r.record && !r.record.feedback).length,
      notv: rows.filter(r => r.record && !r.record.teacherView).length
    };
    const labels = { all: '전체', done: '제출', none: '미제출', nofb: '피드백 전', notv: '변환 전' };
    const filterBox = $('detailFilter');
    filterBox.classList.remove('hidden');
    filterBox.classList.add('flex');
    filterBox.innerHTML = Object.keys(labels).map(k => `
      <button type="button" onclick="setDetailFilter('${k}')" aria-pressed="${detailFilter === k}"
        class="btn btn-sm ${detailFilter === k ? 'btn-primary' : 'btn-ghost'}">${labels[k]} ${counts[k]}</button>`).join('');

    const visible = rows.filter(r =>
      detailFilter === 'all' ||
      (detailFilter === 'done' && r.record) ||
      (detailFilter === 'none' && !r.record) ||
      (detailFilter === 'nofb' && r.record && !r.record.feedback) ||
      (detailFilter === 'notv' && r.record && !r.record.teacherView));
    tableRecords = visible.filter(r => r.record).map(r => r.record);
    selectedIds = new Set(tableRecords.map(r => r.uniqueId).filter(id => selectedIds.has(id)));   // 안 보이는 글은 선택에서 뺌

    $('adminTableHeader').innerHTML = `
      <th class="th w-10">${selectAllHtml()}</th>
      <th class="th w-20">학번</th><th class="th w-16 text-center">제출</th>
      <th class="th w-20 whitespace-nowrap text-center">학생 체크</th><th class="th">소감문과 피드백</th>`;

    const tbody = document.querySelector('#adminTable tbody');
    if (!visible.length) {
      const emptyText = { none: '모든 학생이 제출했어요.', nofb: '피드백을 기다리는 글이 없어요.', notv: '교사 시점으로 바꿀 글이 없어요.' }[detailFilter] || '해당하는 학생이 없어요.';
      tbody.innerHTML = `<tr><td colspan="5" class="td py-12 text-center text-ink-muted">${emptyText}</td></tr>`;
      renderBulkBar();
      return;
    }
    tbody.innerHTML = visible.map(r => r.record ? `
      <tr>
        ${selectCell(r.record)}
        <td class="td font-bold">${r.outside
          ? `<span class="text-stamp">${esc(r.id || '학번 없음')}</span><div class="text-xs font-normal text-stamp">명단에 없음</div>`
          : esc(r.id)}</td>
        <td class="td text-center"><span class="stamp">제출</span></td>
        <td class="td text-center font-bold text-board">${r.record.check === 'O' ? '✓' : ''}</td>
        ${contentCell(r.record)}
      </tr>` : `
      <tr class="bg-page/40">
        <td class="td"></td>
        <td class="td text-ink-muted">${esc(r.id)}</td>
        <td class="td text-center"><span class="stamp-empty">미제출</span></td>
        <td class="td text-center text-ink-muted">-</td>
        <td class="td text-ink-muted">아직 내지 않았어요.</td>
      </tr>`).join('');
    renderBulkBar();
  }

  // ───────── 표에서 글 선택하기 ─────────
  function selectAllHtml() {
    const all = tableRecords.length > 0 && tableRecords.every(r => selectedIds.has(r.uniqueId));
    return `<input type="checkbox" class="h-4 w-4 cursor-pointer accent-[#24493D]" aria-label="표에 보이는 글 모두 선택"
      ${all ? 'checked' : ''} ${tableRecords.length ? '' : 'disabled'} onchange="toggleSelectAll(this.checked)">`;
  }

  /** 체크박스 칸: tableRecords의 번호로 글을 가리킵니다. (학번·내용에 따옴표가 있어도 안전) */
  function selectCell(rec) {
    const i = tableRecords.indexOf(rec);
    return `<td class="td"><input type="checkbox" class="h-4 w-4 cursor-pointer accent-[#24493D]" aria-label="이 글 선택"
      ${selectedIds.has(rec.uniqueId) ? 'checked' : ''} onchange="toggleSelect(${i}, this.checked)"></td>`;
  }

  function toggleSelect(index, on) {
    const rec = tableRecords[index];
    if (!rec) return;
    if (on) selectedIds.add(rec.uniqueId);
    else selectedIds.delete(rec.uniqueId);
    renderBulkBar();
  }

  function toggleSelectAll(on) {
    tableRecords.forEach(r => { if (on) selectedIds.add(r.uniqueId); else selectedIds.delete(r.uniqueId); });
    renderCurrentTable();
  }

  /** 학생이 스스로 '체크'한 글만 골라 선택합니다. */
  function selectStudentChecked() {
    const checked = tableRecords.filter(r => r.check === 'O');
    if (!checked.length) return showToast('이 표에는 학생이 체크한 글이 없어요.', true);
    selectedIds = new Set(checked.map(r => r.uniqueId));
    renderCurrentTable();
    showToast(`학생이 체크한 글 ${checked.length}개를 선택했어요.`);
  }

  function clearSelection() {
    selectedIds = new Set();
    renderCurrentTable();
  }

  function renderBulkBar() {
    const bar = $('bulkBar');
    const show = tableRecords.length > 0;
    bar.classList.toggle('hidden', !show);
    bar.classList.toggle('flex', show);
    const count = tableRecords.filter(r => selectedIds.has(r.uniqueId)).length;
    $('selectedCount').textContent = `${count}개 선택`;
    $('aiBulkBtn').disabled = count === 0;
    $('aiTeacherViewBtn').disabled = count === 0;
    const head = document.querySelector('#adminTableHeader input[type="checkbox"]');
    if (head) head.checked = show && count === tableRecords.length;
  }

  // ───────── 피드백 쓰기 ─────────
  /** 소감문 칸: 학생 글 바로 아래에 피드백·교사 시점 글과 쓰기/고치기 버튼을 붙여, 어느 글에 대한 것인지 한눈에 보이게 합니다. */
  function contentCell(rec) {
    const i = tableRecords.indexOf(rec);
    const boxes = [];
    const writeButtons = [];
    Object.keys(TEXT_FIELDS).forEach(field => {
      const f = TEXT_FIELDS[field];
      if (rec[field]) {
        boxes.push(`
        <div class="mt-2 flex flex-wrap items-start gap-2 rounded-lg border-l-4 ${f.box} px-3 py-2">
          <div class="min-w-0 flex-1 basis-56">
            <p class="text-xs font-bold ${f.labelColor}">${f.label}<span class="ml-1.5 font-medium text-ink-muted">${f.note}</span></p>
            <p class="mt-0.5 whitespace-pre-wrap break-words leading-relaxed">${esc(rec[field])}</p>
          </div>
          <button type="button" onclick="openTextModal('${field}', ${i})" aria-label="${f.label} 고치기" class="btn btn-ghost btn-sm shrink-0 self-start">고치기</button>
        </div>`);
      } else {
        writeButtons.push(`<button type="button" onclick="openTextModal('${field}', ${i})" class="btn btn-ghost btn-sm">${f.writeLabel}</button>`);
      }
    });
    return `<td class="td">
      <p class="whitespace-pre-wrap break-words leading-relaxed">${esc(rec.content)}</p>
      ${boxes.join('')}
      ${writeButtons.length ? `<div class="mt-2 flex flex-wrap gap-1.5">${writeButtons.join('')}</div>` : ''}
    </td>`;
  }

  // ───────── AI 일괄 작업 (피드백 생성 · 교사 시점 변환) ─────────

    const cfg = AI_MODES[mode];

  }

  function saveAiPrompt(mode, text) {
    try { localStorage.setItem(AI_MODES[mode].promptKey, text); } catch (e) { /* 기억하지 못해도 이번 작업에는 영향 없음 */ }
  }

  /** 예상 시간: 글 하나에 (요청 간격 + AI 응답 약 3초) */

    const minutes = Math.ceil(count * (aiIntervalSec + 3) / 60);
    return minutes <= 1 ? '1분 이내' : `약 ${minutes}분`;
  }

  /**
   * AI 창의 '프롬프트 보관함' (구글 시트 [프롬프트]에 보관)
   *  - 고르면 입력칸에 불러오고, 이름을 붙여 저장하면 같은 이름은 덮어쓰고 새 이름은 새 줄로 추가합니다.
   *  - 확인 창을 따로 띄우면 AI 창이 닫히므로, 안내는 창 안의 글줄로 보여 주고 삭제는 두 번 눌러야 합니다.
   */
  function setupPromptLibrary(mode) {
    const box = { prompts: [], ready: false, deleteArmed: false, timer: null };
    const select = $('promptSelect');
    const nameInput = $('promptName');
    const saveBtn = $('promptSave');
    const deleteBtn = $('promptDelete');
    const note = $('promptNote');

    const setNote = (text, tone) => {
      note.textContent = text;
      note.className = 'mt-1.5 text-xs ' + (tone === 'error' ? 'font-semibold text-stamp' : tone === 'ok' ? 'font-semibold text-board' : 'text-ink-muted');
    };
    const indexOfName = name => box.prompts.findIndex(p => p.name === name.trim());
    const disarmDelete = () => {
      box.deleteArmed = false;
      clearTimeout(box.timer);
      deleteBtn.textContent = '삭제';
    };
    const refreshButtons = () => {
      const name = nameInput.value.trim();
      saveBtn.disabled = !box.ready || !name;
      saveBtn.textContent = name && indexOfName(name) > -1 ? '같은 이름에 덮어쓰기' : '보관함에 저장';
      deleteBtn.disabled = !box.ready || select.value === '';
    };
    const render = selectName => {

        : box.prompts.length ? `저장된 프롬프트 ${box.prompts.length}개 중 고르기` : '아직 저장된 프롬프트가 없어요';

        box.prompts.map((p, i) => `<option value="${i}">${esc(p.name)}${p.type === '공통' ? ' (공통)' : ''}</option>`).join('');
      select.disabled = !box.ready || !box.prompts.length;
      const index = selectName ? indexOfName(selectName) : -1;
      select.value = index > -1 ? String(index) : '';
      disarmDelete();
      refreshButtons();
    };
    const call = async (fn, ...args) => {
      try {
        return await callServer(fn, sessionToken, ...args);
      } catch (err) {
        const msg = errText(err);
        if (msg.indexOf('SESSION_EXPIRED') > -1) { handleSessionExpired(); return null; }
        setNote(msg || '서버와 연결하지 못했어요.', 'error');
        return null;
      }
    };
    const applyList = res => {
      box.ready = !!res.ready;
      box.prompts = res.prompts || [];
    };

    select.addEventListener('change', () => {
      disarmDelete();
      const p = box.prompts[Number(select.value)];
      if (select.value !== '' && p) {
        $('aiPrompt').value = p.text;
        nameInput.value = p.name;
        setNote(`'${p.name}' 프롬프트를 불러왔어요.${p.updatedAt ? ` (마지막 저장 ${p.updatedAt})` : ''}`, 'ok');
      }
      refreshButtons();
    });
    nameInput.addEventListener('input', refreshButtons);
    nameInput.addEventListener('keydown', e => {
      if (e.key !== 'Enter') return;
      e.preventDefault();
      if (!saveBtn.disabled) saveBtn.click();
    });

    saveBtn.addEventListener('click', async () => {
      const name = nameInput.value.trim();
      const text = $('aiPrompt').value.trim();
      if (!name) return setNote('보관함에 저장할 이름을 입력하세요.', 'error');
      if (!text) return setNote('프롬프트 내용을 입력하세요.', 'error');
      saveBtn.disabled = true;
      setNote('보관함에 저장하는 중이에요.');

      else setNote(res.message, 'error');

  /** 선택한 글을 한 개씩 서버로 보내고, AI에 보낸 뒤에는 [환경설정]의 요청 간격만큼 기다립니다. */
  async function runAiBatch(mode, ids, prompt, skipExisting) {
    const cfg = AI_MODES[mode];
    const job = { cancel: false };
    aiJob = job;
    const total = ids.length;
    const queue = ids.slice();
    const tries = {};
    const stats = { done: 0, skipped: 0, failed: [] };
    let fatalMessage = '';

    openModal({
      wide: true, locked: true,
      title: cfg.runningTitle,
      html: `
        <div class="mt-4">
          <div class="flex items-baseline justify-between gap-3 text-sm">
            <span id="aiStatus" class="font-semibold">준비하는 중</span>
            <strong id="aiCount" class="shrink-0">0 / ${total}</strong>
          </div>
          <div class="mt-2 h-2 overflow-hidden rounded-full bg-page">
            <div id="aiBar" class="h-full rounded-full bg-board transition-all duration-300" style="width:0%"></div>
          </div>
          <p class="mt-3 text-xs text-ink-muted">이 창을 닫거나 새로고침하면 멈춰요. 이미 저장된 글은 그대로 남아요.</p>
          <div id="aiResult" class="mt-4 hidden"></div>
        </div>`,
      buttons: [{ text: '중지', value: 'stop', variant: 'ghost' }],
      beforeClose: value => {
        if (value !== 'stop') return true;
        job.cancel = true;
        $('aiStatus').textContent = '지금 보낸 글까지만 처리하고 멈출게요';
        return false;
      }
    });

    const update = status => {
      const processed = stats.done + stats.skipped + stats.failed.length;
      if (status && !job.cancel) $('aiStatus').textContent = status;
      $('aiCount').textContent = `${processed} / ${total}`;
      $('aiBar').style.width = `${Math.round(processed / total * 100)}%`;
    };

    while (queue.length && !job.cancel) {
      const id = queue.shift();
      update(`AI가 ${cfg.label}을 쓰는 중이에요`);
      let res;
      try {
        res = await callServer('generateAiText', sessionToken, mode, [id], prompt, skipExisting);
      } catch (err) {
        const msg = errText(err);
        if (msg.indexOf('SESSION_EXPIRED') > -1) { aiJob = null; handleSessionExpired(); return; }
        fatalMessage = msg || '서버와 연결하지 못했어요.';
        queue.unshift(id);
        break;
      }
      if (!res.success) {
        fatalMessage = res.message;
        queue.unshift(id);
        break;
      }
      if (typeof res.intervalSec === 'number') aiIntervalSec = res.intervalSec;   // [환경설정]에서 바꾼 간격을 바로 반영
      let limited = false;
      res.results.forEach(r => {
        if (r.status === 'done') {
          stats.done++;
          const rec = adminAllData.find(x => x.uniqueId === r.uniqueId);
          if (rec) rec[cfg.field] = r.text;
        } else if (r.status === 'skipped') {
          stats.skipped++;
        } else if (r.fatal) {
          fatalMessage = r.message;
          queue.unshift(r.uniqueId);
        } else if (r.retryable && (tries[r.uniqueId] || 0) < AI_MAX_RETRY) {
          tries[r.uniqueId] = (tries[r.uniqueId] || 0) + 1;
          queue.push(r.uniqueId);
          limited = true;
        } else {
          stats.failed.push({ id: r.uniqueId, message: r.message });
        }
      });
      update();
      if (fatalMessage) break;
      if (!queue.length || !res.requested) continue;   // 남은 글이 없거나 AI에 보내지 않았으면(건너뜀) 기다리지 않음
      const wait = limited ? Math.max(AI_RETRY_WAIT_SEC, aiIntervalSec) : aiIntervalSec;
      if (wait > 0) {
        await aiWait(job, wait, sec => update(limited
          ? `요청이 몰려서 ${sec}초 기다렸다가 이어서 할게요`
          : `요청 간격을 지키는 중이에요 (${sec}초 뒤 다음 글)`));
      }
    }

    if (aiJob === job) aiJob = null;
    finishAiBatch(mode, { stats: stats, total: total, leftover: queue, fatalMessage: fatalMessage, cancelled: job.cancel });
  }

  async function aiWait(job, seconds, onTick) {
    for (let s = seconds; s > 0; s--) {
      if (job.cancel) return;
      onTick(s);
      await new Promise(resolve => setTimeout(resolve, 1000));
    }
  }

  /** AI 작업이 끝났을 때: 결과 요약을 보여 주고, 실패한 글은 다시 시도하기 쉽게 선택한 채로 둡니다. */
  function finishAiBatch(mode, o) {

    box.innerHTML = `

      ${failedIds.length ? `<ul class="mt-2 max-h-40 list-disc space-y-1 overflow-y-auto pl-5 text-sm">${o.stats.failed.map(f => `<li><b>${esc(label(f.id))}</b> ${esc(f.message)}</li>`).join('')}</ul>` : ''}
      ${failedIds.length || o.leftover.length ? `<p class="mt-2 text-xs text-ink-muted">실패했거나 처리하지 못한 글은 선택한 채로 남겨 뒀어요. 잠시 뒤 [${esc(cfg.buttonLabel)}] 버튼을 다시 누르면 이어서 할 수 있어요.</p>` : ''}`;

    selectedIds = new Set(failedIds.concat(o.leftover));
    updateModal({

  // ───────── 학생별 교사 시점 글 모아 보기 · 엑셀 받기 ─────────
  /**
   * 교사 시점 글이 있는 소감문을 학생별로 묶습니다.
   *  - 조건: 학번 앞부분(prefix), 활동 날짜 범위(from ~ to, 시작일·종료일 당일 포함, 비어 있으면 제한 없음)
   *  - 정렬: 명단 순서(명단에 없는 학번은 뒤에), 학생 안에서는 날짜순
   */
  function groupTeacherViews(filter) {
    const f = Object.assign({ prefix: '', from: '', to: '' }, filter);
    const order = new Map(allStudentsList.map((id, i) => [id, i]));
    const groups = new Map();
    adminAllData
      .filter(r => r.teacherView && r.teacherView.trim())
      .filter(r => !f.prefix || r.studentId.startsWith(f.prefix))
      .filter(r => (!f.from || r.date >= f.from) && (!f.to || r.date <= f.to))   // 날짜는 'YYYY-MM-DD' 글자라 크기 비교가 곧 날짜 비교
      .forEach(r => {
        if (!groups.has(r.studentId)) groups.set(r.studentId, []);
        groups.get(r.studentId).push(r);
      });
    return Array.from(groups.entries())
      .map(([id, items]) => ({ id: id, items: items.slice().sort((a, b) => a.date.localeCompare(b.date)) }))
      .sort((a, b) => {
        const oa = order.has(a.id) ? order.get(a.id) : Number.MAX_SAFE_INTEGER;
        const ob = order.has(b.id) ? order.get(b.id) : Number.MAX_SAFE_INTEGER;
        return oa !== ob ? oa - ob : a.id.localeCompare(b.id);
      });
  }

  /** '2026-03-01' → '2026.3.1' (기간 안내용) */
  function dotDateKo(date) {
    const m = /^(\d{4})-(\d{2})-(\d{2})$/.exec(date || '');
    return m ? `${m[1]}.${Number(m[2])}.${Number(m[3])}` : (date || '');
  }

  /** '2026-03-12' → '3월 12일' */
  function shortDateKo(date) {
    const m = /^(\d{4})-(\d{2})-(\d{2})$/.exec(date || '');
    return m ? `${Number(m[2])}월 ${Number(m[3])}일` : (date || '');
  }

  /** 교사 시점 글 하나를 한 줄로: 줄바꿈과 겹친 공백을 띄어쓰기 한 칸으로 바꿉니다. */
  function oneLine(text) {
    return String(text || '').replace(/\s+/g, ' ').trim();
  }

  /** 학생 한 명의 교사 시점 글을 날짜순으로 이어 붙입니다. (웹 표·복사·엑셀 공통: 활동 이름 없이, 글 사이는 띄어쓰기 한 칸) */
  function joinTeacherViews(items) {
    return items.map(r => oneLine(r.teacherView)).filter(Boolean).join(' ');

  /** 클립보드 복사: 새 방식이 막혀 있으면 예전 방식으로 한 번 더 시도합니다. */
  async function copyText(text) {
    try {
      if (navigator.clipboard && window.isSecureContext) { await navigator.clipboard.writeText(text); return true; }
    } catch (e) { /* 아래 방식으로 다시 시도 */ }
    const area = document.createElement('textarea');
    area.value = text;
    area.setAttribute('readonly', '');
    area.style.position = 'fixed';
    area.style.opacity = '0';
    document.body.appendChild(area);
    area.select();
    let copied = false;
    try { copied = document.execCommand('copy'); } catch (e) { copied = false; }
    area.remove();
    return copied;
  }

  /** 지금 창에 보이는 학생들의 교사 시점 글을 엑셀 파일로 내려받습니다. (고른 기간·학번 조건 그대로, 시트 2개: 학생별 모음, 활동별 상세) */

  function downloadFile(bytes, filename, mime) {

   * sheets: [{ name, columns: [{ header, width }], rows: [[셀 값, ...]] }]
   *  - 글자는 텍스트 셀(학번 앞자리 0 보존, 줄바꿈 표시), 숫자는 숫자 셀로 넣습니다.

  function buildXlsx(sheets) {
    const xml = v => String(v == null ? '' : v)
      .replace(/[\u0000-\u0008\u000B\u000C\u000E-\u001F]/g, '')   // XML에 넣을 수 없는 제어 문자 제거

    const colName = index => {
      let name = '';
      for (let n = index + 1; n > 0; n = Math.floor((n - 1) / 26)) name = String.fromCharCode(65 + (n - 1) % 26) + name;
      return name;
    };
    // 셀 모양 번호: 0 기본, 1 머리 줄(굵게·연녹색), 2 본문 글자(위쪽 정렬·줄바꿈), 3 본문 숫자(위쪽 정렬)
    const cell = (value, ref, header) => {
      if (!header && typeof value === 'number' && isFinite(value)) return `<c r="${ref}" s="3"><v>${value}</v></c>`;
      return `<c r="${ref}" t="inlineStr" s="${header ? 1 : 2}"><is><t xml:space="preserve">${xml(value)}</t></is></c>`;
    };

    //       XML 주소 속 슬래시 두 개를 코드에 그대로 쓰지 않고 조립합니다. (만들어지는 주소 값은 똑같아요)

  /** 압축하지 않는(store) ZIP 만들기: 파일마다 [로컬 헤더 + 내용], 끝에 [목록(중앙 디렉터리) + 끝 표시] */
  function zipStore(entries) {
    if (!zipStore.table) {
      zipStore.table = Array.from({ length: 256 }, (_, n) => {
        let c = n;
        for (let k = 0; k < 8; k++) c = c & 1 ? 0xEDB88320 ^ (c >>> 1) : c >>> 1;
        return c >>> 0;
      });
    }
    const crc32 = bytes => {
      let c = 0xFFFFFFFF;
      for (let i = 0; i < bytes.length; i++) c = zipStore.table[(c ^ bytes[i]) & 0xFF] ^ (c >>> 8);
      return (c ^ 0xFFFFFFFF) >>> 0;
    };
    const now = new Date();
    const dosTime = (now.getHours() << 11) | (now.getMinutes() << 5) | Math.floor(now.getSeconds() / 2);
    const dosDate = ((now.getFullYear() - 1980) << 9) | ((now.getMonth() + 1) << 5) | now.getDate();
    const encoder = new TextEncoder();
    const parts = [];
    const directory = [];
    let offset = 0;
    entries.forEach(entry => {
      const name = encoder.encode(entry.name);
      const crc = crc32(entry.data);
      const size = entry.data.length;
      const local = new DataView(new ArrayBuffer(30));
      local.setUint32(0, 0x04034b50, true);    // 로컬 헤더 표시
      local.setUint16(4, 20, true);            // 풀 때 필요한 버전
      local.setUint16(6, 0x0800, true);        // 파일 이름 UTF-8
      local.setUint16(8, 0, true);             // 압축 안 함
      local.setUint16(10, dosTime, true);
      local.setUint16(12, dosDate, true);
      local.setUint32(14, crc, true);
      local.setUint32(18, size, true);
      local.setUint32(22, size, true);
      local.setUint16(26, name.length, true);
      local.setUint16(28, 0, true);
      parts.push(new Uint8Array(local.buffer), name, entry.data);

      const central = new DataView(new ArrayBuffer(46));
      central.setUint32(0, 0x02014b50, true);  // 중앙 디렉터리 표시
      central.setUint16(4, 20, true);
      central.setUint16(6, 20, true);
      central.setUint16(8, 0x0800, true);
      central.setUint16(10, 0, true);
      central.setUint16(12, dosTime, true);
      central.setUint16(14, dosDate, true);
      central.setUint32(16, crc, true);
      central.setUint32(20, size, true);
      central.setUint32(24, size, true);
      central.setUint16(28, name.length, true);
      central.setUint32(42, offset, true);     // 이 파일의 로컬 헤더 위치
      directory.push(new Uint8Array(central.buffer), name);
      offset += 30 + name.length + size;
    });
    const directorySize = directory.reduce((n, part) => n + part.length, 0);
    const end = new DataView(new ArrayBuffer(22));
    end.setUint32(0, 0x06054b50, true);        // 끝 표시
    end.setUint16(8, entries.length, true);
    end.setUint16(10, entries.length, true);
    end.setUint32(12, directorySize, true);
    end.setUint32(16, offset, true);
    const all = parts.concat(directory, [new Uint8Array(end.buffer)]);
    const out = new Uint8Array(all.reduce((n, part) => n + part.length, 0));
    let pos = 0;
    all.forEach(part => { out.set(part, pos); pos += part.length; });
    return out;
  }

      <div class="mb-3">
        <div class="flex items-center justify-between text-xs font-bold text-ink-muted">
          <span>${onSummary ? '등록 현황 요약' : `${stepIndex + 1} / ${total} 단계`}</span>
          <span>${items.filter(i => i.registered).length}개 등록됨</span>
        </div>
        <div class="mt-1.5 h-1.5 overflow-hidden rounded-full bg-white ring-1 ring-line">
          <div class="h-full rounded-full bg-board transition-all duration-300" style="width:${pct}%"></div>
        </div>
      </div>`;
    $('wizardView').innerHTML = head + (onSummary ? summaryHtml() : stepHtml(items[stepIndex]));
    if (!onSummary) {
      bindField('propInput', items[stepIndex], 'propError', nextStep);
      setTimeout(() => { if ($('propInput')) $('propInput').focus(); }, 30);
    }
  }

  function stepHtml(item) {
    const isLast = stepIndex === items.length - 1;
    return `
      <div class="panel p-5">
        <div class="flex flex-wrap items-center gap-1.5">${statusBadges(item)}</div>
        <h2 class="mt-3 text-xl font-extrabold">${esc(item.label)}</h2>
        <p class="mt-1.5 text-sm leading-relaxed text-ink-muted">${esc(item.hint)}</p>
        ${item.docUrl ? `<a href="${esc(item.docUrl)}" target="_blank" rel="noopener" class="mt-2 inline-block text-sm font-bold text-board underline underline-offset-2">발급 페이지 새 창으로 열기</a>` : ''}
        ${item.registered ? `
          <div class="mt-4 rounded-lg bg-board-soft px-3 py-2.5 text-sm">
            지금 등록된 값 <code class="ml-1 font-bold tracking-widest">${esc(item.masked)}</code>
            <p class="mt-1 text-xs text-ink-muted">새 값을 넣으면 바뀌고, 비워 두고 [다음]을 누르면 지금 값을 그대로 써요.</p>
          </div>` : ''}
        <label for="propInput" class="field-label mt-4">${item.registered ? '새 값 (바꿀 때만 입력)' : '값 입력'}</label>
        ${inputHtml('propInput', item)}
        <p id="propError" class="mt-2 hidden text-sm font-semibold text-stamp"></p>
      </div>
      <div class="mt-4 flex items-center gap-2">
        <button type="button" onclick="prevStep()" class="btn btn-ghost" ${stepIndex === 0 ? 'disabled' : ''}>이전</button>
        <span class="flex-1"></span>
        ${item.required ? '' : '<button type="button" onclick="skipStep()" class="btn btn-ghost">건너뛰기</button>'}
        <button id="nextBtn" type="button" onclick="nextStep()" class="btn btn-primary">${isLast ? '저장하고 요약 보기' : '다음'}</button>
      </div>`;
  }

  /** [다음]: 값이 있으면 그 자리에서 바로 저장 → 창을 닫아도 여기까지는 유지됩니다. */
  async function nextStep() {
    const item = items[stepIndex];
    const input = $('propInput');
    const value = input.value.trim();
    if (!value) {
      if (item.required && !item.registered) return setFieldError('propError', '필수 항목이에요. 값을 입력해야 다음 단계로 넘어갈 수 있어요.');
      stepIndex++;
      return renderWizard();
    }
    const perr = patternError(item, value);
    if (perr) return setFieldError('propError', perr);

    const btn = $('nextBtn');
    setBusy(btn, true);
    try {
      const res = await call('saveAppProperty', item.key, value);
      if (!res.success) { setBusy(btn, false); return setFieldError('propError', res.message); }
      Object.assign(item, res.status);
      showToast(res.message);
      stepIndex++;
      renderWizard();
    } catch (e) {
      setBusy(btn, false);
      setFieldError('propError', errMsg(e));
    }
  }

  function skipStep() { stepIndex++; renderWizard(); }
  function prevStep() { if (stepIndex > 0) { stepIndex--; renderWizard(); } }
  function goStep(i) { mode = 'wizard'; stepIndex = i; render(); }

  function summaryHtml() {
    const missing = items.filter(i => i.required && !i.registered);
    return `
      <div class="panel p-5">
        <h2 class="text-xl font-extrabold">${missing.length ? '아직 등록하지 않은 필수 항목이 있어요' : '등록을 모두 마쳤어요'}</h2>
        <p class="mt-1.5 text-sm leading-relaxed text-ink-muted">${missing.length
          ? '필수 항목을 등록해야 웹 앱의 교사 화면에 들어갈 수 있어요.'
          : '웹 앱 로그인 화면에서 [교사]를 고르고 등록한 비밀번호로 들어가 보세요.'}</p>
        <ul class="mt-4 divide-y divide-line border-y border-line">
          ${items.map((item, i) => `
            <li class="flex flex-wrap items-center gap-2 py-3">
              <div class="min-w-0 flex-1">
                <div class="flex flex-wrap items-center gap-1.5"><span class="font-bold">${esc(item.label)}</span>${statusBadges(item)}</div>
                <p class="mt-0.5 text-xs text-ink-muted">${item.registered
                  ? `등록된 값 <code class="tracking-widest">${esc(item.masked)}</code>`
                  : (item.required ? '등록이 필요해요' : '등록하지 않으면 기본값을 써요')}</p>
                <p id="test-${esc(item.key)}" class="mt-1 hidden text-xs font-semibold"></p>
              </div>
              ${item.testable && item.registered ? `<button type="button" onclick="runTest('${esc(item.key)}', this)" class="btn btn-ghost btn-sm">연결 테스트</button>` : ''}
              <button type="button" onclick="goStep(${i})" class="btn btn-ghost btn-sm">${item.registered ? '바꾸기' : '등록하기'}</button>
            </li>`).join('')}
        </ul>
      </div>
      <div class="mt-4 flex items-center gap-2">
        <button type="button" onclick="prevStep()" class="btn btn-ghost">이전</button>
        <span class="flex-1"></span>
        <button type="button" onclick="finish()" class="btn btn-primary">완료</button>
      </div>`;
  }

  async function runTest(key, btn) {
    const box = $(`test-${key}`);
    setBusy(btn, true, '확인하는 중');
    try {
      const res = await call('testConnection', key);
      box.textContent = res.message;
      box.className = `mt-1 text-xs font-semibold ${res.success ? 'text-board' : 'text-stamp'}`;
    } catch (e) {
      box.textContent = errMsg(e);
      box.className = 'mt-1 text-xs font-semibold text-stamp';
    } finally {
      setBusy(btn, false);
    }
  }

  async function finish() {
    const missing = items.filter(i => i.required && !i.registered);
    if (missing.length) {
      const ok = await showConfirm(`아직 등록하지 않은 필수 항목: ${missing.map(m => m.label).join(', ')}\n이대로 닫으면 교사 화면에 들어갈 수 없어요.`, {
        title: '필수 항목이 남아 있어요', confirmText: '그래도 닫기', cancelText: '등록하러 가기', danger: true
      });
      if (!ok) return goStep(items.indexOf(missing[0]));
    }
    google.script.host.close();
  }

  // ---------------- 한 번에 보기 (목록) ----------------
  function renderList() {
    $('listView').innerHTML = items.map((item, i) => `
      <div class="panel p-4">
        <div class="flex flex-wrap items-center gap-1.5">
          <h2 class="mr-1 font-extrabold">${esc(item.label)}</h2>${statusBadges(item)}
        </div>
        <p class="mt-1 text-sm leading-relaxed text-ink-muted">${esc(item.hint)}</p>
        ${item.docUrl ? `<a href="${esc(item.docUrl)}" target="_blank" rel="noopener" class="mt-1 inline-block text-sm font-bold text-board underline underline-offset-2">발급 페이지 새 창으로 열기</a>` : ''}
        <p class="mt-2 text-xs text-ink-muted">지금 값: ${item.registered ? `<code class="font-bold tracking-widest">${esc(item.masked)}</code>` : '없음'}</p>
        <div class="mt-2 flex flex-wrap items-end gap-2">
          ${inputHtml(`listInput${i}`, item, 'min-w-[200px] flex-1')}
          <button id="listSave${i}" type="button" onclick="saveFromList(${i})" class="btn btn-primary h-[50px]">저장</button>
          <button type="button" onclick="deleteFromList(${i})" class="btn btn-ghost h-[50px] text-stamp" ${item.registered ? '' : 'disabled'}>삭제</button>
        </div>
        <p id="listError${i}" class="mt-2 hidden text-sm font-semibold text-stamp"></p>
      </div>`).join('');
    items.forEach((item, i) => bindField(`listInput${i}`, item, `listError${i}`, () => saveFromList(i)));
  }

  async function saveFromList(i) {
    const item = items[i];
    const value = $(`listInput${i}`).value.trim();
    if (!value) return setFieldError(`listError${i}`, '저장할 값을 입력하세요.');
    const perr = patternError(item, value);
    if (perr) return setFieldError(`listError${i}`, perr);
    const btn = $(`listSave${i}`);
    setBusy(btn, true, '저장 중');
    try {
      const res = await call('saveAppProperty', item.key, value);
      if (!res.success) { setBusy(btn, false); return setFieldError(`listError${i}`, res.message); }
      Object.assign(item, res.status);
      showToast(res.message);
      renderList();
    } catch (e) {
      setBusy(btn, false);
      showToast(errMsg(e), true);
    }
  }

  async function deleteFromList(i) {
    const item = items[i];
    const ok = await showConfirm(`등록한 ${item.label} 값을 삭제할까요?${item.required ? '\n필수 항목이라 삭제하면 교사 화면에 들어갈 수 없어요.' : ''}`, {
      title: '등록한 값 삭제', confirmText: '삭제', danger: true
    });
    if (!ok) return;
    try {
      const res = await call('deleteAppProperty', item.key);
      Object.assign(item, res.status);
      showToast(res.message);
      renderList();
    } catch (e) {
      showToast(errMsg(e), true);
    }
  }
