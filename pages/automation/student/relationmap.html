우리반 관계지도 앱

구글 스프레드시트와 연동하여 학생들의 교우 관계를 설문조사하고, 관계지도로 시각화하여 학급 경영에 활용하세요.

간단한 설문으로 교우 관계 파악

학생들이 학급 분위기 점수, 즐겁게 지내는 친구, 불편한 친구를 솔직하게 답할 수 있습니다. 답변은 선생님만 볼 수 있어 안심하고 참여할 수 있습니다.

학생 응답을 한눈에 확인

학생별 분위기 점수, 즐겁게 지내는 친구와 이유, 불편한 친구와 이유를 표로 빠르게 확인할 수 있습니다. 수정 권한 부여와 응답 엑셀 다운로드도 지원합니다.

관계 유형별 필터링으로 핵심 파악

즐거운 관계, 불편한 관계, 서로 친구만 보기 등 필터를 조합해 학급의 교우 관계 구조를 시각적으로 파악할 수 있습니다. 지난달과 비교 기능도 제공합니다.

개별 학생의 관계를 깊이 있게 살펴보기

관계지도에서 학생을 클릭하면 해당 학생이 고른 친구, 해당 학생을 고른 친구, 그리고 관계 이유까지 상세하게 확인할 수 있습니다.

세심한 관심이 필요한 학생 자동 알림

따돌림·속상함 등 민감한 키워드가 포함된 응답, 분위기를 낮게 매긴 학생, 선택받지 못한 학생, 미응답 학생을 자동으로 정리하여 보여 줍니다.

지난달과 비교하여 관계 변화 추이 파악

지난달 대비 새로 형성된 관계, 유지된 관계, 단절된 관계를 시각적으로 비교하여 학급 내 교우 관계의 역동적인 변화를 관찰할 수 있습니다.

학생별 지난달 대비 상세 변화 분석

학생을 클릭하면 지난달과 비교하여 어떤 친구를 새로 선택했는지, 상호 교류 상태가 어떻게 바뀌었는지 상세 내역을 명확하게 확인할 수 있습니다.

우리반 관계지도 앱 복사 및 배포 가이드

구글 시트 템플릿 복사하기
1
구글 시트 템플릿 내 드라이브로 복사하기

우측 상단의 [구글 시트 템플릿 복사하기] 버튼을 클릭한 후, 브라우저에 나타나는 [사본 만들기] 버튼을 누르면 본인의 구글 드라이브로 템플릿 시트와 앱 코드가 함께 복사됩니다.

2
구글 시트 상단 메뉴에서 DB 세팅 및 교사 비밀번호 등록

복사한 스프레드시트 상단 메뉴에서 [🌌 관계지도] > [🗂️ DB 세팅 및 초기화]를 실행하여 학생, 설문월, 관계응답, 제출기록 시트를 준비합니다.

  • [🌌 관계지도] > [🔐 환경설정]을 열어 웹 앱 교사 화면에 접속할 교사 비밀번호와 학생 초기 비밀번호(기본값 1234)를 등록합니다.
  • 학생 명단은 웹 앱의 [관리] 탭에서 [학생 추가] 또는 [명단 붙여넣기](학번 이름)로 손쉽게 등록할 수 있습니다.
3
웹 앱(Web App)으로 배포하기

스프레드시트 상단 메뉴에서 [확장 프로그램] > [Apps Script]를 클릭하여 스크립트 편집기 창을 엽니다.

  1. 우측 상단의 파란색 [배포] > [새 배포]를 클릭합니다.
  2. 설정(톱니바퀴) 아이콘을 눌러 유형을 [웹 앱]으로 선택합니다.
  3. 다음 사용자 권한으로 실행: 나(내 계정) 선택
  4. 액세스 권한이 있는 사용자: 모든 사용자(Anyone) 선택 후 [배포] 클릭
  5. (최초 1회 권한 승인) [액세스 승인] > 계정 선택 > [고급] > [~(으)로 이동(안전하지 않음)] > [허용] 진행

코드를 고친 뒤에는 [배포] > [배포 관리]에서 연필 아이콘을 누르고 버전을 [새 버전]으로 바꿔 배포해야 웹 앱에 반영됩니다. 웹 앱 주소는 그대로 유지됩니다.

4
배포된 웹 앱 URL로 접속 및 공유

배포 완료 화면에 생성된 웹 앱 URL을 복사하여 웹 브라우저 주소창에 입력하거나 북마크(즐겨찾기)에 등록합니다. PC, 태블릿, 스마트폰 어디서나 접속하여 관계 설문 및 관계지도 기능을 이용할 수 있습니다.

만 13세 미만 학생 접속 안내 (필독) 구글 계정 정책으로 인해 만 13세 미만의 학생은 앱스스크립트(Apps Script) 웹 앱 사용이 제한될 수 있습니다.
접속이 되지 않을 경우 인터넷 브라우저를 시크릿 모드(비공개 모드)로 바꾸어 접속하거나, 카카오톡 대화방으로 전달된 링크를 클릭(카카오톡 인앱 브라우저)하여 접속하면 제한 없이 정상적으로 우리반 관계지도 앱을 이용할 수 있습니다.

데이터 관리 & 팁

설문 데이터 관리 및 월별 비교 활용
  • 월별 설문 관리: 매월 새로운 설문을 생성하여 학생들의 교우 관계 변화를 추적할 수 있습니다. 이전 달 설문 데이터는 자동으로 보관됩니다.
  • 지난달과 비교: 관계지도에서 [지난달과 비교] 기능을 사용하면 새로 생긴 관계, 사라진 관계, 유지된 관계를 한눈에 확인할 수 있습니다.
  • 명단 수정 시: 전학, 전출 등으로 학생 구성이 변경되면 구글 시트의 학생명단 탭만 수정하면 웹 앱에 즉시 자동 반영됩니다.
  • 응답 엑셀 다운로드: 교사 화면에서 [응답 엑셀] 버튼을 누르면 해당 월의 전체 응답 데이터를 엑셀 파일로 내려받을 수 있습니다.
학생 개인정보 보호에 유의하세요
  • 응답 비공개: 학생의 설문 응답은 교사만 확인할 수 있습니다. 관계지도 화면은 교사 로그인 후에만 볼 수 있으므로 학생에게 노출되지 않습니다.
  • 민감 응답 확인: '살펴볼 점'에 올라오는 민감한 응답(따돌림, 속상함 등)은 즉시 확인하고 적절한 조치를 취해 주세요.
  • 설문 삭제: 더 이상 필요하지 않은 설문 데이터는 [설문 삭제] 기능으로 완전히 제거할 수 있습니다.

/**

 * 시트 구조 점검 (아무것도 바꾸지 않음)

 *  sheets[]: { name, exists, dataRows, headers, expected, status(ok|fix|missing), tasks[], warnings[] }

 *   - tasks    : [안전 세팅]을 누르면 할 일

 *   - warnings : 교사가 직접 확인할 것 (학번 형식·중복, 비밀번호 없는 학생, 진행 중인 달이 둘 이상 등)

 */

function diagnoseDatabase() {

  assertSheetContext_();

  const ss = SpreadsheetApp.getActive();

  const sheets = SHEET_SCHEMA.map(s => {

    const sh = ss.getSheetByName(s.name);

    if (!sh) return { name: s.name, exists: false, dataRows: 0, headers: [], expected: s.headers.slice(), status: 'missing', tasks: ['시트를 새로 만들고 예시 데이터를 채워요'], warnings: [] };

    const lastCol = sh.getLastColumn();

    const headers = lastCol ? sh.getRange(1, 1, 1, lastCol).getValues()[0].map(h => String(h).trim()).filter(Boolean) : [];

    const dataRows = Math.max(0, sh.getLastRow() - 1);

    const missing = s.headers.filter(h => headers.indexOf(h) < 0);

    const tasks = [];

    if (sh.getLastRow() === 0) tasks.push('빈 시트에 머리 줄과 예시 데이터를 채워요');

    else if (missing.length) tasks.push('빠진 열을 오른쪽 끝에 추가해요: ' + missing.join(', '));

    const warnings = diagnoseWarnings_(s.name, sh, headers);

    return { name: s.name, exists: true, dataRows: dataRows, headers: headers, expected: s.headers.slice(), status: tasks.length ? 'fix' : 'ok', tasks: tasks, warnings: warnings };

  });

  return {

    sheets: sheets,

    obsolete: OBSOLETE_SHEETS.filter(n => ss.getSheetByName(n)),

    adminPasswordRegistered: !!getAppProperty_('TEACHER_PIN'),

    studentPasswordRegistered: !!getAppProperty_('STUDENT_DEFAULT_PASSWORD')

  };

}



/** 시트별로 교사가 직접 확인할 것 */

function diagnoseWarnings_(name, sh, headers) {

  const w = [];

  if (sh.getLastRow() < 2) return w;

  const values = sh.getRange(2, 1, sh.getLastRow() - 1, headers.length).getValues();

  const col = h => headers.indexOf(h);

  if (name === SH.STUDENT) {

    const cNo = col('학번'), cName = col('이름'), cHash = col('비밀번호해시'), cAct = col('활성');

    const rows = values.filter(r => cName >= 0 && cellStr_(r[cName]) && (cAct < 0 || bool_(r[cAct], true)));

    if (cNo >= 0) {

      const bad = rows.filter(r => !STUDENT_NO_PATTERN.test(cellStr_(r[cNo]))).map(r => cellStr_(r[cName]));

      if (bad.length) w.push('학번이 숫자 4~5자리가 아닌 학생 ' + bad.length + '명: ' + bad.slice(0, 5).join(', ') + (bad.length > 5 ? ' 등' : '') + ' (웹 앱 관리 탭에서 고쳐 주세요)');

      const seen = {}, dup = [];

      rows.forEach(r => { const no = cellStr_(r[cNo]); if (no && seen[no]) dup.push(no); seen[no] = true; });

      if (dup.length) w.push('학번이 겹치는 학생이 있어요: ' + [...new Set(dup)].join(', '));

    }

    if (cHash >= 0) {

      const noPw = rows.filter(r => !cellStr_(r[cHash])).length;

      if (noPw) w.push('비밀번호가 없는 학생 ' + noPw + '명 (웹 앱 관리 탭 명단에서 [비밀번호 초기화]를 눌러 초기 비밀번호를 정해 주세요)');

    }

  }

  if (name === SH.MONTH) {

    const cSt = col('상태');

    const open = cSt >= 0 ? values.filter(r => cellStr_(r[cSt]) === '진행중').length : 0;

    if (open > 1) w.push('진행 중인 달이 ' + open + '개예요. 학생은 가장 최근 달에만 응답해요.');

  }

  return w;

}



/**

 * DB 세팅 실행

 * @param {string} mode 'safe' = 없는 시트·열만 추가 / 'reset' = 모두 지우고 예시 데이터 + 옛 시트 정리

 * @param {boolean} withBackup 실행 전에 같은 파일 안에 '백업_시트명_날짜' 탭으로 복사

 * @return {logs: string[]}

 */

function runDatabaseSetup(mode, withBackup) {

  assertSheetContext_();

  const lock = LockService.getScriptLock();

  lock.waitLock(30000);

  try {

    const ss = SpreadsheetApp.getActive();

    const logs = [];

    if (withBackup) {

      const stamp = nowStr_('yyMMdd_HHmm');

      SHEET_SCHEMA.forEach(s => {

        const sh = ss.getSheetByName(s.name);

        if (!sh || sh.getLastRow() === 0) return;

        const copy = sh.copyTo(ss).setName(('백업_' + s.name + '_' + stamp).slice(0, 90));

        copy.setTabColor('#B8C3BE');

        logs.push('[' + s.name + '] 백업 탭 \'' + copy.getName() + '\'을(를) 만들었어요');

      });

    }

    SHEET_SCHEMA.forEach(s => {

      let sh = ss.getSheetByName(s.name);

      const isNew = !sh;

      if (isNew) sh = ss.insertSheet(s.name);

      if (mode === 'reset' || isNew || sh.getLastRow() === 0) {

        writeSheetWithDummy_(sh, s);

        logs.push('[' + s.name + '] ' + (isNew ? '새로 만들고' : mode === 'reset' ? '모두 지우고' : '빈 시트에') + ' 예시 데이터 ' + (sh.getLastRow() - 1) + '행을 채웠어요');

      } else {

        const lastCol = Math.max(1, sh.getLastColumn());

        const header = sh.getRange(1, 1, 1, lastCol).getValues()[0].map(h => String(h).trim());

        const missing = s.headers.filter(h => header.indexOf(h) < 0);

        if (missing.length) sh.getRange(1, lastCol + 1, 1, missing.length).setValues([missing]);

        // 텍스트로 고정할 열(학번 등)의 서식을 다시 맞춤

        const all = header.concat(missing);

        s.textCols.forEach(h => { const c = all.indexOf(h) + 1; if (c > 0) sh.getRange(2, c, Math.max(1, sh.getMaxRows() - 1), 1).setNumberFormat('@'); });

        styleHeader_(sh, s, all.length);

        logs.push('[' + s.name + '] ' + (missing.length ? '빠진 열을 추가했어요: ' + missing.join(', ') : '바꿀 구조가 없어 서식만 다시 맞췄어요'));

      }

    });

    if (mode === 'reset') {

      OBSOLETE_SHEETS.forEach(n => {

        const sh = ss.getSheetByName(n);

        if (sh && ss.getSheets().length > 1) { ss.deleteSheet(sh); logs.push('[' + n + '] 이전 버전 시트라 삭제했어요'); }

      });

      logs.push('예시 학생은 학번 1601~1620이고, 비밀번호는 [환경설정]의 학생 초기 비밀번호(등록하지 않았다면 ' + FALLBACK_STUDENT_PASSWORD + ')예요.');

    }

    ['Sheet1', '시트1'].forEach(n => {

      const sh = ss.getSheetByName(n);

      if (sh && sh.getLastRow() === 0 && ss.getSheets().length > 1) ss.deleteSheet(sh);

    });

    return { logs: logs };

  } finally {

    lock.releaseLock();

  }

}



function writeSheetWithDummy_(sh, schema) {

  sh.clear();

  sh.getDataRange().clearDataValidations();

  const rows = schema.dummy();

  const width = schema.headers.length;

  const need = rows.length + 200;

  if (sh.getMaxRows() < need) sh.insertRowsAfter(sh.getMaxRows(), need - sh.getMaxRows());

  const maxRows = sh.getMaxRows();

  schema.textCols.forEach(h => {

    const c = schema.headers.indexOf(h) + 1;

    if (c > 0) sh.getRange(2, c, maxRows - 1, 1).setNumberFormat('@');

  });

  sh.getRange(1, 1, 1, width).setValues([schema.headers]);

  if (rows.length) sh.getRange(2, 1, rows.length, width).setValues(rows);

      SpreadsheetApp.newDataValidation().requireValueInList(schema.lists[h], true).setAllowInvalid(true).build());

  });

}

/* ─────────────────────────────────────────────────────────────

 * 8. 학생 비밀번호 (해시 저장)

 *    시트에는 원래 비밀번호가 아니라 "무작위 salt + 비밀번호"의 SHA-256 값만 저장합니다.

 *    salt는 처음 한 번 자동 생성되어 스크립트 속성(PASSWORD_SALT)에 보관됩니다.

 * ───────────────────────────────────────────────────────────── */

function getSalt_() {

  const props = PropertiesService.getScriptProperties();

  let salt = props.getProperty('PASSWORD_SALT');

  if (!salt) { salt = Utilities.getUuid() + Utilities.getUuid(); props.setProperty('PASSWORD_SALT', salt); }

  return salt;

}

function hashPw_(pw) {

  const bytes = Utilities.computeDigest(Utilities.DigestAlgorithm.SHA_256, getSalt_() + '|' + String(pw), Utilities.Charset.UTF_8);

  return Utilities.base64Encode(bytes);

}

function sheet_(name) {

  const sh = SpreadsheetApp.getActive().getSheetByName(name);

  if (!sh) throw new Error('DB_MISSING');

  return sh;

}



function readTable_(name) {

  const values = sheet_(name).getDataRange().getValues();

  if (!values.length) return { headers: [], rows: [] };

  const headers = values[0].map(h => String(h).trim());

  const rows = [];

  for (let r = 1; r < values.length; r++) {

    if (values[r].every(c => c === '' || c === null)) continue;

    const obj = { _row: r + 1 };

    headers.forEach((h, i) => { if (h) obj[h] = values[r][i]; });

    rows.push(obj);

  }

  return { headers: headers, rows: rows };

}



function appendObjects_(name, objs) {

  if (!objs.length) return;

  const sh = sheet_(name);

  const headers = sh.getRange(1, 1, 1, sh.getLastColumn()).getValues()[0].map(h => String(h).trim());

  const data = objs.map(o => headers.map(h => (o[h] !== undefined ? o[h] : '')));

  const start = sh.getLastRow() + 1;

  ['월', '날짜', '학생ID', '대상ID', '관련학생ID', '학번', '비밀번호해시'].forEach(h => {

    const c = headers.indexOf(h) + 1;

    if (c > 0) sh.getRange(start, c, data.length, 1).setNumberFormat('@');

  });

  sh.getRange(start, 1, data.length, headers.length).setValues(data);

}



function removeRows_(name, predicate) {

  const sh = sheet_(name);

  const values = sh.getDataRange().getValues();

  if (values.length < 2) return 0;

  const headers = values[0].map(h => String(h).trim());

  const keep = [];

  let removed = 0;

  for (let r = 1; r < values.length; r++) {

    const obj = {};

    headers.forEach((h, i) => { obj[h] = values[r][i]; });

    if (predicate(obj)) removed++; else keep.push(values[r]);

  }

  if (!removed) return 0;

  sh.getRange(2, 1, values.length - 1, headers.length).clearContent();

  if (keep.length) sh.getRange(2, 1, keep.length, headers.length).setValues(keep);

  return removed;

}



function setCell_(name, rowNum, headers, header, value, asText) {

  const c = headers.indexOf(header) + 1;

  if (c <= 0) return;

  const rg = sheet_(name).getRange(rowNum, c);

  if (asText) rg.setNumberFormat('@');

  rg.setValue(value);

}



/** 마감예약 'yyyy-MM-dd HH:mm' → Date (형식이 틀리면 null) */

function parseSchedule_(s) {

  s = String(s || '').trim();

  if (!/^\d{4}-\d{2}-\d{2} \d{2}:\d{2}$/.test(s)) return null;

  try { return Utilities.parseDate(s, tz_(), 'yyyy-MM-dd HH:mm'); } catch (e) { return null; }

}



/** 모든 시트를 읽어 데이터 모델로 (비밀번호 해시는 서버 안에서만 사용) */

function loadModel_() {

  const s = v => cellStr_(v);

  const tags = v => s(v).split(',').map(x => x.trim()).filter(Boolean);

  const now = new Date();

  return {

    students: readTable_(SH.STUDENT).rows.map(r => ({

      id: s(r['학생ID']), number: Number(r['번호']) || 0, studentNo: s(r['학번']), name: s(r['이름']),

      hash: s(r['비밀번호해시']), initPw: bool_(r['초기비번'], false), active: bool_(r['활성'], true), _row: r._row

    })).filter(x => x.id && x.name).sort((a, b) => (a.studentNo || '').localeCompare(b.studentNo || '', 'ko', { numeric: true }) || a.number - b.number),   // 학번 순

    // 마감예약 시각이 지난 '진행중' 달은 자동으로 '마감'으로 취급합니다.

    months: readTable_(SH.MONTH).rows.map(r => {

      const closeAt = cellStr_(r['마감예약'], true);

      const due = parseSchedule_(closeAt);

      const raw = s(r['상태']) || '마감';

      return { month: monthStr_(r['월']), status: raw === '진행중' && due && due <= now ? '마감' : raw, start: s(r['시작일']), closeAt: due ? closeAt : '', _row: r._row };

    }).filter(x => /^\d{4}-\d{2}$/.test(x.month)).sort((a, b) => a.month.localeCompare(b.month)),

    // 즐거움·불편 응답만 읽습니다. (이전 버전의 칭찬·도움필요 응답은 무시)

    answers: readTable_(SH.ANSWER).rows.map(r => ({

      month: monthStr_(r['월']), s: s(r['학생ID']), o: s(r['대상ID']), pol: s(r['구분']) || POL.POS,

      rank: Number(r['순서']) || 1, tags: tags(r['이유태그']), text: s(r['이유'])

    })).filter(x => x.month && x.s && x.o && x.s !== x.o && (x.pol === POL.POS || x.pol === POL.NEG)),

    submits: readTable_(SH.SUBMIT).rows.map(r => ({

      month: monthStr_(r['월']), s: s(r['학생ID']), climate: Number(r['학급분위기']) || '',

      climateReason: s(r['분위기이유']), at: cellStr_(r['제출일시'], true),

      editAllowed: bool_(r['수정허용'], false), _row: r._row

    })).filter(x => x.month && x.s)

  };

}

/**

 * 학번·비밀번호 확인 (학번마다 5번 틀리면 10분 잠금).

 * needMonth=true면 진행 중인 설문 달도 함께 찾습니다.

 */

function checkStudent_(studentNo, pw, needMonth) {

  studentNo = String(studentNo || '').trim();

  pw = String(pw || '').trim();

  if (!STUDENT_NO_PATTERN.test(studentNo)) return { error: '학번은 숫자 4~5자리로 입력해 주세요. (예: 3101)' };

  if (!PASSWORD_PATTERN.test(pw)) return { error: '비밀번호를 띄어쓰기 없이 입력해 주세요.' };

  const cache = CacheService.getScriptCache();

  const k = 'pwfail_' + studentNo;

  const fails = Number(cache.get(k) || 0), all = Number(cache.get('pwfail_all') || 0);

  if (fails >= 5) return { error: '비밀번호를 5번 틀려서 10분 동안 잠겼어요. 잠시 후 다시 시도하거나 선생님께 문의해 주세요.' };

  if (all >= 60) return { error: '입력 시도가 너무 많아요. 10분 뒤에 다시 시도해 주세요.' };

  const m = loadModel_();

  const me = m.students.filter(x => x.active && x.studentNo === studentNo)[0];

  if (!me || !me.hash || hashPw_(pw) !== me.hash) {

    cache.put(k, String(fails + 1), 600);

    cache.put('pwfail_all', String(all + 1), 600);

    return { error: '학번이나 비밀번호가 맞지 않아요. 비밀번호를 잊었다면 선생님께 초기화를 부탁해 주세요.' };

  }

  cache.remove(k);

  // 초기 비밀번호로 들어오면 먼저 자기 비밀번호로 바꾸게 합니다.

  if (me.initPw || pw === studentDefaultPassword_()) return { mustChange: true, m: m, me: me };

  if (!needMonth) return { m: m, me: me };

  const open = m.months.filter(x => x.status === '진행중');

  if (!open.length) return { error: '지금은 설문 기간이 아니에요. 선생님께 문의해 주세요.' };

  const mo = open[open.length - 1];

  return { m: m, me: me, month: mo.month, closeAt: mo.closeAt };

}



/** 이번 달 이 학생의 제출 상태: { submitted, editAllowed, sub } */

function submitState_(m, month, sid) {

  const sub = m.submits.filter(x => x.month === month && x.s === sid)[0];

  const submitted = !!sub || m.answers.some(a => a.month === month && a.s === sid);

  return { submitted: submitted, editAllowed: !!(sub && sub.editAllowed), sub: sub };

}



/**

 * 설문 입장

 *  - 처음 제출: 빈 설문지

 *  - 이미 제출: 학생 정보 보호를 위해 답을 불러오지 않고 막습니다.

 *  - 교사가 수정 권한을 준 경우에만 지난 답을 불러와 고칠 수 있습니다.

 */

function enterSurvey(studentNo, pw) {

  try {

    const ctx = checkStudent_(studentNo, pw, true);

    if (ctx.error) return { ok: false, message: ctx.error };

    if (ctx.mustChange) return { ok: false, mustChange: true, message: '처음 로그인했거나 비밀번호가 초기화됐어요. 먼저 나만의 비밀번호로 바꿔 주세요.' };

    const m = ctx.m, me = ctx.me, month = ctx.month;

    const state = submitState_(m, month, me.id);

    if (state.submitted && !state.editAllowed) {

      return { ok: false, locked: true, message: monthLabel_(month) + ' 설문은 이미 제출했어요. 친구들의 정보를 지키기 위해 제출한 답은 다시 불러오지 않아요. 고칠 내용이 있으면 선생님께 수정 권한을 요청해 주세요.' };

    }

    const previous = { climate: '', climateReason: '' };

    SURVEY_CONFIG.questions.forEach(q => { previous[q.key] = []; });

    if (state.editAllowed) {

      const mine = m.answers.filter(a => a.month === month && a.s === me.id).sort((a, b) => a.rank - b.rank);

      SURVEY_CONFIG.questions.forEach(q => { previous[q.key] = mine.filter(a => a.pol === q.pol).map(a => ({ id: a.o, tags: a.tags, text: a.text })); });

      previous.climate = state.sub.climate; previous.climateReason = state.sub.climateReason;

    }

    return {

      ok: true, month: month, monthLabel: monthLabel_(month), closeAt: ctx.closeAt,

      me: { id: me.id, name: me.name, studentNo: me.studentNo },

      classmates: m.students.filter(x => x.active && x.id !== me.id).map(x => ({ id: x.id, name: x.name, number: x.number })),

      config: SURVEY_CONFIG,

      previous: previous,

      editing: state.editAllowed

    };

  } catch (e) { return friendlyError_(e); }

}



/** 학생 비밀번호 바꾸기 (띄어쓰기 없이 4~20자, 초기 비밀번호와 같으면 안 됨) */

function changeStudentPassword(studentNo, oldPw, newPw) {

  try {

    const ctx = checkStudent_(studentNo, oldPw, false);

    if (ctx.error) return { ok: false, message: ctx.error };

    newPw = String(newPw || '').trim();

    if (!PASSWORD_PATTERN.test(newPw)) return { ok: false, message: '새 비밀번호는 띄어쓰기 없이 4~20자로 정해 주세요.' };

    if (newPw === studentDefaultPassword_()) return { ok: false, message: '선생님이 알려 준 초기 비밀번호와 다르게 정해 주세요.' };

    if (newPw === String(oldPw).trim()) return { ok: false, message: '지금 비밀번호와 다르게 정해 주세요.' };

    const t = readTable_(SH.STUDENT);

    const row = t.rows.filter(r => cellStr_(r['학생ID']) === ctx.me.id)[0];

    setCell_(SH.STUDENT, row._row, t.headers, '비밀번호해시', hashPw_(newPw), true);

    setCell_(SH.STUDENT, row._row, t.headers, '초기비번', false);

    return { ok: true };

  } catch (e) { return friendlyError_(e); }

}



/**

 * 설문 제출: 처음 제출이거나 수정 권한이 있을 때만 저장하고, 수정 권한은 제출과 함께 사라집니다.

 * @param {Object} p { positive:[{id,tags,text}], negative:[...], climate(1~5), climateReason }

 */

function submitSurvey(studentNo, pw, p) {

  const lock = LockService.getScriptLock();

  lock.waitLock(20000);

  try {

    const ctx = checkStudent_(studentNo, pw, true);

    if (ctx.error) return { ok: false, message: ctx.error };

    if (ctx.mustChange) return { ok: false, message: '먼저 비밀번호를 바꿔 주세요.' };

    const m = ctx.m, me = ctx.me, month = ctx.month;

    const state = submitState_(m, month, me.id);

    p = p || {};

    const nameOf = {}, valid = {};

    m.students.forEach(x => { if (x.active && x.id !== me.id) { valid[x.id] = true; nameOf[x.id] = x.name; } });

    const rows = [], at = nowStr_();

    const posIds = {};

    for (let qi = 0; qi < SURVEY_CONFIG.questions.length; qi++) {

      const q = SURVEY_CONFIG.questions[qi];

      const list = Array.isArray(p[q.key]) ? p[q.key].slice(0, q.max) : [];

      const used = {};

      for (let i = 0; i < list.length; i++) {

        const it = list[i] || {};

        const id = String(it.id || '');

        if (!valid[id] || used[id]) continue;

        if (q.pol === POL.NEG && posIds[id]) return { ok: false, message: nameOf[id] + ' 친구를 2번과 3번에 함께 고를 수 없어요.' };

        const tags = (Array.isArray(it.tags) ? it.tags : []).map(String).filter(t => q.tags.indexOf(t) >= 0);

        const text = String(it.text || '').trim().slice(0, SURVEY_CONFIG.reasonMax);

        if (!tags.length) return { ok: false, message: (qi + 2) + '번 문항에서 ' + nameOf[id] + ' 친구를 고른 이유의 분류를 하나 이상 골라 주세요.' };

        if (!text) return { ok: false, message: (qi + 2) + '번 문항에서 ' + nameOf[id] + ' 친구를 고른 이유를 자세히 적어 주세요.' };

        used[id] = true;

        if (q.pol === POL.POS) posIds[id] = true;

        rows.push({ '응답ID': newId_('A'), '월': month, '학생ID': me.id, '대상ID': id, '구분': q.pol, '순서': Object.keys(used).length, '이유태그': tags.join(', '), '이유': text, '기록일시': at });

      }

    }

    const climate = Number(p.climate);

    if ([1, 2, 3, 4, 5].indexOf(climate) < 0) return { ok: false, message: '1번 문항에서 우리 반 분위기 점수를 골라 주세요.' };

    const climateReason = String(p.climateReason || '').trim().slice(0, 300);



    removeRows_(SH.ANSWER, r => monthStr_(r['월']) === month && cellStr_(r['학생ID']) === me.id);

    removeRows_(SH.SUBMIT, r => monthStr_(r['월']) === month && cellStr_(r['학생ID']) === me.id);

    appendObjects_(SH.ANSWER, rows);

    appendObjects_(SH.SUBMIT, [{ '월': month, '학생ID': me.id, '학급분위기': climate, '분위기이유': climateReason, '제출일시': at, '수정허용': false }]);

    return { ok: true };

  } catch (e) {

    return friendlyError_(e);

  } finally {

    lock.releaseLock();

  }

}

 * ───────────────────────────────────────────────────────────── */

function teacherLogin(pin) {

  const saved = getAppProperty_('TEACHER_PIN');

  if (!saved) return { ok: false, message: '관리자가 아직 교사 비밀번호를 등록하지 않았습니다. 구글 시트 상단 [🌌 관계지도] > [환경설정] 메뉴에서 등록해 주세요.' };

  const cache = CacheService.getScriptCache();

  const fails = Number(cache.get('pinfail') || 0);

  if (fails >= 5) return { ok: false, message: '교사 비밀번호를 5번 잘못 입력해 5분간 잠겼어요. 잠시 후 다시 시도해 주세요.' };

  if (String(pin || '').trim() !== saved) {

    cache.put('pinfail', String(fails + 1), 300);

    return { ok: false, message: '교사 비밀번호가 일치하지 않아요. (남은 기회 ' + Math.max(0, 4 - fails) + '번)' };

  }

  cache.remove('pinfail');

  const token = Utilities.getUuid();

  cache.put('tk_' + token, '1', TEACHER_SESSION_SEC);

  return { ok: true, token: token };

}



function requireTeacher_(token) {

  const cache = CacheService.getScriptCache();

  if (!token || !cache.get('tk_' + token)) throw new Error('AUTH: 로그인 시간이 지났어요. 다시 로그인해 주세요.');

  cache.put('tk_' + token, '1', TEACHER_SESSION_SEC);

}



function teacherLogout(token) {

  if (token) CacheService.getScriptCache().remove('tk_' + token);

  return { ok: true };

}

/** 선택한 달 + 그 이전 달을 분석하고, 비교 결과·온톨로지 사실·월별 추이까지 한 번에 돌려줍니다. */

function getDashboard(token, month) {

  requireTeacher_(token);

  try {

    const m = loadModel_();

    const ctx = buildContext_(m, month);

    const trend = m.months.map(x => {

      const a = x.month === ctx.month ? ctx.cur : (x.month === ctx.prevMonth ? ctx.prev : analyzeMonth_(m, x.month));

      return {

        month: x.month, status: x.status, closeAt: x.closeAt, responded: a.responded, total: a.total,

        mutual: a.mutualPairs.length, neg: a.edges.filter(e => e.pol === POL.NEG).length,

        isolated: a.responded ? Object.keys(a.stats).filter(id => a.stats[id].recvPos === 0).length : null,

        climateAvg: a.climate.avg

      };

    });

    return {

      ok: true,

      month: ctx.month, prevMonth: ctx.prevMonth, months: trend,

      cur: ctx.cur, diff: ctx.diff,

      facts: ctx.onto ? ctx.onto.facts : [],

      students: m.students.filter(x => x.active).map(x => ({ id: x.id, number: x.number, studentNo: x.studentNo, name: x.name })),

      roster: m.students.map(x => ({ id: x.id, number: x.number, studentNo: x.studentNo, name: x.name, hasPassword: !!x.hash, initPw: x.initPw, active: x.active })),

      config: SURVEY_CONFIG, pol: POL

    };

  } catch (e) { return friendlyError_(e); }

}



/** 선택 달·이전 달 분석 + 비교 + 온톨로지 (대시보드와 AI 분석이 함께 사용) */

function buildContext_(m, month) {

  const list = m.months.map(x => x.month);

  let sel = list.indexOf(month) >= 0 ? month : '';

  if (!sel) {

    const open = m.months.filter(x => x.status === '진행중');

    sel = open.length ? open[open.length - 1].month : (list[list.length - 1] || '');

  }

  const idx = list.indexOf(sel);

  const prevMonth = idx > 0 ? list[idx - 1] : '';

  const cur = sel ? analyzeMonth_(m, sel) : null;

  const prev = prevMonth ? analyzeMonth_(m, prevMonth) : null;

  const diff = cur && prev ? diffMonths_(cur, prev) : null;

  const onto = cur ? buildFacts_(cur, diff) : null;

  return { month: sel, prevMonth: prevMonth, cur: cur, prev: prev, diff: diff, onto: onto };

}



/** 학생이 쓴 글에 SURVEY_CONFIG.alertWords 낱말이 있으면 그 낱말들을 돌려줍니다. */

function alertWordsIn_(text) {

  text = String(text || '').replace(/\s+/g, ' ');

  return SURVEY_CONFIG.alertWords.filter(w => w && text.indexOf(w) >= 0);

}



/** 태그나 글에서 세심한 확인이 필요한 낱말·태그를 찾습니다. */

function sensitiveHits_(tags, text) {

  return (tags || []).filter(t => SURVEY_CONFIG.alertTags.indexOf(t) >= 0).concat(alertWordsIn_(text));

}



/**

 * 한 달 분석: 관계 선, 학생별 통계, 학급 분위기, 서로 친구, 엇갈림, 그리고 '살펴볼 점' 표 5가지

 *  watch.sensitive  세심한 확인이 필요한 태그·표현

 *  watch.climateLow 학급 분위기를 1~2점으로 매긴 학생

 *  watch.isolated   즐거운 친구로 선택받지 못한 학생

 *  watch.conflicts  서로 불편함 · 마음이 엇갈림

 *  watch.missing    미응답

 */

function analyzeMonth_(m, month) {

  const students = m.students.filter(x => x.active);

  const ids = {};

  students.forEach(x => { ids[x.id] = true; });

  const edges = m.answers.filter(a => a.month === month && ids[a.s] && ids[a.o]);

  const subs = {};

  m.submits.filter(x => x.month === month && ids[x.s]).forEach(x => { subs[x.s] = x; });

  const responded = {};

  Object.keys(subs).forEach(k => { responded[k] = true; });

  edges.forEach(e => { responded[e.s] = true; });

  const has = {};

  edges.forEach(e => { has[e.s + '|' + e.o + '|' + e.pol] = true; });



  const stats = {};

  students.forEach(x => {

    const sub = subs[x.id];

    stats[x.id] = { id: x.id, recvPos: 0, recvNeg: 0, givenPos: 0, givenNeg: 0, mutual: 0,

                    responded: !!responded[x.id], editAllowed: !!(sub && sub.editAllowed), submittedAt: sub ? sub.at : '',

                    climate: sub ? sub.climate : '', climateReason: sub ? sub.climateReason : '' };

  });

  edges.forEach(e => {

    if (e.pol === POL.POS) { stats[e.s].givenPos++; stats[e.o].recvPos++; }

    else { stats[e.s].givenNeg++; stats[e.o].recvNeg++; }

  });

  const mutualPairs = [], mutualNeg = [], mixed = [];

  edges.forEach(e => {

    if (e.pol === POL.POS && e.s < e.o && has[e.o + '|' + e.s + '|' + POL.POS]) { mutualPairs.push([e.s, e.o]); stats[e.s].mutual++; stats[e.o].mutual++; }

    if (e.pol === POL.NEG && e.s < e.o && has[e.o + '|' + e.s + '|' + POL.NEG]) mutualNeg.push([e.s, e.o]);

    if (e.pol === POL.POS && has[e.o + '|' + e.s + '|' + POL.NEG]) mixed.push([e.s, e.o]);

  });



  // 학급 분위기: 평균과 1~5점 분포

  const scores = students.map(x => Number(stats[x.id].climate)).filter(v => v >= 1 && v <= 5);

  const dist = [0, 0, 0, 0, 0];

  scores.forEach(v => { dist[v - 1]++; });

  const climate = { avg: scores.length ? round1_(scores.reduce((a, b) => a + b, 0) / scores.length) : null, count: scores.length, dist: dist };



  // 살펴볼 점 (소주제별 표)

  const anyResp = Object.keys(responded).length > 0;

  const watch = { sensitive: [], climateLow: [], isolated: [], conflicts: [], missing: [] };

  edges.filter(e => e.pol === POL.NEG).forEach(e => {

    const hits = sensitiveHits_(e.tags, e.text);

    if (hits.length) watch.sensitive.push({ s: e.s, o: e.o, where: '불편한 친구', hits: hits, tags: e.tags, text: e.text });

  });

  students.forEach(x => {

    const st = stats[x.id];

    const ch = alertWordsIn_(st.climateReason);

    if (ch.length) watch.sensitive.push({ s: x.id, o: '', where: '분위기 이유', hits: ch, tags: [], text: st.climateReason });

    const c = Number(st.climate);

    if (c && c <= 2) watch.climateLow.push({ id: x.id, score: c, reason: st.climateReason });

    if (anyResp && st.recvPos === 0) watch.isolated.push({ id: x.id, responded: st.responded, chose: edges.filter(e => e.s === x.id && e.pol === POL.POS).map(e => e.o) });

  });

  watch.climateLow.sort((a, b) => a.score - b.score);

  const textOf = (s, o, pol) => (edges.filter(e => e.s === s && e.o === o && e.pol === pol)[0] || {}).text || '';

  mutualNeg.forEach(p => watch.conflicts.push({ a: p[0], b: p[1], type: '서로 불편함', aText: textOf(p[0], p[1], POL.NEG), bText: textOf(p[1], p[0], POL.NEG) }));

  mixed.forEach(p => watch.conflicts.push({ a: p[0], b: p[1], type: '마음이 엇갈림', aText: textOf(p[0], p[1], POL.POS), bText: textOf(p[1], p[0], POL.NEG) }));

  watch.missing = anyResp ? students.filter(x => !responded[x.id]).map(x => x.id) : [];



  return {

    month: month, total: students.length, responded: Object.keys(responded).length, missing: watch.missing,

    edges: edges.map(e => ({ s: e.s, o: e.o, pol: e.pol, rank: e.rank, tags: e.tags, text: e.text })),

    stats: stats, climate: climate, mutualPairs: mutualPairs, mutualNeg: mutualNeg, mixed: mixed, watch: watch

  };

}



/** 지난달과 비교 — '두 달 모두 응답한 학생'이 한 선택만 견줘 착시를 막습니다. */

function diffMonths_(cur, prev) {

  const both = {};

  Object.keys(cur.stats).forEach(id => { if (cur.stats[id].responded && prev.stats[id] && prev.stats[id].responded) both[id] = true; });

  const key = e => e.s + '|' + e.o + '|' + e.pol;

  const ce = cur.edges.filter(e => both[e.s]);

  const pe = prev.edges.filter(e => both[e.s] && cur.stats[e.o]);

  const cm = {}, pm = {};

  ce.forEach(e => { cm[key(e)] = e; });

  pe.forEach(e => { pm[key(e)] = e; });

  const pick = (arr, pol, other, want) => arr.filter(e => e.pol === pol && !!other[key(e)] === want);

  const pairsOf = a => { const o = {}; a.mutualPairs.filter(p => both[p[0]] && both[p[1]]).forEach(p => { o[p[0] + '|' + p[1]] = p; }); return o; };

  const cp = pairsOf(cur), pp = pairsOf(prev);

  const cnt = (arr, id, pol) => arr.filter(e => e.o === id && e.pol === pol).length;



  const students = Object.keys(cur.stats).map(id => ({

    id: id, comparable: !!both[id],

    prevPos: cnt(pe, id, POL.POS), curPos: cnt(ce, id, POL.POS),

    prevNeg: cnt(pe, id, POL.NEG), curNeg: cnt(ce, id, POL.NEG),

    prevClimate: prev.stats[id] ? prev.stats[id].climate : '', curClimate: cur.stats[id].climate

  }));

  const hl = { escaped: [], grew: [], climateUp: [], newIsolated: [], shrank: [], newNegTarget: [], climateDown: [] };

  students.forEach(x => {

    const d = x.curPos - x.prevPos;

    if (x.prevPos === 0 && x.curPos > 0) hl.escaped.push(x.id);

    else if (d >= 2) hl.grew.push(x.id);

    if (x.prevPos > 0 && x.curPos === 0) hl.newIsolated.push(x.id);

    else if (d <= -2) hl.shrank.push(x.id);

    if (x.curNeg > x.prevNeg) hl.newNegTarget.push(x.id);

    const pc = Number(x.prevClimate), cc = Number(x.curClimate);

    if (pc && cc && pc - cc >= 2) hl.climateDown.push(x.id);

    if (pc && cc && cc - pc >= 2) hl.climateUp.push(x.id);

  });

  return {

    prevMonth: prev.month, comparable: Object.keys(both).length,

    newPos: pick(ce, POL.POS, pm, false), keptPos: pick(ce, POL.POS, pm, true), lostPos: pick(pe, POL.POS, cm, false),

    newNeg: pick(ce, POL.NEG, pm, false), keptNeg: pick(ce, POL.NEG, pm, true), resolvedNeg: pick(pe, POL.NEG, cm, false),

    newMutual: Object.keys(cp).filter(k => !pp[k]).map(k => cp[k]),

    lostMutual: Object.keys(pp).filter(k => !cp[k]).map(k => pp[k]),

    mutualPrev: prev.mutualPairs.length, mutualCur: cur.mutualPairs.length,

    climatePrev: prev.climate, climateCur: cur.climate,

    students: students, highlights: hl

  };

}





/* ─────────────────────────────────────────────────────────────

 * 13. 온톨로지: 사실(트리플) 만들기 + 추론

 *     사실 = { s(주어), p(관계), o(대상), src(설문/추론), rule(추론 규칙) }

 * ───────────────────────────────────────────────────────────── */

const REL_NAMES = {};

REL_NAMES[POL.POS] = ['즐겁게 지냄', '즐거운 친구로 선택받음'];

REL_NAMES[POL.NEG] = ['불편함을 느낌', '불편하다고 지목됨'];



function buildFacts_(cur, diff) {

  const ids = cur.stats;

  const facts = [];

  const add = (s, p, o, src, rule, extra) => facts.push(Object.assign({ s: s, p: p, o: o, src: src, rule: rule || '', oIsStudent: !!ids[o] }, extra || {}));

  const pk = (a, b) => (a < b ? a + '|' + b : b + '|' + a);

  const tone = pol => (pol === POL.NEG ? '부정' : '긍정');



  // 기본 사실 + ① 역관계

  cur.edges.forEach(e => {

    const meta = { pol: tone(e.pol), tags: e.tags, text: e.text };

    add(e.s, REL_NAMES[e.pol][0], e.o, '설문', '', meta);

    add(e.o, REL_NAMES[e.pol][1], e.s, '추론', '역관계', meta);

  });

  // ② 상호선택 · ③ 엇갈림

  cur.mutualPairs.forEach(p => { add(p[0], '서로 친구', p[1], '추론', '상호선택', { pol: '긍정', pair: true }); add(p[1], '서로 친구', p[0], '추론', '상호선택', { pol: '긍정', pair: true }); });

  cur.mutualNeg.forEach(p => { add(p[0], '서로 불편함', p[1], '추론', '상호선택', { pol: '부정', pair: true }); add(p[1], '서로 불편함', p[0], '추론', '상호선택', { pol: '부정', pair: true }); });

  cur.mixed.forEach(p => { add(p[0], '마음이 엇갈림', p[1], '추론', '엇갈림', { pol: '부정', pair: true }); add(p[1], '마음이 엇갈림', p[0], '추론', '엇갈림', { pol: '부정', pair: true }); });



  // 연결망: 즐거운 관계는 무방향 연결(먼저 고를수록 가중치 큼), 불편 관계는 '부정 쌍'

  const adj = {}, negPair = {}, posOut = {}, mutualSet = {};

  Object.keys(ids).forEach(id => { adj[id] = {}; posOut[id] = {}; mutualSet[id] = {}; });

  cur.edges.forEach(e => {

    if (e.pol === POL.NEG) { negPair[pk(e.s, e.o)] = true; return; }

    const w = Math.max(1, 4 - e.rank);

    posOut[e.s][e.o] = true;

    adj[e.s][e.o] = (adj[e.s][e.o] || 0) + w; adj[e.o][e.s] = (adj[e.o][e.s] || 0) + w;

  });

  cur.mutualPairs.forEach(p => { mutualSet[p[0]][p[1]] = true; mutualSet[p[1]][p[0]] = true; });



  // ④ 공통 친구 → 다리 놓기 후보

  const bridgeMap = {};

  Object.keys(ids).forEach(b => {

    const fr = Object.keys(mutualSet[b]);

    for (let i = 0; i < fr.length; i++) for (let j = i + 1; j < fr.length; j++) {

      const a = fr[i], c = fr[j], k = pk(a, c);

      if (adj[a][c] || negPair[k]) continue;

      (bridgeMap[k] = bridgeMap[k] || { a: k.split('|')[0], c: k.split('|')[1], via: [] }).via.push(b);

    }

  });

  const bridges = Object.keys(bridgeMap).map(k => bridgeMap[k])

    .map(x => Object.assign(x, { need: Math.min(ids[x.a].recvPos, ids[x.c].recvPos) }))

    .sort((x, y) => x.need - y.need || y.via.length - x.via.length).slice(0, 15);

  bridges.forEach(x => {

    add(x.a, '다리 놓기 후보', x.c, '추론', '공통 친구', { via: x.via, pair: true, pol: '긍정' });

    add(x.c, '다리 놓기 후보', x.a, '추론', '공통 친구', { via: x.via, pair: true, pol: '긍정' });

  });



  // ⑤ 한방향 선택 → 연결 기회

  Object.keys(ids).forEach(s => {

    const st = ids[s];

    if (!st.responded || (st.recvPos > 0 && st.mutual > 0)) return;

    Object.keys(posOut[s]).forEach(o => {

      if (!posOut[o][s] && !negPair[pk(s, o)]) add(s, '연결 기회', o, '추론', '한방향 선택', { pol: '긍정' });

    });

  });



  // ⑥ 지난달과 비교

  if (diff) {

    const r = '지난달과 비교';

    diff.newPos.forEach(e => add(e.s, '새로 즐겁게 지냄', e.o, '추론', r, { pol: '긍정', text: e.text }));

    diff.lostPos.forEach(e => add(e.s, '즐거운 관계가 사라짐', e.o, '추론', r, { pol: '부정', text: e.text }));

    diff.newNeg.forEach(e => add(e.s, '새로 불편해짐', e.o, '추론', r, { pol: '부정', text: e.text }));

    diff.resolvedNeg.forEach(e => add(e.s, '불편함이 풀림', e.o, '추론', r, { pol: '긍정', text: e.text }));

    diff.newMutual.forEach(p => { add(p[0], '새로 서로 친구가 됨', p[1], '추론', r, { pol: '긍정', pair: true }); add(p[1], '새로 서로 친구가 됨', p[0], '추론', r, { pol: '긍정', pair: true }); });

    diff.lostMutual.forEach(p => { add(p[0], '서로 친구가 아니게 됨', p[1], '추론', r, { pol: '부정', pair: true }); add(p[1], '서로 친구가 아니게 됨', p[0], '추론', r, { pol: '부정', pair: true }); });

  }



  return { facts: facts, bridges: bridges };

}





/* ─────────────────────────────────────────────────────────────

 * 14. 설문 달 관리 (열기 · 바로 마감 · 마감 예약)

/** 달 설문 열기: 다른 '진행중' 달은 자동 마감, 이 달의 마감 예약은 지웁니다. */

function openMonth(token, month) {

  requireTeacher_(token);

  const lock = LockService.getScriptLock();

  lock.waitLock(20000);

  try {

    month = String(month || '').trim();

    const t = readTable_(SH.MONTH);

    let found = false;

    t.rows.forEach(r => {

      const mo = monthStr_(r['월']);

      if (mo === month) {

        setCell_(SH.MONTH, r._row, t.headers, '상태', '진행중');

        setCell_(SH.MONTH, r._row, t.headers, '마감예약', '', true);

        found = true;

      } else if (cellStr_(r['상태']) === '진행중') setCell_(SH.MONTH, r._row, t.headers, '상태', '마감');

    return { ok: true, month: month };

  } catch (e) {

    return friendlyError_(e);

  } finally {

    lock.releaseLock();

  }

}

/* ─────────────────────────────────────────────────────────────

 * 15. 학생 명단 관리 (학번 · 비밀번호)

 *     새 학생과 [비밀번호 초기화]는 [환경설정]의 학생 초기 비밀번호(없으면 1234)를 쓰고, 학생은 첫 로그인 때 자기 비밀번호로 바꿉니다.

 *     시트에는 비밀번호 원문이 아니라 해시만 저장합니다.

 * ───────────────────────────────────────────────────────────── */



/** 학생 추가. list = [{ studentNo, name }] — 번호는 자동, 비밀번호는 학생 초기 비밀번호 */

function addStudents(token, list) {

  requireTeacher_(token);

  const lock = LockService.getScriptLock();

  lock.waitLock(20000);

  try {

    const m = loadModel_();

    const usedNo = {};

    m.students.forEach(x => { if (x.studentNo) usedNo[x.studentNo] = true; });

    let nextIdNum = m.students.reduce((mx, x) => Math.max(mx, Number(String(x.id).replace(/\D/g, '')) || 0), 0) + 1;

    let nextNumber = m.students.reduce((mx, x) => Math.max(mx, x.number), 0) + 1;

    const h = hashPw_(studentDefaultPassword_());

    const rows = [], skipped = [];

    (list || []).forEach(it => {

      const name = String((it && it.name) || '').trim().slice(0, 20);

      const no = String((it && it.studentNo) || '').trim();

      if (!name) return;

      if (!STUDENT_NO_PATTERN.test(no)) { skipped.push(name + '(학번은 숫자 4~5자리)'); return; }

      if (usedNo[no]) { skipped.push(name + '(학번 ' + no + ' 중복)'); return; }

      usedNo[no] = true;

      const num = nextNumber++;   // 번호는 명단 마지막 번호 다음으로 자동

      rows.push({ '학생ID': 'S' + pad2_(nextIdNum++), '번호': num, '학번': no, '이름': name, '비밀번호해시': h, '초기비번': true, '활성': true });

    });

    if (!rows.length) return { ok: false, message: skipped.length ? '추가하지 못했어요: ' + skipped.join(', ') : '추가할 학생을 입력해 주세요.' };

    appendObjects_(SH.STUDENT, rows);

    return { ok: true, added: rows.length, skipped: skipped };

  } catch (e) {

    return friendlyError_(e);

  } finally {

    lock.releaseLock();

  }

}



/** 학생 정보 수정: 학번·이름 (활성 값으로 명단에서 숨기기도 가능) */

function updateStudent(token, v) {

  requireTeacher_(token);

  try {

    v = v || {};

    const t = readTable_(SH.STUDENT);

    const row = t.rows.filter(r => cellStr_(r['학생ID']) === String(v.id))[0];

    if (!row) return { ok: false, message: '학생을 찾을 수 없어요.' };

    if (v.studentNo !== undefined) {

      const no = String(v.studentNo).trim();

      if (!STUDENT_NO_PATTERN.test(no)) return { ok: false, message: '학번은 숫자 4~5자리로 입력해 주세요.' };

      if (t.rows.some(r => r !== row && cellStr_(r['학번']) === no)) return { ok: false, message: '같은 학번을 쓰는 학생이 이미 있어요.' };

      setCell_(SH.STUDENT, row._row, t.headers, '학번', no, true);

    }

    if (v.name !== undefined) {

      const name = String(v.name).trim().slice(0, 20);

      if (!name) return { ok: false, message: '이름을 입력해 주세요.' };

      setCell_(SH.STUDENT, row._row, t.headers, '이름', name);

    }

    if (v.number !== undefined) setCell_(SH.STUDENT, row._row, t.headers, '번호', Math.max(0, Math.floor(Number(v.number) || 0)));

    if (v.active !== undefined) setCell_(SH.STUDENT, row._row, t.headers, '활성', !!v.active);

    return { ok: true };

  } catch (e) { return friendlyError_(e); }

}

function removeFromRoster(token, id) {

/** html을 담은 모달을 열고, data-close 버튼의 값으로 끝나는 Promise를 돌려줍니다. */

function openModal(html, opts) {

  opts = opts || {};

  return new Promise(resolve => {

    const wrap = document.createElement('div');

    wrap.className = 'fixed inset-0 z-[90] flex items-end justify-center p-3 sm:items-center';

    wrap.innerHTML = `<div class="absolute inset-0 bg-ink/50" data-backdrop></div>

      <div class="relative max-h-[90vh] w-full ${opts.wide ? 'max-w-lg' : 'max-w-sm'} overflow-y-auto rounded-2xl bg-white p-6 shadow-xl" role="dialog" aria-modal="true">${html}</div>`;

    const onKey = e => { if (e.key === 'Escape') close(null); };

    const close = v => { document.removeEventListener('keydown', onKey); wrap.remove(); resolve(v); };

    document.addEventListener('keydown', onKey);

    wrap.querySelector('[data-backdrop]').addEventListener('click', () => close(null));

    wrap.querySelectorAll('[data-close]').forEach(b => b.addEventListener('click', () => {

      const v = b.dataset.close; close(v === 'true' ? true : v === 'false' ? false : v);

    }));

    $('#modal-root').appendChild(wrap);

    if (opts.onMount) opts.onMount(wrap, close);

    const f = wrap.querySelector('input, textarea, select') || wrap.querySelector('[data-close="true"], button');

    if (f) setTimeout(() => f.focus(), 60);

  });

}

        if (res && res.error) { err.textContent = res.error; err.classList.remove('hidden'); return; }

        close(res === undefined ? values : res);

      };

      btn.addEventListener('click', submit);

      wrap.querySelectorAll('input').forEach(i => i.addEventListener('keydown', e => { if (e.key === 'Enter') submit(); }));

      if (o.onMount) o.onMount(wrap, close);

    }

  });

}

function loginError(msg) { const el = $('#login-error'); el.textContent = msg; el.classList.remove('hidden'); }



async function doLogin() {

  const btn = $('#login-btn'), label = btn.textContent;

  const busy = on => { btn.disabled = on; btn.innerHTML = on ? '<span class="spinner"></span>확인하는 중' : esc(label); };

  $('#login-error').classList.add('hidden');

  try {

    if (S.loginRole === 'student') {

      const no = $('#login-no').value.trim(), pw = $('#login-pw').value.trim();

      if (!/^\d{4,5}$/.test(no)) return loginError('학번은 숫자 4~5자리로 입력해 주세요. (예: 1630)');

      if (!pw) return loginError('비밀번호를 입력해 주세요.');

      busy(true);

      const res = await api('enterSurvey', no, pw);

      busy(false);

      if (res.mustChange) return changePasswordFlow(no, pw);

      if (res.locked) { $('#login-pw').value = ''; return mAlert('이미 제출한 설문이에요', res.message); }

      if (!res.ok) return loginError(res.message);

      $('#login-pw').value = '';

      startSurvey({ data: res, no, pw });

    } else {

      const pin = $('#login-pin').value.trim();

      if (!pin) return loginError('교사 비밀번호를 입력해 주세요.');

      busy(true);

      const res = await api('teacherLogin', pin);

      busy(false);

      if (!res.ok) return loginError(res.message);

      $('#login-pin').value = '';

      S.token = res.token;

      try { sessionStorage.setItem('rm_token', res.token); } catch (e) {}

      enterTeacher();

    }

  } catch (e) {

    busy(false);

    loginError(String((e && e.message) || e).replace(/^(Exception|Error):\s*/, '') || '서버와 연결하지 못했어요.');

  }

}



/** 초기 비밀번호로 들어온 학생: 새 비밀번호(띄어쓰기 없이 4~20자)를 정한 뒤 설문으로 */

async function changePasswordFlow(no, oldPw) {

  const r = await mForm({

    title: '나만의 비밀번호로 바꿔 주세요',

    message: '처음 로그인했거나 선생님이 비밀번호를 초기화했어요. 다른 친구가 내 학번으로 들어오지 못하도록 새 비밀번호를 정해 주세요. 영문·숫자·기호를 섞어 띄어쓰기 없이 4~20자로 쓸 수 있어요.',

    fields: [

      { name: 'p1', label: '새 비밀번호 (띄어쓰기 없이 4~20자)', type: 'password', maxlength: 20 },

      { name: 'p2', label: '새 비밀번호 한 번 더', type: 'password', maxlength: 20 }

    ],

    submit: '바꾸고 설문 시작',

    onSubmit: async v => {

      if (!/^\S{4,20}$/.test(v.p1)) return { error: '띄어쓰기 없이 4~20자로 정해 주세요.' };

      if (v.p1 !== v.p2) return { error: '두 칸의 비밀번호가 서로 달라요.' };

      const res = await api('changeStudentPassword', no, oldPw, v.p1);

      if (!res.ok) return { error: res.message };

      return { ok: true, pw: v.p1 };

    }

  });

  if (!r || !r.ok) return;

  toast('비밀번호를 바꿨어요. 잊지 않게 기억해 두세요.');

  $('#login-pw').value = r.pw;

  doLogin();

}

function bindSurveyEvents() {

  const sv = S.sv, root = $('#sv-questions');

  paintClimate();

  root.addEventListener('click', e => {

    if (sv.done || sv.submitting) return;

    const tag = e.target.closest('[data-tag]');

    if (tag) {

      const it = sv.answers[tag.dataset.tq].find(x => x.id === tag.dataset.id), t = tag.dataset.tag, k = it.tags.indexOf(t);

      if (k >= 0) it.tags.splice(k, 1); else it.tags.push(t);

      tag.setAttribute('aria-pressed', k < 0);

      document.querySelector(`[data-qerr="${tag.dataset.tq}"]`).classList.add('hidden');

      setDirty(true);

      return;

    }

    const pill = e.target.closest('[data-pick]');

    if (pill && !pill.disabled) {

      const key = pill.dataset.pick, id = pill.dataset.id, q = sv.data.config.questions.find(x => x.key === key);

      const list = sv.answers[key], i = list.findIndex(x => x.id === id);

      if (i >= 0) list.splice(i, 1);

      else if (list.length >= q.max) return toast(`${q.max}명까지 고를 수 있어요`, true);

      else list.push({ id, tags: [], text: '' });

      renderPills(key); renderReasons(key);

      if (key === 'positive') renderPills('negative');

      if (key === 'negative') renderPills('positive');

      document.querySelector(`[data-qerr="${key}"]`).classList.add('hidden');

      // 다시 그린 뒤에도 키보드 위치를 잃지 않도록 같은 이름 버튼에 초점을 돌려줍니다

      const again = document.querySelector(`[data-pick="${key}"][data-id="${CSS.escape(id)}"]`);

      if (again) again.focus({ preventScroll: true });

      setDirty(true);

      return;

    }

    const cl = e.target.closest('[data-climate]');

    if (cl) { sv.climate = Number(cl.dataset.climate); paintClimate(); document.querySelector('[data-qerr="climate"]').classList.add('hidden'); setDirty(true); }

  });

  root.addEventListener('input', e => {

    const t = e.target;

    if (t.dataset.reason) { const it = sv.answers[t.dataset.reason].find(x => x.id === t.dataset.id); if (it) it.text = t.value; }

    if (t.id === 'sv-climate-reason') sv.climateReason = t.value;

    setDirty(true);

  });

  $('#sv-submit').onclick = submitSurveyAnswers;

}



/** 제출 전 확인: 고른 친구마다 분류 태그와 자세한 이유가 있는지, 분위기 점수를 골랐는지 */

function validateSurvey() {

  const sv = S.sv, errs = [];

  const nm = id => (sv.data.classmates.find(c => c.id === id) || {}).name;

  const ce = document.querySelector('[data-qerr="climate"]');

  if (!sv.climate) { ce.textContent = '우리 반 분위기 점수를 하나 골라 주세요.'; ce.classList.remove('hidden'); errs.push('climate'); }

  else ce.classList.add('hidden');

  sv.data.config.questions.forEach(q => {

    const noTag = sv.answers[q.key].filter(x => !x.tags.length).map(x => nm(x.id));

    const noText = sv.answers[q.key].filter(x => !x.text.trim()).map(x => nm(x.id));

    const el = document.querySelector(`[data-qerr="${q.key}"]`);

    const msg = [noTag.length ? `${noTag.join(', ')}: 이유 분류를 하나 이상 골라 주세요.` : '', noText.length ? `${noText.join(', ')}: 자세한 이유를 적어 주세요.` : ''].filter(Boolean).join(' ');

    if (msg) { el.textContent = msg; el.classList.remove('hidden'); errs.push(q.key); }

    else el.classList.add('hidden');

  });

  if (errs.length) document.querySelector(`[data-q="${errs[0]}"]`).scrollIntoView({ behavior: 'smooth', block: 'start' });

  return !errs.length;

}



async function submitSurveyAnswers() {

  if (!sv.answers.positive.length && !(await mConfirm('2번에서 친구를 고르지 않았어요', '요즘 함께 즐겁게 지내는 친구가 아직 없다면 그대로 제출해도 괜찮아요.', { ok: '그대로 제출', cancel: '다시 볼게요' }))) return;

  sv.submitting = true;

  btn.disabled = true; btn.innerHTML = '<span class="spinner"></span>제출하는 중';

  $('#sv-exit').disabled = true;

  let res;

  try { res = await api('submitSurvey', sv.no, sv.pw, payload); }

  catch (e) { res = { ok: false, message: String((e && e.message) || e) }; }

  finally {

    sv.submitting = false;

    $('#sv-exit').disabled = false;

    if (btn.isConnected) { btn.disabled = false; btn.textContent = '응답 제출'; }

  }

  if (!res.ok) return mAlert('제출하지 못했어요', res.message);

  setDirty(false);

  clearTimeout(surveyCloseTimer);

  sv.done = true; sv.pw = '';   // 비밀번호는 제출 후 바로 지웁니다

  $('#sv-panel').innerHTML = `

    <div class="px-2 py-10 text-center">

        if (!r.ok) { err.textContent = r.message; err.classList.remove('hidden'); return; }

    }

/* ── 응답 엑셀 (SheetJS): 학생별 응답 · 관계 목록 · 학생별 요약 ── */

function downloadResponsesXlsx() {

  if (!window.XLSX) return mAlert('엑셀 도구를 불러오지 못했어요', '인터넷 연결을 확인하고 새로고침한 뒤 다시 시도해 주세요.');

  const d = S.data, cur = d && d.cur, qs = d ? d.config.questions : [];

  if (!cur) return;

  const stu = id => d.students.find(x => x.id === id) || { studentNo: '', name: nameOf(id), number: '' };

  const cell = (id, pol) => cur.edges.filter(e => e.s === id && e.pol === pol).sort((a, b) => a.rank - b.rank)

    .map(e => `${nameOf(e.o)} [${(e.tags || []).join(', ')}] ${e.text}`).join('\n');

  const sheet1 = [['학번', '이름', '제출', '1. 분위기 점수', '분위기 이유'].concat(qs.map((q, i) => `${i + 2}. ${POL_STYLE[q.pol].label}`))];

  d.students.forEach(s => {

    const st = cur.stats[s.id];

    sheet1.push([s.studentNo, s.name, st.responded ? 'O' : '', st.climate || '', st.climateReason || ''].concat(qs.map(q => cell(s.id, q.pol))));

  });

  const sheet2 = [['응답 학번', '응답 이름', '구분', '순서', '대상 학번', '대상 이름', '분류', '이유']];

  cur.edges.slice().sort((a, b) => String(stu(a.s).studentNo).localeCompare(String(stu(b.s).studentNo), 'ko', { numeric: true }) || a.pol.localeCompare(b.pol) || a.rank - b.rank)

    .forEach(e => sheet2.push([stu(e.s).studentNo, stu(e.s).name, POL_STYLE[e.pol].label, e.rank, stu(e.o).studentNo, stu(e.o).name, (e.tags || []).join(', '), e.text]));

  const sheet3 = [['학번', '이름', '받은 즐거운 선택', '서로 친구', '받은 불편 응답', '분위기 점수']];

  d.students.forEach(s => { const st = cur.stats[s.id]; sheet3.push([s.studentNo, s.name, st.recvPos, st.mutual, st.recvNeg, st.climate || '']); });

  const wb = XLSX.utils.book_new();

  const add = (rows, name, widths) => { const ws = XLSX.utils.aoa_to_sheet(rows); ws['!cols'] = widths.map(w => ({ wch: w })); XLSX.utils.book_append_sheet(wb, ws, name); };

  add(sheet1, '학생별 응답', [10, 10, 6, 12, 40, 50, 50]);

  add(sheet2, '관계 목록', [10, 10, 22, 6, 10, 10, 30, 50]);

  add(sheet3, '학생별 요약', [10, 10, 14, 10, 14, 10]);

  XLSX.writeFile(wb, `관계설문_${S.month}.xlsx`);

  toast('엑셀 파일을 내려받았어요');

}



/* ═══════════════════════════════════════════════════════════════

 *  6. 지도 탭: 칠판 관계지도 + 학생 강조

 * ═══════════════════════════════════════════════════════════════ */

function renderMap() {

  const cur = S.data.cur, d = S.data.diff;

  $('#map-empty').hidden = true;

  $('#map-body').hidden = false;

  const prevT = d ? S.data.months.find(x => x.month === d.prevMonth) : null;

  const delta = (a, b, goodUp, digits) => {

    if (!prevT || a == null || b == null) return '';

    const x = Math.round((a - b) * 10) / 10;

    if (!x) return '<p class="mt-0.5 text-[11px] font-semibold text-ink-muted">지난달과 같아요</p>';

    return `<p class="mt-0.5 text-[11px] font-bold ${(goodUp ? x > 0 : x < 0) ? 'text-board' : 'text-stamp'}">지난달보다 ${x > 0 ? '+' : ''}${digits ? x.toFixed(1) : x}</p>`;

  };

  const stat = (label, value, unit, sub) => `<div class="stat"><p class="text-xs font-bold text-ink-muted">${label}</p>

    <p class="mt-0.5 text-2xl font-extrabold tabular-nums">${value}<span class="ml-0.5 text-sm font-semibold text-ink-muted">${unit}</span></p>${sub || ''}</div>`;

  const negCount = cur.edges.filter(e => e.pol === POL.NEG).length;

  $('#map-stats').innerHTML =

    stat('설문 응답', `${cur.responded}/${cur.total}`, '명') +

    stat('서로 친구', cur.mutualPairs.length, '쌍', delta(cur.mutualPairs.length, prevT && prevT.mutual, true)) +

    stat('불편 응답', negCount, '건', delta(negCount, prevT && prevT.neg, false)) +

    stat('학급 분위기', cur.climate.avg == null ? '-' : cur.climate.avg.toFixed(1), '/ 5', delta(cur.climate.avg, prevT && prevT.climateAvg, true, true));

  renderMapControls(); renderLegend(); renderBelowMap();

  if (S.netDirty || !S.net) buildNetwork();

  else { S.net.setSize('100%', '100%'); S.net.redraw(); refreshGraph(); }   // 다른 탭에서 돌아왔을 때 크기 다시 맞춤

}

/* ── 칠판 위 관계지도 (vis-network) ──

 *  즐거운 관계만 보이지 않는 '배치용 선'으로 당겨 자리를 잡고(불편한 관계는 끌어당기지 않음),

 *  자리를 잡은 뒤에는 물리 계산을 꺼서 보기 방식·필터를 바꾸거나 달을 바꿔도 학생 자리가 움직이지 않습니다. */

let layoutSeed = 11;

const NETWORK_OPTIONS = {

  autoResize: true,

  nodes: { shape: 'dot', scaling: { min: 10, max: 30, label: { enabled: false } } },

  edges: { smooth: { enabled: true, type: 'curvedCW', roundness: 0.16 }, selectionWidth: 0, hoverWidth: 0.6 },

  physics: {

    enabled: true, solver: 'forceAtlas2Based', minVelocity: 0.8,

    forceAtlas2Based: { gravitationalConstant: -85, centralGravity: 0.01, springLength: 140, springConstant: 0.06, damping: 0.5, avoidOverlap: 0.8 },

    stabilization: { enabled: true, iterations: 600, updateInterval: 40, fit: false }

  },

  interaction: { hover: true, tooltipDelay: 120, keyboard: false, selectConnectedEdges: false }

};

const edgeColor = (color, opacity) => ({ color, highlight: color, hover: color, opacity });



/** 별(노드): 이번 달 모드는 관계 상태로, 비교 모드는 받은 선택의 증감으로 분필 색칠 */

function makeNodes() {

  const cur = S.data.cur, diff = S.data.diff, dmap = {};

  if (diff) diff.students.forEach(x => { dmap[x.id] = x; });

  return S.data.students.map(s => {

    const st = cur.stats[s.id];

    let bg, title, border = CH.board, bw = 2;

    if (S.mode === 'diff' && diff) {

      const x = dmap[s.id], dd = x.curPos - x.prevPos;

      bg = dd > 0 ? CH.green : dd < 0 ? CH.red : CH.chalk;

      title = `${s.name}: 받은 선택 ${x.prevPos} → ${x.curPos}`;

    } else {

      // 불편 응답 2건 이상 = 진한 빨강, 선택받지 못함 = 회색, 둘 다면 진한 빨강 + 굵은 회색 테두리

      const isolated = cur.responded && st.recvPos === 0, manyNeg = st.recvNeg >= 2;

      bg = manyNeg ? CH.darkRed : isolated ? CH.gray : st.mutual > 0 ? CH.yellow : CH.chalk;

      border = manyNeg && isolated ? CH.gray : CH.board;

      bw = manyNeg && isolated ? 5 : 2;

      title = `${s.name}: 받은 선택 ${st.recvPos}, 서로 친구 ${st.mutual}, 불편 응답 ${st.recvNeg}`;

    }

    return {

      id: s.id, label: s.name, value: 1 + st.recvPos, title: tooltip([title]), borderWidth: bw,

      color: { background: bg, border: border, highlight: { background: bg, border: CH.yellow }, hover: { background: bg, border: CH.yellow } },

      font: { color: CH.chalk, size: 14, face: 'Pretendard', strokeWidth: 4, strokeColor: CH.board }

    };

  });

}



/** 선(엣지): 누르면 보여줄 이유를 S.edgeInfo에 담아 둡니다. */

function makeEdges() {

  S.edgeInfo = {};

  const edges = [];

  let n = 0;

  const push = (edge, info) => { const id = 'e' + (n++); edge.id = id; edge.physics = false; S.edgeInfo[id] = info; edges.push(edge); };

  const short = e => (e.text ? '“' + e.text + '”' : '');

  const arrow = { to: { enabled: true, scaleFactor: 0.45 } };



  if (S.mode === 'month') {

    const es = S.data.cur.edges, has = {}, done = {};

    es.forEach(e => { has[e.s + '|' + e.o + '|' + e.pol] = e; });

    es.forEach(e => {

      const rev = has[e.o + '|' + e.s + '|' + e.pol];

      if (e.pol === POL.POS) {

        if (rev) {

          const k = [e.s, e.o].sort().join('|'); if (done[k]) return; done[k] = 1;

          if (!S.filters.pos && !S.filters.mutualOnly) return;

          push({ from: e.s, to: e.o, width: 3.6, color: edgeColor(CH.yellow, 0.95), title: tooltip([`${nameOf(e.s)} ↔ ${nameOf(e.o)}: 서로 친구`]) }, { title: '서로 친구예요', list: [e, rev] });

        } else if (S.filters.pos && !S.filters.mutualOnly) {

          push({ from: e.s, to: e.o, arrows: arrow, width: [0, 2.2, 1.6, 1.2][e.rank] || 1.2, color: edgeColor(CH.posBlue, 0.85), title: tooltip([`${nameOf(e.s)} → ${nameOf(e.o)}: ${short(e)}`]) }, { title: '즐겁게 지내는 친구로 골랐어요', list: [e] });

        }

      } else if (S.filters.mutualOnly) {

        return;

      } else if (e.pol === POL.NEG && S.filters.neg) {

        push({ from: e.s, to: e.o, arrows: arrow, width: 2, dashes: [6, 5], color: edgeColor(CH.red, 1), title: tooltip([`${nameOf(e.s)} → ${nameOf(e.o)}: ${short(e)}`]) }, { title: '마음이 불편하다고 답했어요', list: [e] });

      }

    });

  } else {

    const d = S.data.diff, f = S.diffFilters;

    const add = (list, style, info) => list.forEach(e => push(Object.assign({ from: e.s, to: e.o, arrows: arrow, title: tooltip([`${nameOf(e.s)} → ${nameOf(e.o)}: ${info}`]) }, style), { title: info, list: [e] }));

    if (f.kept) {

      add(d.keptPos, { width: 1, color: edgeColor(CH.posBlue, 0.3) }, '두 달 연속 즐거운 관계');

      add(d.keptNeg, { width: 1, dashes: [6, 5], color: edgeColor(CH.red, 0.45) }, '두 달 연속 불편한 관계');

    }

    if (f.removed) {

      add(d.lostPos, { width: 1.6, dashes: [6, 6], color: edgeColor(CH.gray, 1) }, '지난달엔 즐거운 관계였지만 이번 달엔 고르지 않았어요');

      add(d.resolvedNeg, { width: 1.6, dashes: [2, 5], color: edgeColor(CH.green, 0.8) }, '지난달 불편했던 관계가 풀렸어요');

    }

    if (f.added) {

      add(d.newPos, { width: 3, color: edgeColor(CH.green, 1) }, '새로 생긴 즐거운 관계');

      add(d.newNeg, { width: 3, dashes: [6, 5], color: edgeColor(CH.red, 1) }, '새로 생긴 불편한 관계');

    }

  }

  return edges;

}



/** 배치용 선: 즐거운 관계만, 서로 고르거나 먼저 고를수록 가깝게 (그리지는 않음) */

function makeLayoutEdges() {

  const weight = new Map();

  S.data.cur.edges.forEach(e => {

    if (e.pol !== POL.POS) return;

    const key = e.s < e.o ? `${e.s}|${e.o}` : `${e.o}|${e.s}`;

    weight.set(key, (weight.get(key) || 0) + Math.max(1, 4 - e.rank));

  });

  return [...weight.entries()].map(([key, w]) => { const [a, b] = key.split('|'); return { id: `L|${key}`, from: a, to: b, hidden: true, physics: true, length: Math.max(70, 150 - w * 14) }; });

}



/**

 * 학생 강조: 선택한 학생과 직접 이어진 친구·선은 또렷하게, 나머지는 분필 자국처럼 흐리게.

 * 지금 켜 둔 관계 종류(필터)의 선을 기준으로 이어진 친구를 찾습니다.

 */

function graphData() {

  const nodes = makeNodes(), edges = makeEdges(), f = S.focusId;

  if (!f) return { nodes, edges };

  const near = new Set([f]);

  edges.forEach(e => { if (e.from === f) near.add(e.to); if (e.to === f) near.add(e.from); });

  edges.forEach(e => {

    if (e.from === f || e.to === f) { e.width = (e.width || 1) + 1.2; e.color = Object.assign({}, e.color, { opacity: 1 }); }

    else e.color = Object.assign({}, e.color, { opacity: 0.06 });

  });

  const faint = 'rgba(243,240,228,0.12)';

  nodes.forEach(nd => {

    if (nd.id === f) {

      nd.borderWidth = 5;

      nd.color = Object.assign({}, nd.color, { border: CH.yellow });

      nd.font = Object.assign({}, nd.font, { size: 17, color: CH.yellow });

    } else if (!near.has(nd.id)) {

      nd.color = { background: faint, border: 'rgba(243,240,228,0.18)', highlight: { background: faint, border: CH.yellow }, hover: { background: 'rgba(243,240,228,0.3)', border: CH.yellow } };

      nd.font = Object.assign({}, nd.font, { color: 'rgba(243,240,228,0.25)', strokeWidth: 0 });

    }

  });

  return { nodes, edges };

}



function refreshGraph() {

  if (!S.data || !S.data.cur || S.tab !== 'map') return;

  if (!S.net || S.netDirty) return buildNetwork();

  const g = graphData();

  S.nodesDS.update(g.nodes);

  S.edgesDS.clear();

  S.edgesDS.add(makeLayoutEdges().concat(g.edges));

}



/** 그래프 만들기: 기억해 둔 위치를 써서 달을 바꿔도 학생 자리가 그대로예요. */

function buildNetwork() {

  const box = $('#network');

  if (S.net) { S.net.destroy(); S.net = null; }

  S.netDirty = false;

  S.netReady = null;

  if (!window.vis) { box.innerHTML = '<p class="p-6 text-chalk">그래프 도구를 불러오지 못했어요. 인터넷 연결을 확인하고 새로고침해 주세요.</p>'; return; }

  if (!S.data.students.length) { box.innerHTML = '<p class="p-6 text-chalk">아직 학생이 없어요. 관리 탭에서 학생 명단을 추가해 주세요.</p>'; return; }

  box.innerHTML = '';

  const g = graphData(), saved = loadPositions();

  const placed = g.nodes.filter(nd => saved[nd.id]).map(nd => nd.id), allPlaced = placed.length === g.nodes.length;

  // 자리가 있는 학생은 붙잡아 두고, 새로 들어온 학생만 빈자리를 찾게 합니다

  g.nodes.forEach(nd => { const p = saved[nd.id]; if (p) { nd.x = p.x; nd.y = p.y; if (!allPlaced) nd.fixed = true; } });

  S.nodesDS = new vis.DataSet(g.nodes);

  S.edgesDS = new vis.DataSet(makeLayoutEdges().concat(g.edges));

  const options = Object.assign({}, NETWORK_OPTIONS, { layout: { improvedLayout: true, randomSeed: layoutSeed } }, allPlaced ? { physics: { enabled: false } } : {});

  const net = S.net = new vis.Network(box, { nodes: S.nodesDS, edges: S.edgesDS }, options);

  if (allPlaced) { fitNetwork(false); S.netReady = Promise.resolve(); }

  else S.netReady = new Promise(done => {

    net.once('stabilizationIterationsDone', () => {

      if (S.net === net) {

        net.setOptions({ physics: { enabled: false } });

        if (placed.length) S.nodesDS.update(placed.map(id => ({ id, fixed: false })));

        savePositions();

        fitNetwork(false);

      }

      done();

    });

    setTimeout(done, 4000);

  });

  net.on('dragEnd', p => { if (p.nodes.length) savePositions(); });

  // 학생을 누르면 강조 + 정보창, 선을 누르면 이유, 빈 곳을 누르면 강조 해제

  net.on('click', p => {

    if (p.nodes.length) return p.nodes[0] === S.focusId ? clearFocus() : focusStudent(p.nodes[0]);   // 같은 학생을 다시 누르면 선택 해제

    if (p.edges.length && S.edgeInfo[p.edges[0]]) return showEdgeInfo(S.edgeInfo[p.edges[0]]);

    if (drawerId || S.focusId) clearFocus();

  });

  if (S.focusId) net.selectNodes([S.focusId]);

}



/** 칠판을 채우도록 맞춤 (vis 기본값은 1배보다 크게 키우지 않아 그림이 작게 모입니다) */

function fitNetwork(animate) {

  if (S.net) S.net.fit({ maxZoomLevel: 1.4, animation: animate ? { duration: 400, easingFunction: 'easeInOutQuad' } : false });

}



/* 학생 자리는 이 기기에 기억합니다 (끌어 옮긴 자리도) */

const POSITION_STORE_KEY = 'relationmap:pos';

function loadPositions() {

  if (!S.positions) {

    let saved = {};

    try { saved = JSON.parse(localStorage.getItem(POSITION_STORE_KEY) || '{}') || {}; } catch (e) { saved = {}; }

    S.positions = saved;

  }

  return S.positions;

}

function savePositions() {

  if (!S.net) return;

  const all = Object.assign({}, loadPositions(), S.net.getPositions());

  S.positions = all;

  try { localStorage.setItem(POSITION_STORE_KEY, JSON.stringify(all)); } catch (e) { /* 저장 공간이 없어도 지도는 그대로 씁니다 */ }

}



$('#btn-fit').addEventListener('click', () => fitNetwork(true));

$('#btn-relayout').addEventListener('click', () => {

  if (!S.data || !S.data.cur) return;

  S.positions = {};

  try { localStorage.removeItem(POSITION_STORE_KEY); } catch (e) { /* 무시 */ }

  layoutSeed = Math.floor(Math.random() * 100000);

  buildNetwork();

});



/** 지도에서 학생 강조 + 오른쪽 Drawer 열기 (center: 지도를 그 학생 쪽으로 옮김) */

async function focusStudent(id, opts) {

  opts = opts || {};

  if (!S.data || !S.data.cur || !S.data.cur.stats[id]) return;

  S.focusId = id;

  if (S.tab !== 'map') switchTab('map');

  else { refreshGraph(); renderBelowMap(); }

  openDrawer(id);

  if (S.netReady) await S.netReady;

  if (!S.net || S.focusId !== id) return;

  S.net.selectNodes([id]);

  if (opts.center) S.net.focus(id, { scale: Math.max(S.net.getScale(), 1), animation: { duration: 450 } });

}



/** 강조 해제 + Drawer 닫기 */

function clearFocus() {

  if (drawerId) return closeDrawer();

  S.focusId = null;

  refreshGraph(); renderBelowMap();

  if (S.net) S.net.unselectAll();

}

function sectionTable(icon, title, note, tone, head, rows, unit, count) {

  if (!rows.length) return '';

  const toneBox = tone === 'neg' ? 'border-stamp/40' : tone === 'good' ? 'border-board/40' : '';

  const toneHead = tone === 'neg' ? 'bg-stamp-soft' : tone === 'good' ? 'bg-board-soft' : 'bg-page/50';

  const toneText = tone === 'neg' ? 'text-stamp' : tone === 'good' ? 'text-board' : '';

  return `<section class="panel overflow-hidden ${toneBox}">

    <div class="flex flex-wrap items-baseline gap-x-2 border-b border-line px-4 py-3 ${toneHead}">

      <h3 class="font-extrabold ${toneText}">${icon} ${title}</h3>

      ${unit === false ? '' : `<span class="text-sm font-bold text-ink-muted">${count == null ? rows.length : count}${unit || '건'}</span>`}

      ${note ? `<span class="basis-full text-xs text-ink-muted">${note}</span>` : ''}

    </div>

    <div class="overflow-x-auto"><table class="w-full min-w-[520px] text-sm">

      <thead><tr>${head.map(h => `<th class="th">${h}</th>`).join('')}</tr></thead>

      <tbody>${rows.join('')}</tbody></table></div>

  </section>`;

}

let drawerId = null;

function openDrawer(id) {

  if (!S.data || !S.data.cur || !S.data.students.some(x => x.id === id)) return;

  const d = $('#drawer'), wasOpen = !!drawerId, top = d.scrollTop, same = drawerId === id;

  drawerId = id;

  d.innerHTML = detailHtml(id);

  d.scrollTop = same ? top : 0;   // 다시 그릴 때는 읽던 자리를 지킵니다

  d.classList.remove('hidden');

  void d.offsetWidth;   // 숨김을 푼 자리를 먼저 계산해야 미끄러져 들어오는 효과가 보여요

  d.classList.add('open');

  if (!wasOpen) setTimeout(() => { const c = d.querySelector('[data-drawer-close]'); if (c) c.focus(); }, 80);

}

function closeDrawer() {

  if (!drawerId) return;

  drawerId = null;

  const d = $('#drawer');

  d.classList.remove('open');

  setTimeout(() => { if (!drawerId) { d.classList.add('hidden'); d.innerHTML = ''; } }, 260);

  if (S.focusId) { S.focusId = null; if (S.data && S.data.cur) { refreshGraph(); renderBelowMap(); } if (S.net) S.net.unselectAll(); }

}

$('#drawer').addEventListener('click', e => {

  if (e.target.closest('[data-go-map]') && drawerId) focusStudent(drawerId, { center: true });

});

async function toggleEditPermission(id, allow) {

  const name = nameOf(id);

  const ok = await mConfirm(allow ? `${name} 학생에게 수정 권한을 줄까요?` : `${name} 학생의 수정 권한을 거둘까요?`,

          : '학생이 더 이상 지난 답을 불러올 수 없어요.', { ok: allow ? '권한 주기' : '권한 거두기' });

  if (!ok) return;

  const r = await call('setEditPermission', S.token, S.month, id, allow);

  if (!r) return;

  if (!r.ok) return mAlert('바꾸지 못했어요', r.message);

  toast(allow ? `${name} 학생에게 수정 권한을 줬어요` : '수정 권한을 거뒀어요');

  await loadDashboard(S.month);

}

function suggestMonth() {

  const now = new Date();

  const thisMonth = `${now.getFullYear()}-${String(now.getMonth() + 1).padStart(2, '0')}`;

  const ms = S.data.months.map(x => x.month);

  if (!ms.includes(thisMonth)) return thisMonth;

  const last = ms[ms.length - 1], y = Number(last.slice(0, 4)), mo = Number(last.slice(5, 7));

  return mo === 12 ? `${y + 1}-01` : `${y}-${String(mo + 1).padStart(2, '0')}`;

}

/** 붙여넣은 줄 → 명단 항목 (「학번 이름」, 「이름 학번」, 「번호 학번 이름」 · 탭·쉼표·띄어쓰기 구분) */

function parseRosterLines(text) {

  const entries = [], problems = [];

  String(text || '').split(/\r?\n/).forEach((line, index) => {

    const tokens = line.trim().split(/[\s,;]+/).filter(Boolean);

    if (!tokens.length) return;

    let studentNo = '', nameTokens = [];

    if (tokens.length >= 3 && /^\d{1,2}$/.test(tokens[0]) && /^\d{4,5}$/.test(tokens[1])) { studentNo = tokens[1]; nameTokens = tokens.slice(2); }

    else if (tokens.length >= 2 && /^\d{4,5}$/.test(tokens[0])) { studentNo = tokens[0]; nameTokens = tokens.slice(1); }

    else if (tokens.length >= 2 && /^\d{4,5}$/.test(tokens[tokens.length - 1])) { studentNo = tokens[tokens.length - 1]; nameTokens = tokens.slice(0, -1); }

    else { problems.push(`${index + 1}번째 줄: ${line.trim().slice(0, 30)}`); return; }

    const name = nameTokens.join(' ').trim();

    if (!name || name.length > 20) problems.push(`${index + 1}번째 줄: 이름은 1~20자로 적어 주세요.`);

    else entries.push({ studentNo, name });

  });

  return { entries, problems };

}

    $('modalRoot').classList.remove('flex');

    const r = modalResolve;

    modalResolve = null;

    if (r) r(value);

  }

  function badge(text, tone) {

    const cls = {

      required: 'bg-stamp-soft text-stamp', optional: 'bg-page text-ink-muted',

      done: 'bg-board-soft text-board', todo: 'text-ink-muted ring-1 ring-inset ring-line'

    }[tone];

    return `<span class="inline-flex items-center rounded-full px-2 py-0.5 text-xs font-bold ${cls}">${esc(text)}</span>`;

  }

  function statusBadges(item) {

    return (item.required ? badge('필수', 'required') : badge('선택', 'optional')) +

      (item.registered ? badge('등록됨', 'done') : badge('미등록', 'todo'));

  }

  function patternError(item, value) {

    if (!value || !item.pattern) return '';

    try { return new RegExp(item.pattern).test(value) ? '' : (item.patternMessage || '형식이 올바르지 않아요.'); }

    catch (e) { return ''; }

  }

  function setFieldError(id, message) {

    const el = $(id);

    if (!el) return;

    el.textContent = message || '';

    el.classList.toggle('hidden', !message);

  }

  function toggleEye(inputId, btn) {

    const input = $(inputId);

    const show = input.type === 'password';

    input.type = show ? 'text' : 'password';

    btn.innerHTML = show ? EYE_OFF : EYE_ON;

    btn.setAttribute('aria-label', show ? '값 숨기기' : '값 보기');

  }



  /** 입력칸 공통 동작: 붙여넣으면 앞뒤 공백 제거, 입력하는 즉시 형식 검사, Enter로 실행 */

  function bindField(inputId, item, errorId, onEnter) {

    const input = $(inputId);

    if (!input) return;

    const check = () => setFieldError(errorId, patternError(item, input.value.trim()));

    input.addEventListener('paste', () => setTimeout(() => { input.value = input.value.trim(); check(); }, 0));

    input.addEventListener('input', check);

    input.addEventListener('keydown', e => { if (e.key === 'Enter') { e.preventDefault(); onEnter(); } });

  }



  /** 입력칸 HTML (password 타입이면 눈 아이콘 포함) */

  function inputHtml(id, item, extraClass) {

    const isPw = item.type === 'password';

    return `

      <div class="relative ${extraClass || ''}">

        <input id="${id}" type="${isPw ? 'password' : 'text'}" autocomplete="off" spellcheck="false"

          placeholder="${esc(item.placeholder)}" class="field ${isPw ? 'pr-12' : ''}">

        ${isPw ? `<button type="button" onclick="toggleEye('${id}', this)" aria-label="값 보기"

          class="absolute bottom-0 right-0 top-1.5 flex items-center px-3.5 text-ink-muted hover:text-ink">${EYE_ON}</button>` : ''}

      </div>`;

  }



  // ---------------- 시작: 등록 현황 + 이어서 할 단계 불러오기 ----------------

  async function init() {

    try {

      const results = await Promise.all([call('getPropertyStatus'), call('getSetupProgress')]);

      items = results[0];

      const progress = results[1];

      // 아직 등록하지 않은 필수 항목이 있으면 그 단계부터, 모두 등록했으면 요약 화면부터

      const idx = items.findIndex(i => i.step === progress.nextStep);

      stepIndex = progress.nextStep && idx > -1 ? idx : items.length;

      $('loadingBox').classList.add('hidden');

      $('modeToggle').classList.remove('hidden');

      render();

    } catch (e) {

      $('loadingBox').innerHTML = `<p class="font-bold text-stamp">등록 현황을 불러오지 못했어요.</p><p class="mt-1">${esc(errMsg(e))}</p>`;

    }

  }



  function render() {

    const isWizard = mode === 'wizard';

    $('wizardView').classList.toggle('hidden', !isWizard);

    $('listView').classList.toggle('hidden', isWizard);

    $('modeToggle').textContent = isWizard ? '한 번에 보기' : '단계별로 보기';

    if (isWizard) renderWizard(); else renderList();

  }



  function toggleMode() {

    mode = mode === 'wizard' ? 'list' : 'wizard';

    render();

  }



  // ---------------- 위저드 (한 화면에 한 항목) ----------------

  function renderWizard() {

    const total = items.length;

    const onSummary = stepIndex >= total;

    const pct = Math.round((((onSummary ? total : stepIndex) + 1) / (total + 1)) * 100);   // 1단계부터 막대가 조금 채워져 보이도록

    const head = `

      <div class="mb-3">

        <div class="flex items-center justify-between text-xs font-bold text-ink-muted">

          <span>${onSummary ? '등록 현황 요약' : `${stepIndex + 1} / ${total} 단계`}</span>

          <span>${items.filter(i => i.registered).length}개 등록됨</span>

        </div>

        <div class="mt-1.5 h-1.5 overflow-hidden rounded-full bg-white ring-1 ring-line">

          <div class="h-full rounded-full bg-board transition-all duration-300" style="width:${pct}%"></div>

        </div>

      </div>`;

    $('wizardView').innerHTML = head + (onSummary ? summaryHtml() : stepHtml(items[stepIndex]));

    if (!onSummary) {

      bindField('propInput', items[stepIndex], 'propError', nextStep);

      setTimeout(() => { if ($('propInput')) $('propInput').focus(); }, 30);

    }

  }



  function stepHtml(item) {

    const isLast = stepIndex === items.length - 1;

    return `

      <div class="panel p-5">

        <div class="flex flex-wrap items-center gap-1.5">${statusBadges(item)}</div>

        <h2 class="mt-3 text-xl font-extrabold">${esc(item.label)}</h2>

        <p class="mt-1.5 text-sm leading-relaxed text-ink-muted">${esc(item.hint)}</p>

        ${item.docUrl ? `<a href="${esc(item.docUrl)}" target="_blank" rel="noopener" class="mt-2 inline-block text-sm font-bold text-board underline underline-offset-2">발급 페이지 새 창으로 열기</a>` : ''}

        ${item.registered ? `

          <div class="mt-4 rounded-lg bg-board-soft px-3 py-2.5 text-sm">

            지금 등록된 값 <code class="ml-1 font-bold tracking-widest">${esc(item.masked)}</code>

            <p class="mt-1 text-xs text-ink-muted">새 값을 넣으면 바뀌고, 비워 두고 [다음]을 누르면 지금 값을 그대로 써요.</p>

          </div>` : ''}

        <label for="propInput" class="field-label mt-4">${item.registered ? '새 값 (바꿀 때만 입력)' : '값 입력'}</label>

        ${inputHtml('propInput', item)}

        <p id="propError" class="mt-2 hidden text-sm font-semibold text-stamp"></p>

      </div>

      <div class="mt-4 flex items-center gap-2">

        <button type="button" onclick="prevStep()" class="btn btn-ghost" ${stepIndex === 0 ? 'disabled' : ''}>이전</button>

        <span class="flex-1"></span>

        ${item.required ? '' : '<button type="button" onclick="skipStep()" class="btn btn-ghost">건너뛰기</button>'}

        <button id="nextBtn" type="button" onclick="nextStep()" class="btn btn-primary">${isLast ? '저장하고 요약 보기' : '다음'}</button>

      </div>`;

  }



  /** [다음]: 값이 있으면 그 자리에서 바로 저장 → 창을 닫아도 여기까지는 유지됩니다. */

  async function nextStep() {

    const item = items[stepIndex];

    const input = $('propInput');

    const value = input.value.trim();

    if (!value) {

      if (item.required && !item.registered) return setFieldError('propError', '필수 항목이에요. 값을 입력해야 다음 단계로 넘어갈 수 있어요.');

      stepIndex++;

      return renderWizard();

    }

    const perr = patternError(item, value);

    if (perr) return setFieldError('propError', perr);



    const btn = $('nextBtn');

    setBusy(btn, true);

    try {

      const res = await call('saveAppProperty', item.key, value);

      if (!res.success) { setBusy(btn, false); return setFieldError('propError', res.message); }

      Object.assign(item, res.status);

      showToast(res.message);

      stepIndex++;

      renderWizard();

    } catch (e) {

      setBusy(btn, false);

      setFieldError('propError', errMsg(e));

    }

  }



  function skipStep() { stepIndex++; renderWizard(); }

  function prevStep() { if (stepIndex > 0) { stepIndex--; renderWizard(); } }

  function goStep(i) { mode = 'wizard'; stepIndex = i; render(); }



  function summaryHtml() {

    const missing = items.filter(i => i.required && !i.registered);

    return `

      <div class="panel p-5">

        <h2 class="text-xl font-extrabold">${missing.length ? '아직 등록하지 않은 필수 항목이 있어요' : '등록을 모두 마쳤어요'}</h2>

        <p class="mt-1.5 text-sm leading-relaxed text-ink-muted">${missing.length

          ? '필수 항목을 등록해야 웹 앱의 교사 화면에 들어갈 수 있어요.'

          : '웹 앱 로그인 화면에서 [교사]를 고르고 등록한 비밀번호로 들어가 보세요.'}</p>

        <ul class="mt-4 divide-y divide-line border-y border-line">

          ${items.map((item, i) => `

            <li class="flex flex-wrap items-center gap-2 py-3">

              <div class="min-w-0 flex-1">

                <div class="flex flex-wrap items-center gap-1.5"><span class="font-bold">${esc(item.label)}</span>${statusBadges(item)}</div>

                <p class="mt-0.5 text-xs text-ink-muted">${item.registered

                  ? `등록된 값 <code class="tracking-widest">${esc(item.masked)}</code>`

                  : (item.required ? '등록이 필요해요' : '등록하지 않으면 기본값(1234)을 써요')}</p>

                <p id="test-${esc(item.key)}" class="mt-1 hidden text-xs font-semibold"></p>

              </div>

              ${item.testable && item.registered ? `<button type="button" onclick="runTest('${esc(item.key)}', this)" class="btn btn-ghost btn-sm">연결 테스트</button>` : ''}

              <button type="button" onclick="goStep(${i})" class="btn btn-ghost btn-sm">${item.registered ? '바꾸기' : '등록하기'}</button>

            </li>`).join('')}

        </ul>

      </div>

      <div class="mt-4 flex items-center gap-2">

        <button type="button" onclick="prevStep()" class="btn btn-ghost">이전</button>

        <span class="flex-1"></span>

        <button type="button" onclick="finish()" class="btn btn-primary">완료</button>

      </div>`;

  }



  async function runTest(key, btn) {

    const box = $(`test-${key}`);

    setBusy(btn, true, '확인하는 중');

    try {

      const res = await call('testConnection', key);

      box.textContent = res.message;

      box.className = `mt-1 text-xs font-semibold ${res.success ? 'text-board' : 'text-stamp'}`;

    } catch (e) {

      box.textContent = errMsg(e);

      box.className = 'mt-1 text-xs font-semibold text-stamp';

    } finally {

      setBusy(btn, false);

    }

  }



  async function finish() {

    const missing = items.filter(i => i.required && !i.registered);

    if (missing.length) {

      const ok = await showConfirm(`아직 등록하지 않은 필수 항목: ${missing.map(m => m.label).join(', ')}\n이대로 닫으면 교사 화면에 들어갈 수 없어요.`, {

        title: '필수 항목이 남아 있어요', confirmText: '그래도 닫기', cancelText: '등록하러 가기', danger: true

      });

      if (!ok) return goStep(items.indexOf(missing[0]));

    }

    google.script.host.close();

  }

  function renderList() {

    $('listView').innerHTML = items.map((item, i) => `

      <div class="panel p-4">

        <div class="flex flex-wrap items-center gap-1.5">

          <h2 class="mr-1 font-extrabold">${esc(item.label)}</h2>${statusBadges(item)}

        ${item.docUrl ? `<a href="${esc(item.docUrl)}" target="_blank" rel="noopener" class="mt-1 inline-block text-sm font-bold text-board underline underline-offset-2">발급 페이지 새 창으로 열기</a>` : ''}

        <p class="mt-2 text-xs text-ink-muted">지금 값: ${item.registered ? `<code class="font-bold tracking-widest">${esc(item.masked)}</code>` : (item.required ? '없음' : '없음 (기본값 1234를 써요)')}</p>

        <div class="mt-2 flex flex-wrap items-end gap-2">

          ${inputHtml(`listInput${i}`, item, 'min-w-[200px] flex-1')}

          <button id="listSave${i}" type="button" onclick="saveFromList(${i})" class="btn btn-primary h-[50px]">저장</button>

          <button type="button" onclick="deleteFromList(${i})" class="btn btn-ghost h-[50px] text-stamp" ${item.registered ? '' : 'disabled'}>삭제</button>

        </div>

        <p id="listError${i}" class="mt-2 hidden text-sm font-semibold text-stamp"></p>

      </div>`).join('');

    items.forEach((item, i) => bindField(`listInput${i}`, item, `listError${i}`, () => saveFromList(i)));

  }



  async function saveFromList(i) {

    const item = items[i];

    const value = $(`listInput${i}`).value.trim();

    if (!value) return setFieldError(`listError${i}`, '저장할 값을 입력하세요.');

    const perr = patternError(item, value);

    if (perr) return setFieldError(`listError${i}`, perr);

    const btn = $(`listSave${i}`);

    setBusy(btn, true, '저장 중');

    try {

      const res = await call('saveAppProperty', item.key, value);

      if (!res.success) { setBusy(btn, false); return setFieldError(`listError${i}`, res.message); }

      Object.assign(item, res.status);

      showToast(res.message);

      renderList();

    } catch (e) {

      setBusy(btn, false);

      showToast(errMsg(e), true);

    }

  }



  async function deleteFromList(i) {

    const item = items[i];

    const ok = await showConfirm(`등록한 ${item.label} 값을 삭제할까요?${item.required ? '\n필수 항목이라 삭제하면 교사 화면에 들어갈 수 없어요.' : '\n삭제하면 기본값(1234)을 써요.'}`, {

      title: '등록한 값 삭제', confirmText: '삭제', danger: true

    });

    if (!ok) return;

    try {

      const res = await call('deleteAppProperty', item.key);

      if (!res.success) return showToast(res.message, true);

      Object.assign(item, res.status);

      showToast(res.message);

      renderList();

    } catch (e) {

      showToast(errMsg(e), true);

    }

  }

  function esc(v) {

    return String(v == null ? '' : v).replace(/[&<>"']/g, ch => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' }[ch]));

  function call(fnName, ...args) {

    return new Promise((resolve, reject) => {

  }

  function errMsg(e) { return String((e && e.message) || e || '알 수 없는 오류').replace(/^(Error|Exception):\s*/, ''); }

  function showToast(message, isError) {

    const el = document.createElement('div');

    el.className = `rounded-full px-4 py-2.5 text-sm font-semibold shadow-lg transition-opacity duration-300 ${isError ? 'bg-stamp text-white' : 'bg-ink text-chalk'}`;

    el.textContent = message;

    $('toastRoot').appendChild(el);

    setTimeout(() => { el.style.opacity = '0'; setTimeout(() => el.remove(), 300); }, 2600);

  }



  /**

   * 확인 모달. validate()가 false를 돌려주면 닫히지 않습니다. (전체 초기화 확인 문구 검사용)

   * bodyHtml에는 esc()로 처리한 값만 넣습니다.

   */

  function openConfirm(o) {

    $('modalTitle').textContent = o.title;

    $('modalBody').innerHTML = o.bodyHtml;

    $('modalButtons').innerHTML = `

      <button type="button" class="btn btn-ghost flex-1 py-3" onclick="closeModal(false)">취소</button>

      <button type="button" class="btn ${o.danger ? 'btn-danger' : 'btn-primary'} flex-1 py-3" onclick="closeModal(true)">${esc(o.confirmText)}</button>`;

    $('modalRoot').classList.remove('hidden');

    $('modalRoot').classList.add('flex');

    setTimeout(() => {

      const target = $('modalBody').querySelector('input') || $('modalButtons').lastElementChild;

      target.focus();

    }, 50);

    return new Promise(resolve => { modalState = { resolve: resolve, validate: o.validate || null }; });

  }

  function closeModal(value) {

    if (!modalState) return;

    if (value && modalState.validate && modalState.validate() === false) return;

    const r = modalState.resolve;

    modalState = null;

    $('modalRoot').classList.add('hidden');

    $('modalRoot').classList.remove('flex');

    r(value);

  }

  function setActionsDisabled(disabled) {

    ['safeBtn', 'resetBtn', 'rediagnoseBtn'].forEach(id => { $(id).disabled = disabled; });

  }



  // ---------------- 진단 ----------------

  async function diagnose() {

    setActionsDisabled(true);

    $('diagArea').innerHTML = '<div class="panel p-5 text-sm text-ink-muted sm:col-span-2">시트를 살펴보는 중이에요.</div>';

    try {

      lastDiagnosis = await call('diagnoseDatabase');

      renderDiagnosis(lastDiagnosis);

      setActionsDisabled(false);

    } catch (e) {

      $('diagArea').innerHTML = `<div class="panel p-5 text-sm sm:col-span-2"><p class="font-bold text-stamp">점검하지 못했어요.</p><p class="mt-1 text-ink-muted">${esc(errMsg(e))}</p></div>`;

      $('rediagnoseBtn').disabled = false;

    }

  }



  function renderDiagnosis(d) {

    const STATUS = {

      ok: ['정상', 'bg-board-soft text-board'],

      check: ['확인 필요', 'bg-white text-ink ring-1 ring-inset ring-chalk-yellow'],

      fix: ['보완 필요', 'bg-chalk-yellow/40 text-ink'],

      missing: ['시트 없음', 'bg-stamp-soft text-stamp']

    };

    $('diagArea').innerHTML = d.sheets.map(s => {

      // 바꿀 구조는 없지만 직접 확인할 항목이 남아 있으면 '확인 필요'로 표시

      const st = STATUS[s.status === 'ok' && s.warnings.length ? 'check' : s.status];

      const chips = s.expected.map(h => s.headers.indexOf(h) > -1

        ? `<span class="rounded bg-board-soft px-1.5 py-0.5 text-xs font-semibold text-board">${esc(h)}</span>`

        : `<span class="rounded border border-dashed border-stamp/60 px-1.5 py-0.5 text-xs font-semibold text-stamp" title="이 열이 아직 없어요">${esc(h)}</span>`

      ).join('');

      const extra = s.headers.filter(h => s.expected.indexOf(h) === -1);

      return `

        <section class="panel p-4">

          <div class="flex items-center justify-between gap-2">

            <h2 class="font-extrabold">[${esc(s.name)}] 시트</h2>

            <span class="rounded-full px-2 py-0.5 text-xs font-bold ${st[1]}">${st[0]}</span>

          </div>

          <p class="mt-0.5 text-xs text-ink-muted">${s.exists ? `데이터 ${s.dataRows}행` : '아직 만들어지지 않았어요'}</p>

          <p class="mt-3 text-xs font-semibold text-ink-muted">필요한 열 <span class="font-normal">(점선 = 아직 없음)</span></p>

          <div class="mt-1 flex flex-wrap gap-1">${chips}</div>

          ${extra.length ? `<p class="mt-2 text-xs text-ink-muted">앱에서 쓰지 않는 열: ${extra.map(esc).join(', ')}</p>` : ''}

          ${s.tasks.length ? `

            <p class="mt-3 text-xs font-bold">[안전 세팅]을 누르면</p>

            <ul class="mt-1 list-disc space-y-0.5 pl-5 text-sm">${s.tasks.map(t => `<li>${esc(t)}</li>`).join('')}</ul>` : ''}

          ${s.warnings.length ? `

            <div class="mt-3 rounded-lg bg-chalk-yellow/25 px-3 py-2">

              <p class="text-xs font-bold">직접 확인할 것</p>

              <ul class="mt-1 list-disc space-y-0.5 pl-5 text-sm">${s.warnings.map(w => `<li>${esc(w)}</li>`).join('')}</ul>

            </div>` : ''}

        </section>`;

    }).join('');



    // 이전 버전에서 쓰던 시트

    const obs = $('obsoleteNotice');

    obs.classList.toggle('hidden', !d.obsolete.length);

    obs.innerHTML = d.obsolete.length

      ? `<p class="text-sm"><span class="font-bold">이전 버전 시트가 남아 있어요</span> <span class="text-ink-muted">${d.obsolete.map(esc).join(', ')}. 앱에서는 쓰지 않으며, [전체 초기화]를 하면 정리돼요.</span></p>`

      : '';



    // 비밀번호 등록 상태

    const notice = $('pwNotice');

    notice.classList.remove('hidden');

    notice.innerHTML = `

      <div class="flex flex-wrap items-center justify-between gap-2">

        <div class="space-y-1">

          ${d.adminPasswordRegistered

            ? '<p class="text-sm"><span class="font-bold text-board">교사 비밀번호 등록됨</span> <span class="text-ink-muted">웹 앱에서 교사로 로그인할 수 있어요.</span></p>'

            : '<p class="text-sm"><span class="font-bold text-stamp">교사 비밀번호 미등록</span> <span class="text-ink-muted">등록해야 교사 화면에 들어갈 수 있어요.</span></p>'}

          ${d.studentPasswordRegistered

            ? '<p class="text-sm"><span class="font-bold text-board">학생 초기 비밀번호 등록됨</span></p>'

            : '<p class="text-sm"><span class="font-bold">학생 초기 비밀번호 미등록</span> <span class="text-ink-muted">기본값 1234를 써요.</span></p>'}

        </div>

        <button type="button" onclick="google.script.run.showSettingsDialog()" class="btn ${d.adminPasswordRegistered ? 'btn-ghost' : 'btn-primary'} btn-sm">비밀번호 등록 창 열기</button>

      </div>`;

  }

  async function runSafe() {

    const tasks = [];

    (lastDiagnosis ? lastDiagnosis.sheets : []).forEach(s => s.tasks.forEach(t => tasks.push(`[${s.name}] ${t}`)));

    const ok = await openConfirm({

      title: '안전 세팅',

      bodyHtml: tasks.length

        ? `<p>아래 작업을 실행해요. 기존 데이터는 지우지 않아요.</p>

           <ul class="mt-2 list-disc space-y-1 pl-5 text-ink">${tasks.map(t => `<li>${esc(t)}</li>`).join('')}</ul>`

        : '<p>바꿀 구조가 없어요. 실행하면 텍스트 서식(학번 등)만 다시 맞춰요.</p>',

      confirmText: '안전 세팅 실행'

    });

    if (ok) execute('safe');

  }



  async function runReset() {

    const backup = $('backupChk').checked;

    const ok = await openConfirm({

      title: '전체 초기화',

      danger: true,

      bodyHtml: `

        <p>[학생] · [설문월] · [관계응답] · [제출기록] 시트의 <b class="text-ink">모든 내용이 지워지고</b> 예시 데이터로 바뀌어요. 이전 버전 시트도 정리돼요.</p>

        ${backup

          ? '<p class="mt-2">백업 시트를 먼저 만들어 둘게요.</p>'

          : '<p class="mt-2 rounded-lg bg-stamp-soft px-3 py-2 font-semibold text-stamp">백업이 꺼져 있어요. 지운 내용은 되돌릴 수 없어요.</p>'}

        <label for="resetConfirmInput" class="mt-4 block font-semibold text-ink">계속하려면 아래 칸에 <b>초기화</b>를 입력하세요.</label>

        <input id="resetConfirmInput" type="text" autocomplete="off" class="field" placeholder="초기화">

        <p id="resetConfirmError" class="mt-2 hidden font-semibold text-stamp">'초기화'를 정확히 입력하세요.</p>`,

      confirmText: '전체 초기화 실행',

      validate: () => {

        const pass = $('resetConfirmInput').value.trim() === '초기화';

        $('resetConfirmError').classList.toggle('hidden', pass);

        return pass;

      }

    });

    if (ok) execute('reset');

  }



  async function execute(mode) {

    const btn = mode === 'reset' ? $('resetBtn') : $('safeBtn');

    const label = btn.innerHTML;

    setActionsDisabled(true);

    btn.innerHTML = `<span class="flex items-center gap-2 text-sm"><span class="spinner"></span>${mode === 'reset' ? '초기화하는 중' : '세팅하는 중'}</span>`;

    try {

      const res = await call('runDatabaseSetup', mode, $('backupChk').checked);

      renderLogs(mode, res.logs);

      showToast(mode === 'reset' ? '전체 초기화를 마쳤어요.' : '안전 세팅을 마쳤어요.');

      btn.innerHTML = label;

      await diagnose();

    } catch (e) {

      btn.innerHTML = label;

      setActionsDisabled(false);

      renderLogs(mode, ['실행하지 못했어요: ' + errMsg(e)], true);

    }

  }



  function renderLogs(mode, logs, isError) {

    const box = $('logArea');

    box.classList.remove('hidden');

    box.innerHTML = `

      <h2 class="font-extrabold ${isError ? 'text-stamp' : ''}">${mode === 'reset' ? '전체 초기화 결과' : '안전 세팅 결과'}</h2>

      <ul class="mt-2 list-disc space-y-1 pl-5 text-sm">${logs.map(l => `<li>${esc(l)}</li>`).join('')}</ul>`;

    box.scrollIntoView({ behavior: 'smooth', block: 'nearest' });

  }
