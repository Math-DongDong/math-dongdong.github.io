Apps Script 코드


                    
질문을 바꾸면 코드도 함께 바뀝니다. 수정 후에는 코드를 다시 붙여넣고 재배포하세요.

                


                

                    
설치 순서

                    
    
                        
  1. 1
                            
    구글 시트를 새로 만들고 확장 프로그램 → Apps Script를 엽니다.
    
                        
    2. 
                        
  2. 2
                            
    기존 내용을 지우고 왼쪽 코드를 전부 붙여넣은 뒤 저장합니다.
    
                        
    3. 
                        
  3. 3
                            
    배포 → 새 배포 → 웹 앱을 선택하고, 실행 사용자는 나, 액세스 권한은 모든
                                    사용자로 지정합니다.
    
                        
    4. 
                        
  4. 4
                            
    /exec로 끝나는 URL을 복사해 기본 정보 → 웹앱 URL 칸에 붙여넣습니다.
    
                        
    5. 
                        
  5. 5
                            
    아래에서 응답자용 파일을 내려받아 학교 홈페이지, 구글 사이트 도구, 깃허브 페이지 등에 올리고 주소를 공유합니다.
    
                        
    6. 
                    


                    

                    
응답자용 파일

                    
                    
파일 하나로 동작하며, 제출한 내용은 구글 시트에만 쌓입니다.


                    

                        응답 확인은 구글 시트에서만 가능합니다. 생성되는 코드에는 시트 내용을 불러오거나 외부로 내보내는 기능이 들어 있지 않습니다.
