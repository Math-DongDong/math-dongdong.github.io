아하! 수학 편집기

학습 페이지의 글과 미션 문항을 화면에서 바로 고칩니다.
저장하면 같은 이름의 파일이 내려받아지니, 저장소의 원본 파일에 덮어쓰세요.

주제 선택해서 열기

서버에서 파일을 불러오지 못했습니다. GitHub Pages 또는 Live Server 주소로 편집기를 열었는지 확인하거나, 아래 파일 첨부를 이용하세요.

파일 첨부 (아직 올리지 않은 파일)

ahamath/1 폴더의 HTML 파일을 끌어다 놓거나 클릭해서 선택하세요

사용 방법

  • 클릭으로 선택하고, 더블클릭 또는 Enter로 글자를 고칩니다. Esc로 편집을 끝냅니다.
  • 심화 화면, 게이트 안내처럼 평소에 숨어 있는 영역은 주황 점선으로 펼쳐 보입니다. 저장 파일에서는 원래대로 숨겨집니다.
  • 미션 문항은 상단의 미션 문항 편집에서 고칩니다. 시각 자료는 편집 화면에서 재생되지 않습니다(미리보기에서 확인).
고칠 부분을 클릭하세요.
더블클릭하면 글자를 고칠 수 있어요.

글자

글자를 고치는 중에 굵게 할 부분을 드래그한 뒤 누르세요.

수학 기호

글자를 고치는 중인 커서 위치에 들어갑니다.

링크 주소

게이트 버튼은 정리 카드 id(예: #block-c4)를 가리켜야 합니다.

클릭: 선택 · 더블클릭/Enter: 글자 고치기 · Esc: 편집 끝내기 · Delete: 삭제 · Ctrl+D: 복제 · Ctrl+Z/Y: 되돌리기/다시

미션 문항 편집

문항을 지우거나 옮겨서 ID의 뜻이 바뀌었을 때만 1 올리세요. 올리면 이 주제의 학생 기록이 초기화됩니다.
글 안에 <b>굵게</b>, <br>(줄바꿈) 태그를 쓸 수 있습니다.
