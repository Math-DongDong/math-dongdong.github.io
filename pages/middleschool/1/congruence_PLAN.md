# 삼각형 합동 카드게임 (중1) — 구현 계획서

> 기준 파일: `pages/middleschool/2/similarity.html` (삼각형 닮음 카드게임 v0.2, 유형 A 개인 기록형)
> 신규 파일: `pages/middleschool/1/congruence.html`

## 1. 개요

| 항목 | 닮음 (중2, 기존) | 합동 (중1, 신규) |
|---|---|---|
| 조건 | SSS / SAS / AA 닮음 | **SSS / SAS / ASA 합동** |
| 기호 | △ABC ∽ △DEF | △ABC **≡** △DEF |
| 판정 | 변의 **비**가 같음 (교차곱) | 변의 길이·각의 크기가 **같음** (정수 일치) |
| 보너스 | 닮음비로 대응변 계산 | 대응변은 **같은 길이**, 대응각은 180° − 나머지 두 각 |
| 컬렉션 | `similar_triangle_records` | `congruent_triangle_records` (`*_records` 패턴 → 규칙 수정 불필요) |

- 게임 흐름(로그인 → 12장 보드 → 2장 선택 → 조건 판정 → 대응 꼭짓점 → 보너스 → 라운드/무한도전 → 기록 저장·순위 → 교사 대시보드)은 그대로 유지
- 중1 학생은 닮음을 아직 배우지 않으므로 "닮음", "닮음비" 용어는 화면에서 완전히 제거

## 2. 카드 유형 (데이터 모델)

| type | 카드에 표시되는 정보 | 필드 |
|---|---|---|
| `SSS` | 세 변 | `s: [a, b, c]` |
| `SAS` | 두 변 + 끼인각 | `k, th, p, q` (기존 `SA` 재사용) |
| `ASA` (신규) | 한 변 + 양 끝 각 | `k`(변의 시작 꼭짓점), `c`(변 길이), `al, be`(양 끝 각) |
| `ASA` + `aas: true` (R3+) | 두 각 + 끼인변이 **아닌** 변 (AAS 표시) | 위와 같은 데이터, 표시만 다르게: 각 하나를 숨기고 나머지 각 표시 |

- AAS는 별도 합동 조건으로 두지 않고 **ASA로 판정** (나머지 각 = 180° − 두 각 → 변의 양 끝 각이 정해짐)

- `pts(c)`에 ASA 좌표 계산 추가: P[k]=(0,0), P[k+1]=(c,0), 사인법칙으로 세 번째 꼭짓점
- 태그 문구: `변 3개` / `변 2개+끼인각` / `변 1개+양 끝 각`
- `uniq()`(세 변·세 각이 모두 달라 대응이 하나로 정해짐)는 그대로 사용

## 3. 판정 로직 `judge(a, b)`

- 타입이 다르면 `INVALID` (기존과 동일 → 66쌍 전수 검증 유지)
- SSS: 정렬한 세 변이 완전히 같음
- SAS: `th` 같고 `{p, q}` 집합이 같음, SSA 함정 카드면 `NONE`
- ASA: `c` 같고 `{al, be}` 집합이 같음
- `match(a, b)` 대응: 합동은 실제 변 길이가 같으므로 **`pts()`로 계산한 세 변의 크기 순위로 통일** 가능 (타입별 분기 축소)

## 4. 함정(Decoy) 카드 — 학습 포인트

| 함정 | 생성 방법 | 오답 메시지 |
|---|---|---|
| 확대 카드 | 진짜 카드의 변을 ×2 (각은 그대로) | "모양은 같지만 크기가 달라 합동이 아니에요" |
| 한 값 어긋남 | 변 ±1~2 또는 각 ±5~10° | "대응하는 변(각)의 크기가 달라요" |
| SSA | 두 변 + **끼인각이 아닌** 각 (R3+) | "주어진 각이 끼인각이 아니면 합동이라 할 수 없어요" |
| AAA (R2+) | 세 각만 표시, 변 없음 | "세 각이 같아도 크기가 다를 수 있어요" |

- 오답 메시지를 함정 종류별로 분기 → `D.trap` 필드로 종류 저장, 통계 `trapOk/trapTot`에 반영

## 5. 라운드 구성 (`CFG`)

| 라운드 | 쌍 구성 | 특징 |
|---|---|---|
| R1 | SSS, SAS, SAS, ASA, ASA | 숫자 범위 3~8, 쉬운 각(10° 단위), 확대·어긋남 함정만 |
| R2 | 동일 비율 | 대응 꼭짓점 문제 40% 출제 (`CONN_RATE`), **AAA 함정 등장** |
| R3 | SSS, SAS, ASA 혼합 | **AAS 카드(두 각 + 끼인변이 아닌 변)를 ASA 계산형으로 출제 → 나머지 각을 계산해야 ASA 확인** (닮음 R2의 '나머지 각 계산형' 대응, 정답 버튼은 ASA), SSA 함정 추가, 보너스 퀴즈 |
| R4+ | 무작위 | ♾️ 무한도전, 5° 단위 각 |

- 회전·뒤집기(`deco()`)는 그대로 → "돌리거나 뒤집어도 합동" 감각 형성

## 6. 대응 꼭짓점 & 보너스 퀴즈

- 대응 꼭짓점 모달: `∽` → `≡` 기호 교체, 로직 동일
- 보너스 (R3+, `mkBonus` 수정)
  - **대응변**: "△ABC ≡ △DEF에서 AB = 7일 때 DE는?" → 정답은 같은 값, 오답 보기: 다른 변 길이, ±1
  - **대응각**: 기존과 동일 (180° − 두 각)
  - 닮음비 관련 문구·계산 전부 삭제

## 7. 점수·하트

- 기존 규칙 유지: 정답 +100 × 콤보 배율(최대 2배), 조건만 틀림 +30, 비합동 선택·대응 오류 하트 −1, 보너스 오답은 하트 유지

## 11. 확정된 결정 사항

- AAS(두 각 + 끼인변 아닌 변)는 **R3부터 계산형 ASA로 취급**
- AAA 함정은 **R2부터 출제**
- 보드 구성은 기존과 같이 **합동 쌍 5개 + 함정 2장 = 12장** 유지
