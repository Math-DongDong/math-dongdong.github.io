절댓값과 수의 대소 관계

−7과 +5 가운데 큰 수와 0에서 먼 수가 서로 달라요. 거리를 재는 법을 먼저 배우고, 그다음 크기를 견주는 법을 만나요.

화면을 위에서 아래로 천천히 내리기만 하면 돼요.

다시 볼 문제

한 번에 맞히지 못한 문제예요. 누르면 이 문제들만 골라서 다시 풀 수 있어요. 다시 풀어서 한 번에 맞히면 그때 기록에 쌓여요.

    1

    개념 익히기

    절댓값 → 수직선 → 대소 비교 순서로 만나요

    크다와 멀다가 갈라져요

    수직선 위에 −7과 +5를 찍었어요. 두 가지를 물어볼게요.

    어느 수가 더 클까요?+5
    어느 수가 0에서 더 멀까요?−7
    두 답이 서로 달라요. '크다'와 '멀다'는 다른 이야기예요.

    먼저 '멀고 가까움'을 부르는 이름부터 만들어 볼게요.

    원점에서 얼마나 떨어져 있나요

    수직선에서 0을 나타내는 점을 원점이라고 해요. 원점에서 각 수까지의 거리를 재어 볼게요.

    원점에서 그 수를 나타내는 점까지의 거리를 그 수의 절댓값이라 하고, 기호 | |를 써서 나타내요.
    |+5| = 5     |−7| = 7

    기호 안에는 수를 넣고, 답으로는 거리를 적어요.

    부호만 떼면 돼요

    거리를 재는 것이니 어느 쪽으로 떨어져 있는지는 상관없어요.

    |+3| = 3    |−3| = 3    |0| = 0
    절댓값을 구할 때는 부호를 떼고 숫자만 보면 돼요.

    0은 원점에서 떨어져 있지 않아요. '떨어진 정도가 0'이라고 적는 거예요.

    절댓값이 3인 수는 두 개예요

    거꾸로 물어볼게요. 원점에서 3만큼 떨어진 점은 어디에 있을까요?

    절댓값이 3인 수 −3 과 +3  (두 개)
    절댓값이 0인 수 0  (하나)
    절댓값이 −3인 수 없어요
    거리는 음수가 될 수 없어요. 그래서 절댓값은 늘 0 또는 양수예요.

    숫자가 크면 큰 수일까요

    세 도시의 아침 기온이에요. 가장 추운 도시는 어디일까요?

    도시 가 나 다
    아침 기온 −8 ℃ −3 ℃ +2 ℃
    숫자만 보면 8이 가장 커서 '가'가 따뜻해 보여요. 하지만 −8은 0보다 8이나 아래라는 뜻이에요. 가장 추운 도시는 '가'예요.

    음수는 숫자가 클수록 오히려 더 작은 수가 돼요. 수직선 위에 올려 두면 그 까닭이 보여요.

    수직선에서는 오른쪽이 커요

    세 기온을 수직선 위에 그대로 올려 볼게요.

    수직선 위에 나타내면 오른쪽에 있는 수가 왼쪽에 있는 수보다 커요.
    (음수) < 0 < (양수)

    −8이 가장 왼쪽에 있으니 가장 작은 수, 곧 가장 추운 도시예요.

    부호가 같을 때는 절댓값으로

    수직선을 매번 그리기는 번거로워요. 부호가 같은 두 수라면 절댓값만 보고도 알 수 있어요.

    +2 < +5   →   |+2| < |+5|
    −5 < −2   →   |−5| > |−2|
    양수끼리는 절댓값이 큰 수가 크고, 음수끼리는 절댓값이 큰 수가 작아요.

    음수는 반대되는 성질을 나타내는 수예요. 그래서 크기를 견주는 방향도 반대가 돼요.

    한눈에 정리해요

    절댓값 원점에서 그 수까지의 거리
    부호를 떼면 돼요. 늘 0 또는 양수예요
    수직선 오른쪽에 있는 수가 더 큰 수
    (음수) < 0 < (양수)
    같은 부호 양수끼리는 절댓값이 큰 쪽이 크고,
    음수끼리는 절댓값이 큰 쪽이 작아요

    크기를 글 대신 기호로 적을 때는 부등호를 써요.

    x > a x는 a보다 크다 · x는 a 초과이다
    x < a x는 a보다 작다 · x는 a 미만이다
    x ≥ a x는 a보다 크거나 같다 · x는 a 이상이다
    x는 a보다 작지 않다
    x ≤ a x는 a보다 작거나 같다 · x는 a 이하이다
    x는 a보다 크지 않다
    ≥ 와 ≤ 아래의 줄은 등호(=)를 줄여 붙인 것이에요. '같아도 된다'는 뜻이에요.

    대표 예제

    풀이가 ① ② ③ 순서로 하나씩 나타나요

    예제 1. 절댓값 구하기

    다음 두 수의 절댓값을 기호로 나타내고 값을 구해 볼게요.

    −2.7     +8/9
    ① 무엇을 구하는지 확인
    절댓값은 원점에서의 거리예요. 어느 쪽으로 떨어졌는지(부호)는 보지 않아요.
    ② 기호로 적기
    |−2.7|   과   |+8/9|
    ③ 값 구하기
    |−2.7| = 2.7     |+8/9| = 8/9

    |−2.7| 의 답을 −2.7 이라고 적는 실수가 가장 많아요. 거리는 음수가 될 수 없어요.

    예제 2. 두 음수 비교하기

    −1/2 과 −3/4 가운데 어느 쪽이 클까요?

    ① 부호 확인
    둘 다 음수예요. 음수끼리는 절댓값이 큰 쪽이 작아요.
    ② 절댓값 견주기
    |−1/2| = 1/2 = 2/4,   |−3/4| = 3/4
    통분해서 견주면 2/4 < 3/4
    ③ 답 적기
    절댓값이 작은 −1/2 이 더 커요.   −1/2 > −3/4

    분모가 다르면 통분이 먼저예요. 분자만 보고 1 < 3 이라고 하면 답이 뒤집혀요.

    한 걸음 더

    이번에는 범위를 다뤄요. 이상 · 이하 · 초과 · 미만을 부등호로 적고, 그 안에 정수가 몇 개나 있는지 세어 봐요.

    여기도 스크롤만 내리면 그림이 저절로 움직여요.

    이상 · 이하 · 초과 · 미만

    말로 된 범위를 부등호로 바꿔 적어 볼게요. 그 수가 포함되는지가 갈림길이에요.

    x는 −2 이상이다 x ≥ −2
    x는 6 미만이다 x < 6
    x는 −2 이상 6 미만이다 −2 ≤ x < 6
    이상 · 이하에는 그 수가 포함되고, 초과 · 미만에는 포함되지 않아요.

    포함되면 등호가 붙은 ≥, ≤ 를, 포함되지 않으면 >, < 를 써요.

    범위 안에 정수가 몇 개 있을까요

    −2 ≤ x < 6 을 수직선 위에 나타내면 이렇게 돼요.

    왼쪽 끝 −2는 포함(색칠된 점), 오른쪽 끝 6은 포함되지 않아요(빈 점).
    −2, −1, 0, 1, 2, 3, 4, 5  →  모두 8개

    가장 작은 정수는 −2, 가장 큰 정수는 5예요. 6은 들어가지 않으니까요.

    심화 예제. 절댓값이 4보다 작은 정수

    절댓값이 4보다 작은 정수는 모두 몇 개일까요?

    ① 조건을 거리로 바꾸기
    절댓값이 4보다 작다는 것은 원점에서 4보다 가까이 있다는 뜻이에요.
    ② 범위로 적기
    −4 < x < 4  (양 끝의 −4와 4는 들어가지 않아요)
    ③ 정수만 세기
    −3, −2, −1, 0, 1, 2, 3  →  7개

    0을 빠뜨리기 쉬워요. 0도 절댓값이 0이라 4보다 작으니 꼭 세어야 해요.
