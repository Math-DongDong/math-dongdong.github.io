같은 종류의 항끼리 모아서 더하고 빼요. 무엇끼리 모을 수 있는지만 알면 계산은 간단해요.

다시 볼 문제

한 번에 맞히지 못한 문제예요. 누르면 이 문제들만 골라서 다시 풀 수 있어요. 다시 풀어서 한 번에 맞히면 그때 기록에 쌓여요.

    개념 익히기

    막대로 더하기 → 동류항 → 계수끼리 계산 → 괄호 풀기 순서로 만나요

    막대로 더해 봐요

    노란 막대 하나는 x, 파란 조각 하나는 1 이에요. 2x + 1 과 3x + 2 를 막대로 놓고 더해 볼까요?

    막대와 조각은 크기가 달라서 하나로 셀 수 없어요. 모두 합쳐 8x 라고 하면 안 되고, 같은 모양끼리만 모아서 세요.

    식에서 '같은 모양'은 어떻게 알아볼까요?

    같은 모양의 항, 동류항

    문자와 차수가 각각 같은 항을 동류항이라고 해요. 상수항끼리도 모두 동류항이에요.

    두 항 동류항? 까닭
    5x 와 7x ○ 문자 x, 차수 1 이 같아요
    -4 와 7 ○ 상수항끼리
    2x 와 2y × 문자가 달라요
    3x 와 3x² × 차수가 달라요
    계수가 같은지는 상관없어요. 문자와 차수만 봐요.

    동류항끼리는 어떻게 더할까요?

    동류항은 계수끼리 계산해요

    4x + 3x 는 x 막대 4개와 3개, 모두 7개예요. 분배법칙을 거꾸로 쓴 것과 같아요.

    동류항끼리는 계수끼리 더하거나 빼고, 문자는 그대로 둬요. 동류항이 아닌 항은 그대로 남겨요.

    괄호로 묶인 식을 뺄 때는 조심할 것이 있어요.

    괄호 앞의 - 는 모든 항의 부호를 바꿔요

    (4x + 2) - (3x + 1) 은 4x + 2 에서 3x + 1 을 통째로 빼는 거예요. 막대로 덜어 내 볼까요?

    동류항끼리 줄을 맞춰 세로로 계산해도 같아요.

    4x + 2
    -) 3x + 1
    x + 1
    + ( ) 는 괄호를 그냥 풀고, - ( ) 는 괄호 안 모든 항의 부호를 바꿔서 풀어요.

    괄호 앞에 수가 곱해져 있으면 어떻게 할까요?

    괄호를 먼저 풀고 모아요

    괄호 앞에 수가 있으면 분배법칙으로 괄호를 먼저 풀어요. 그다음 동류항끼리 모아요.

    ① 괄호 풀기 → ② 동류항끼리 모으기 → ③ 계수끼리 계산하기, 이 순서면 어떤 일차식도 정리할 수 있어요.

    정리 카드에서 한 번 더 볼까요?

    한눈에 정리해요

    동류항 문자와 차수가 각각 같은 항, 상수항끼리
    5x 와 7x, -4 와 7
    동류항 계산 계수끼리 더하거나 빼요
    4x + 3x = 7x
    + ( ) 그대로 풀어요
    +(3x + 1) = 3x + 1
    - ( ) 모든 항의 부호를 바꿔요
    -(3x + 1) = -3x - 1
    괄호 풀기 → 동류항끼리 모으기 → 계산, 세 단계만 기억해요.

    대표 예제

    풀이가 ① ② ③ 순서로 하나씩 나타나요

    예제 1. 괄호가 있는 덧셈

    괄호를 풀고 동류항끼리 모아 볼까요?

    2(4x + 3) + (x + 2)
    ① 괄호 풀기
    2 를 두 항에 모두 곱하고, + ( ) 는 그대로 풀어서 8x + 6 + x + 2
    ② 동류항끼리 모으기
    x 항끼리, 상수항끼리 모아서 8x + x + 6 + 2
    ③ 계산하기
    (8 + 1)x + 8 이므로 9x + 8

    x 의 계수 1 은 보이지 않지만 꼭 더해야 해요.

    예제 2. 괄호가 있는 뺄셈

    두 괄호 앞에 모두 수가 곱해져 있어요.

    3(x - 1) - 2(4 - x)
    ① 괄호 풀기
    3 × x + 3 × (-1) 과 (-2) × 4 + (-2) × (-x) 를 이어서 3x - 3 - 8 + 2x
    ② 동류항끼리 모으기
    3x + 2x - 3 - 8
    ③ 계산하기
    5x - 11

    (-2) × (-x) 는 음수끼리의 곱이라 +2x 예요. 여기서 부호를 가장 많이 놓쳐요.

    한 걸음 더

    ÷ 가 섞인 식과 분수 꼴의 일차식을 더하고 빼요. 마지막에는 생각한 수를 맞히는 비밀도 풀어 봐요.

    ÷ 가 섞이면 분수로 바꿔 놓고

    곱셈과 나눗셈은 덧셈·뺄셈보다 먼저예요. ÷ 를 분수로 바꿔 놓고 동류항을 모아요.

    x + x ÷ 2 를 (x + x) ÷ 2 = x 로 계산하기 쉬워요. ÷ 2 는 바로 앞의 x 에만 걸려요.

    분수 꼴은 통분해서

    분모가 다른 분수 꼴의 일차식은 분모를 같게 맞춘(통분한) 뒤 분자끼리 계산해요.

    분수 앞의 - 는 분자 전체에 걸려요. 3x - 3 을 빼면 -3x + 3 이 돼요.

    심화 예제. 생각한 수를 맞히는 비밀

    어떤 수를 생각하고, 2를 곱하고, 10을 더하고, 2로 나눈 뒤 처음 생각한 수를 빼요. 누가 해도 답은 5 예요. 왜 그럴까요?

    ① 조건 확인
    생각한 수를 x 라고 해요.
    ② 식 세우기
    (2x + 10)/2 - x
    ③ 계산하기
    x + 5 - x = 5. x 항이 사라지니 어떤 수를 생각해도 답은 5 예요.

    더하는 수를 바꾸면 답도 바꿀 수 있어요. 친구에게 직접 내 보세요.
