중1. 기본 도형과 작도

각과 맞꼭지각

두 반직선이 만드는 각을 기호로 나타내고, 두 직선이 만날 때 마주 보는 맞꼭지각의 크기가 왜 같은지 알아봐요.

다시 볼 문제

한 번에 맞히지 못한 문제예요. 아래 버튼으로 이 문제들만 모아서 다시 풀 수 있어요.

    1

    개념 익히기

    각을 기호로 나타내요

    두 반직선 OA 와 OB 로 이루어진 도형을 각 AOB 라고 해요. 두 반직선이 만나는 점 O 가 각의 꼭짓점이에요.

    각 AOB 는 기호로 ∠AOB 또는 ∠BOA 로 나타내요. 꼭짓점 O 는 언제나 가운데에 써요. 간단히 ∠O 나 ∠a 로 쓰기도 해요.
    ∠AOB 는 각 그 자체를 나타내기도 하고, 각의 크기를 나타내기도 해요. 예) ∠AOB = 45°

    그런데 ∠O 처럼 꼭짓점 하나로만 부르면 곤란할 때가 있어요.

    꼭짓점에 각이 여러 개라면

    아래 그림에서 점 B 에는 각이 두 개 있어요. ∠B 라고만 하면 어느 각인지 알 수 없지요.

    한 꼭짓점에 각이 여러 개 있을 때는 세 점을 써서 어느 각인지 분명히 나타내요. 점 B 의 두 각은 ∠OBC 와 ∠OBA 로 구별해요.

    이제 각의 크기에 따라 이름을 붙여 볼까요?

    평각과 각의 분류

    두 반직선이 한 직선을 이룰 때의 각을 평각이라고 해요. 평각은 180° 예요.

    이름 크기
    예각 0° < (각의 크기) < 90°
    직각 90°
    둔각 90° < (각의 크기) < 180°
    평각 180°
    평각은 직각 두 개를 합한 것이에요. 한 직선 위에 꼭짓점이 있으면 그 직선의 한쪽에 생긴 각을 모두 더해 180° 가 돼요.

    평각을 이용하면 모르는 각의 크기를 구할 수 있어요.

    평각으로 각의 크기 구하기

    ∠AOD 가 평각일 때 ∠COD 의 크기를 구해 볼까요?

    ∠AOB + ∠BOC + ∠COD = 180°
    한 직선 위에 모인 각의 합은 180° 예요. 모르는 각 하나만 남기고 나머지를 180° 에서 빼요.

    이번에는 두 직선이 한 점에서 만나는 경우를 볼까요?

    교각과 맞꼭지각

    서로 다른 두 직선 l, m 이 한 점에서 만나면 각이 네 개 생겨요.

    두 직선이 만나서 생기는 네 각 ∠a, ∠b, ∠c, ∠d 를 두 직선의 교각이라고 해요.
    교각 가운데 ∠a 와 ∠c 처럼 서로 마주 보는 두 각을 맞꼭지각이라고 해요.

    맞꼭지각은 크기가 늘 같아 보여요. 정말 그럴까요?

    맞꼭지각의 크기는 같아요

    각도기로 재지 않아도 평각만으로 알 수 있어요. ∠a 와 ∠c 는 둘 다 ∠b 와 합해서 평각이 돼요.

    맞꼭지각의 크기는 항상 같아요.
    ∠a = ∠c, ∠b = ∠d

    정리 카드로 한 번 더 볼까요?

    한눈에 정리해요

    ∠AOB 반직선 OA, OB 로 이루어진 각
    꼭짓점 O 를 가운데에 써요
    평각 두 반직선이 한 직선을 이룰 때의 각, 180°
    교각 두 직선이 만나서 생기는 네 각
    맞꼭지각 교각 가운데 서로 마주 보는 두 각
    크기가 항상 같아요
    모르는 각은 평각(180°)과 맞꼭지각으로 찾아요.
    2

    대표 예제

    예제 1. 평각에서 ∠x 구하기

    ∠AOD 가 평각일 때 ∠x 의 크기를 구해 볼까요?

    ① 조건 확인
    ∠AOD 가 평각이니 세 각을 모두 더하면 180° 예요.
    ② 식 세우기
    50° + ∠x + 60° = 180°
    ③ 계산하기
    ∠x = 180° - 50° - 60° 이므로 ∠x = 70°

    모르는 각 하나만 남기고 나머지를 180° 에서 빼면 돼요.

    예제 2. 맞꼭지각으로 ∠x, ∠y 구하기

    두 직선이 한 점에서 만날 때 ∠x 와 ∠y 의 크기를 구해 볼까요?

    ① 맞꼭지각 찾기
    ∠x 는 50° 와 마주 보는 맞꼭지각이니 ∠x = 50°
    ② 평각으로 식 세우기
    ∠y 와 50° 는 한 직선 위에 있으니 ∠y + 50° = 180°
    ③ 계산하기
    ∠y = 180° - 50° 이므로 ∠y = 130°

    확인 : ∠x + ∠y = 50° + 130° = 180° 로 평각이 돼요.

    한 걸음 더

    ∠x = 30° 와 x = 30 을 구분하고, 마주 보는데도 맞꼭지각이 아닌 경우를 가려낸 뒤, 각의 크기를 방정식으로 구해 봐요.

    ∠x = 30° 와 x = 30 은 달라요

    그림에 각이 x 로 적혀 있는지, x° 로 적혀 있는지에 따라 답을 쓰는 방법이 달라요.

    그림의 표시 x 의 뜻 답 쓰는 법
    x 각의 이름 ∠x = 30°
    x° 각의 크기를 나타내는 수 x = 30
    x° 처럼 ° 가 붙어 있으면 x 는 그냥 수예요. 그래서 "x 의 값" 을 묻고, x + 2x + 60 = 180 처럼 ° 를 떼고 방정식을 세워요.

    x = 30° 나 ∠x = 30 처럼 섞어 쓰지 않도록 조심해요.

    마주 본다고 다 맞꼭지각은 아니에요

    "55° 로 크기가 같고 서로 마주 보니까 맞꼭지각이야!" 라고 말한 친구가 있어요. 정말 그럴까요?

    맞꼭지각은 두 직선이 만날 때 생기는 각이에요. 두 각의 변이 곧게 이어져 직선을 이루지 않으면, 크기가 같고 마주 보아도 맞꼭지각이 아니에요.

    심화 예제. 세 직선에서 x 구하기

    세 직선이 한 점에서 만날 때 x 의 값을 구해 볼까요?

    ① 맞꼭지각 옮기기
    아래쪽 60° 와 맞꼭지각인 위쪽 각도 60° 예요.
    ② 평각으로 식 세우기
    위쪽 세 각이 한 직선 위에 모였으니 x + 60 + 50 = 180
    ③ 계산하기
    x = 70

    떨어져 있는 각은 맞꼭지각으로 옮겨 와서 한 직선 위에 모아 보세요.
