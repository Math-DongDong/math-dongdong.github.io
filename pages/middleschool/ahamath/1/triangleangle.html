중1. 평면도형의 성질

삼각형의 내각과 외각

다각형의 내각과 외각이 무엇인지 알고, 평행선을 이용해 삼각형의 세 내각의 크기의 합과 한 외각의 크기를 설명해 봐요.

다시 볼 문제

한 번에 맞히지 못한 문제예요. 아래 버튼으로 이 문제들만 모아서 다시 풀 수 있어요.

    1

    개념 익히기

    선분으로만 둘러싸인 도형, 다각형

    두 도형 모두 변이 다섯 개처럼 보여요. 그런데 둘 다 다각형일까요?

    여러 개의 선분으로만 둘러싸인 평면도형을 다각형이라고 해요. 다각형을 이루는 선분을 변, 변과 변이 만나는 점을 꼭짓점이라고 해요.
    변이 3개, 4개, …, n개인 다각형을 각각 삼각형, 사각형, …, n각형이라고 해요.

    다각형의 꼭짓점에는 어떤 각이 생길까요?

    안쪽의 각 내각, 바깥쪽의 각 외각

    오각형의 한 꼭짓점을 살펴봐요. 안쪽에도, 변을 늘인 바깥쪽에도 각이 생겨요.

    다각형에서 이웃하는 두 변으로 이루어진 내부의 각을 내각이라고 해요.
    각 꼭짓점에서 한 변과 그 변에 이웃한 변의 연장선으로 이루어진 각을 외각이라고 해요.
    한 내각의 외각은 두 개지만 맞꼭지각이라 크기가 같아서 하나만 생각해요.

    내각과 외각을 나란히 놓고 보면 무엇이 보일까요?

    내각과 외각을 더하면 180°

    한 꼭짓점을 크게 키워 봤어요. 회색 선은 변을 늘인 연장선이에요.

    (내각의 크기) + (외각의 크기) = 180°
    내각과 외각은 한 직선 위에 나란히 붙어 있어서 둘을 합하면 평각, 180° 예요.
    그래서 외각의 크기는 180° 에서 내각의 크기를 빼서 구할 수 있어요.

    이제 삼각형의 세 내각을 한곳에 모아 볼까요?

    삼각형의 세 내각의 크기의 합

    초등학교에서는 삼각형을 잘라 세 각을 한 점에 모았어요. 이번에는 자르지 않고 평행선의 엇각으로 세 각을 점 A 에 모아 볼까요?

    ∠A + ∠B + ∠C = 180°
    l ∥ ‾BC 이니 ∠B, ∠C 는 점 A 에 생긴 엇각과 크기가 같아요. 세 각이 점 A 에 모여 평각을 이루니까 삼각형의 세 내각의 크기의 합은 180° 예요.

    같은 방법으로 외각도 살펴볼까요?

    한 외각은 이웃하지 않는 두 내각의 합

    ‾BC 를 늘여 생긴 ∠C 의 외각 ∠ACD 를 봐요. 이번에는 점 C 를 지나고 ‾BA 에 평행한 반직선 CE 를 그어요.

    ∠ACD = ∠ACE + ∠ECD = ∠A + ∠B
    삼각형의 한 외각의 크기는 그와 이웃하지 않는 두 내각의 크기의 합과 같아요.

    세 내각의 합으로도 설명할 수 있어요. ∠ACD = 180° - ∠C 이고, ∠A + ∠B 도 180° - ∠C 이니까요.

    한눈에 정리해요

    내각 이웃하는 두 변이 만드는 안쪽의 각
    외각 한 변과, 이웃한 변의 연장선이 만드는 각
    두 개 중 하나만 생각해요
    내각 + 외각 한 꼭짓점에서 180°
    삼각형의
    세 내각의 합    		 180°
    평행선의 엇각으로 한 점에 모아요
    삼각형의
    한 외각    		 이웃하지 않는 두 내각의 크기의 합
    삼각형에서만 성립해요 (사각형부터는 아니에요)
    삼각형에서 내각을 구할 때는 180° 에서 빼고, 외각을 구할 때는 이웃하지 않는 두 내각을 더해요.

    대표 예제

    예제 1. 세 내각의 합으로 ∠x 구하기

    삼각형 ABC 에서 ∠x 의 크기를 구해 볼까요?

    ① 무엇을 쓸까
    세 각이 모두 삼각형의 내각이니 세 내각의 크기의 합 180° 를 써요.
    ② 식 세우기
    ∠x + 70° + 45° = 180°
    ③ 계산하기
    ∠x = 180° - 115° = 65°

    70° + 45° = 115° 에서 멈추지 않아요. 115° 는 ∠x 의 외각의 크기예요.

    예제 2. 외각의 크기 구하기

    삼각형 ABC 에서 ∠C 의 외각 ∠x 의 크기를 구해 볼까요?

    ① 이웃하지 않는 두 내각 찾기
    ∠x 는 꼭짓점 C 의 외각이니, C 와 떨어진 ∠A 와 ∠B 를 봐요.
    ② 식 세우기
    ∠x = ∠A + ∠B = 60° + 70°
    ③ 계산하기
    ∠x = 130°

    180° - (60° + 70°) = 50° 는 외각이 아니라 내각 ∠ACB 의 크기예요.

    한 걸음 더

    외각을 잘못 잡는 경우를 살펴보고, 삼각형 두 개가 맞닿은 그림과 x 가 들어간 각에서 크기를 구해 봐요.

    바깥쪽 전체는 외각이 아니에요

    현진이는 "내각과 그 바깥쪽을 합치면 360° 니까 한 내각과 외각의 크기의 합은 360° 예요." 라고 말했어요. 맞을까요?

    외각은 꼭짓점을 빙 둘러싼 바깥쪽 전체가 아니라, 한 변과 이웃한 변의 연장선 사이의 각이에요. 그래서 한 꼭짓점에서 (내각) + (외각) 은 언제나 180° 예요.

    심화 예제 1. 맞닿은 두 삼각형

    두 선분 AE 와 BD 가 점 C 에서 만나요. ∠x 의 크기를 구해 볼까요?

    ① 이어 주는 각 찾기
    두 삼각형은 점 C 에서 맞닿아 있어요. ∠ACB 와 ∠DCE 는 맞꼭지각이라 크기가 같아요.
    ② 오른쪽 삼각형
    ∠DCE = 180° - (50° + 60°) = 70° 이니 ∠ACB = 70°
    ③ 왼쪽 삼각형
    ∠x = 180° - (80° + 70°) = 30°

    70° 를 구하고 멈추지 않아요. 70° 는 ∠x 가 아니라 점 C 의 각이에요.

    심화 예제 2. x 가 들어간 각

    각의 크기가 x 를 써서 적혀 있어요. x 의 값을 구해 볼까요?

    ① 외각의 성질
    80° 는 꼭짓점 C 의 외각이니, 이웃하지 않는 두 내각의 합과 같아요.
    ② 식 세우기
    (x + 20) + (2x - 15) = 80 이므로 3x + 5 = 80
    ③ 방정식 풀기
    3x = 75 이므로 x = 25

    확인 : 두 내각은 45°, 35° 이고 45° + 35° = 80° 예요. 그림에 x° 처럼 적혀 있으면 x 는 각이 아니라 수예요.
