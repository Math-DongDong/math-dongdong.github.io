정수와 유리수의 덧셈과 뺄셈

부호가 붙은 수를 더하고 빼요. 뺄셈도 부호만 정리하면 간단한 식 하나가 돼요. 화면을 아래로 천천히 내리기만 하면 돼요.

다시 볼 문제

한 번에 맞히지 못한 문제예요. 누르면 이 문제들만 골라서 다시 풀 수 있어요. 다시 풀어서 한 번에 맞히면 그때 기록에 쌓여요.

    1

    개념 익히기

    부호 정리 → 수직선 → 덧셈 규칙 → 뺄셈 간단히 쓰기 순서로 만나요

    부호가 두 번 겹치면

    상점과 벌점으로 점수를 주고받아요. 빈칸 두 곳을 먼저 예상해 볼까요?

    상황 식 점수 변화
    상점 8점을 받다 +(+8) +8
    벌점 4점을 받다 +(-4) -4
    벌점 17점을 없애 주다 -(-17) +17
    상점 15점을 빼앗기다 -(+15) -15
    두 부호가 같으면 +  /  두 부호가 다르면 -
    벌점을 없애 주면 점수는 올라가요. 그래서 -(-17)은 +17이에요.

    부호를 정리했으니 이제 이 수들을 더해 볼까요?

    부호는 방향, 수는 칸 수

    주사위 두 개로 말을 옮긴다고 생각해요. 부호는 어느 쪽으로 갈지, 숫자는 몇 칸 갈지를 정해요.

    +는 오른쪽, -는 왼쪽이에요. 0에서 오른쪽으로 2칸, 또 오른쪽으로 3칸 가면 +5에 도착해요.

    방향이 같을 때와 다를 때를 나눠서 볼게요.

    방향이 같으면 계속 나아가요

    왼쪽으로 3칸 가고, 또 왼쪽으로 2칸 가요. 돌아오는 일이 없으니 칸 수가 그대로 쌓여요.

    (부호가 같을 때) 절댓값의 합 + 공통인 부호
    (-3) + (-2) = -(3 + 2) = -5

    방향이 다르면 되돌아와요

    오른쪽으로 3칸 갔다가, 왼쪽으로 4칸 되돌아와요. 간 만큼 되돌아오고 남는 칸이 답이 돼요.

    (부호가 다를 때) 절댓값의 차 + 절댓값이 큰 수의 부호
    (+3) + (-4) = -(4 - 3) = -1

    여기까지가 덧셈이에요. 이제 뺄셈을 볼까요?

    뺄셈도 부호 정리부터

    수학자 파스칼도 5에서 7을 뺄 수 있을까? 하고 오래 고민했어요. 맨 처음에 배운 부호 정리를 그대로 쓰면 괄호와 뺄셈 기호가 사라져요.

    원래 식 두 부호는? 간단한 식
    (+4) - (+7) - 와 + 는 달라요 4 - 7
    (+4) - (-3) - 와 - 는 같아요 4 + 3
    (-3) + (-2) + 와 - 는 달라요 -3 - 2
    두 부호가 같으면 +  /  두 부호가 다르면 -
    부호를 정리하면 4 - 7 처럼 짧은 식 하나만 남아요. 어떤 수에서 0을 빼면 그 수는 그대로예요.

    간단해진 식은 수직선에서 그대로 읽으면 돼요.

    간단해진 식도 수직선 그대로

    4 - 7 은 4에서 출발해 왼쪽으로 7칸 가라는 뜻이에요. 덧셈에서 하던 것과 똑같아요.

    (+4) - (+7) → 4 - 7 → 왼쪽으로 7칸 → -3
    (+4) - (-3) → 4 + 3 → 오른쪽으로 3칸 → +7

    -3 - 2 도 마찬가지예요. 왼쪽으로 3칸, 또 왼쪽으로 2칸 가서 -5가 돼요.

    한눈에 정리해요

    부호 정리 -(-5) = +5, -(+5) = -5
    같으면 +, 다르면 -
    부호가 같은 덧셈 절댓값을 더하고 공통 부호
    (-3)+(-2) = -5
    부호가 다른 덧셈 절댓값의 차, 큰 쪽의 부호
    (+3)+(-4) = -1
    뺄셈 부호를 정리해 간단한 식으로
    (+4)-(+7) = 4 - 7 = -3
    0을 뺄 때 어떤 수에서 0을 빼면 그 수 그대로
    (-6) - 0 = -6
    부호를 먼저 정리하면 덧셈이든 뺄셈이든 수직선 한 가지 방법으로 풀려요.

    대표 예제

    풀이가 ① ② ③ 순서로 하나씩 나타나요

    예제 1. 뺄셈이 섞인 식

    다음 식을 계산해 볼까요?

    (-3) + (-5) - (+7) - (-10)
    ① 조건 확인
    뺄셈이 두 번 들어 있어요. 괄호 앞 기호와 수의 부호를 먼저 정리해요.
    ② 식 세우기
    -3 - 5 - 7 + 10
    ③ 계산하기
    왼쪽으로 3칸, 5칸, 7칸 이어 가면 -15, 다시 오른쪽으로 10칸 가면 -5

    -(-10)을 그대로 -10으로 두면 -25가 나와요. 부호 바꾸기를 꼭 확인해요.

    예제 2. 얼마나 올라왔을까요?

    잠수함이 바다 속 -80 m에 있다가 -30 m까지 올라왔어요. 얼마나 올라왔을까요?

    (-30) - (-80)
    ① 조건 확인
    올라온 높이는 (나중 위치) - (처음 위치)로 구해요.
    ② 식 세우기
    - 와 - 는 같은 부호이므로 -30 + 80
    ③ 계산하기
    왼쪽으로 30칸 갔다가 오른쪽으로 80칸 가면 +50, 즉 50 m 올라왔어요.

    -(-80)을 그대로 -80으로 두면 -110이 나와요. 부호부터 정리해요.

    한 걸음 더

    같은 덧셈을 셈돌로 다시 보고, 분수 계산에 꼭 필요한 통분을 만나요.

    여기도 스크롤만 내리면 그림이 저절로 움직여요.

    셈돌로 다시 보기

    수직선 말고 다른 방법도 있어요. + 셈돌 하나와 - 셈돌 하나는 짝을 지어 함께 사라져요.

    + 셈돌 1개와 - 셈돌 1개 = 0
    짝을 지어 지우고 남은 셈돌이 답이에요. 수직선에서 갔다가 되돌아오는 것과 같은 이야기를 셈돌로 본 거예요.

    부호가 같은 두 수는 짝이 생기지 않아서 셈돌이 그대로 쌓여요.

    분수는 분모부터 같게

    1/3 과 1/6 은 한 칸의 크기가 서로 달라요. 칸의 크기가 다르면 몇 칸인지 셀 수 없어요.

    분모를 같게 맞추는 것 = 통분 (분모의 최소공배수로)
    식 통분 계산
    1/3 + 1/6 2/6 + 1/6 3/6 = 1/2
    1/2 - 3/4 2/4 - 3/4 -1/4
    분모를 같게 맞춘 뒤에는 분자만 더하고 빼요. 분모끼리는 더하지 않아요.

    부호 정리 → 통분 → 계산, 이 순서면 분수도 정수와 똑같아요.

    심화 예제. 분수가 섞인 식

    부호와 분모를 차례로 정리해 볼까요?

    (-2/3) + (+1/2) - (-1/3)
    ① 조건 확인
    부호를 정리하면 -2/3 + 1/2 + 1/3 이에요.
    ② 식 세우기
    분모 3, 2, 3 의 최소공배수는 6이므로 -4/6 + 3/6 + 2/6
    ③ 계산하기
    분자만 계산하면 -4 + 3 + 2 = +1 이므로 +1/6

    통분하지 않고 분모끼리 더하면 전혀 다른 값이 나와요.
