정수와 유리수의 덧셈과 뺄셈

부호가 붙은 수를 더하고 빼요. 뺄셈도 기호와 부호만 정리하면 짧은 식 하나가 돼요. 화면을 아래로 천천히 내리기만 하면 돼요.

다시 볼 문제

한 번에 맞히지 못한 문제예요. 누르면 이 문제들만 골라서 다시 풀 수 있어요. 다시 풀어서 한 번에 맞히면 그때 기록에 쌓여요.

    1

    개념 익히기

    기호와 부호 정리 → 짧게 쓰기 → 수직선 → 덧셈 → 뺄셈 순서로 만나요

    기호와 부호가 만나면

    상점과 벌점으로 점수를 주고받아요. 더하기·빼기 기호 뒤에 부호가 붙은 수가 오면 점수가 어떻게 바뀔까요?

    상황 식 점수 변화
    상점 8점을 받다 +(+8) +8
    벌점 4점을 받다 +(-4) -4
    벌점 17점을 없애 주다 -(-17) +17
    상점 15점을 빼앗기다 -(+15) -15
    기호와 부호가 같으면 +  /  기호와 부호가 다르면 -
    앞의 +, - 는 더하라·빼라는 기호, 뒤의 +, - 는 수에 붙은 부호예요. 벌점을 없애 주면 점수는 올라가니 -(-17)은 +17이에요.

    기호와 부호를 하나로 정리했으니, 이제 괄호를 지우고 짧게 써 볼까요?

    괄호를 지우고 짧게 써요

    기호와 부호를 하나로 정리하면 괄호가 필요 없어요. 맨 앞의 + 도 쓰지 않고 지워요.

    원래 식 짧게 쓴 식
    (+2) + (+3) 2 + 3
    (-3) + (-2) -3 - 2
    (+4) + (-3) 4 - 3
    -3 - 2 의 - 는 빼라는 말이 아니라 -3과 -2, 두 수에 붙은 부호예요.

    짧게 쓴 식을 수직선 위에서 읽어 볼까요?

    부호는 방향, 수는 칸 수

    짧게 쓴 식은 수직선 위에서 그대로 읽어요. 부호는 어느 쪽으로 갈지, 숫자는 몇 칸 갈지를 정해요.

    +는 오른쪽, -는 왼쪽이에요. 2 + 3 은 0에서 오른쪽으로 2칸, 또 오른쪽으로 3칸 가라는 뜻이에요.

    방향이 같을 때와 다를 때를 나눠서 볼게요.

    방향이 같으면 계속 나아가요

    왼쪽으로 3칸 가고, 또 왼쪽으로 2칸 가요. 돌아오는 일이 없으니 칸 수가 그대로 쌓여요.

    (부호가 같을 때) 절댓값의 합 + 공통인 부호
    -3 - 2 = -(3 + 2) = -5

    방향이 다르면 되돌아와요

    오른쪽으로 4칸 갔다가, 왼쪽으로 3칸 되돌아와요. 간 만큼 되돌아오고 남는 칸이 답이 돼요.

    (부호가 다를 때) 절댓값의 차 + 절댓값이 큰 수의 부호
    4 - 3 = +(4 - 3) = +1

    여기까지가 덧셈이에요. 이제 뺄셈을 볼까요?

    뺄셈도 같은 방법으로

    수학자 파스칼도 5에서 7을 뺄 수 있을까? 하고 오래 고민했어요. 뺄셈도 기호와 부호를 정리하면 앞에서 본 것과 똑같은 모양이 돼요.

    원래 식 짧게 쓴 식
    (+4) - (+7) 4 - 7
    (+4) - (-3) 4 + 3
    (-2) - (-9) -2 + 9
    기호와 부호가 같으면 +  /  기호와 부호가 다르면 -
    뺄셈도 짧게 쓰면 덧셈과 똑같은 모양이에요. 어떤 수에서 0을 빼면 그 수는 그대로예요.

    짧아진 식은 수직선에서 그대로 읽으면 돼요.

    짧아진 식도 수직선 그대로

    4 - 7 은 0에서 오른쪽으로 4칸 간 다음, 다시 왼쪽으로 7칸 가라는 뜻이에요. 덧셈에서 하던 것과 똑같아요.

    (+4) - (+7) → 4 - 7 → 오른쪽 4칸, 왼쪽 7칸 → -3
    (+4) - (-3) → 4 + 3 → 오른쪽 4칸, 오른쪽 3칸 → +7

    기호와 부호를 정리해 짧게 쓰고 나면, 읽는 방법은 한 가지뿐이에요.

    한눈에 정리해요

    기호와 부호 -(-5) = +5, -(+5) = -5
    기호와 부호가 같으면 +, 다르면 -
    짧게 쓰기 (+4) + (-3) = 4 - 3
    괄호와 맨 앞의 + 는 지워요
    부호가 같은 덧셈 절댓값을 더하고 공통 부호
    -3 - 2 = -(3 + 2) = -5
    부호가 다른 덧셈 절댓값의 차, 큰 쪽의 부호
    4 - 3 = +(4 - 3) = +1
    뺄셈 기호와 부호를 정리해 짧은 식으로
    (+4)-(+7) = 4 - 7 = -3
    0을 뺄 때 어떤 수에서 0을 빼면 그 수 그대로
    (-6) - 0 = -6
    기호와 부호를 먼저 정리하면 덧셈이든 뺄셈이든 수직선 한 가지 방법으로 풀려요.

    대표 예제

    풀이가 ① ② ③ 순서로 하나씩 나타나요

    예제 1. 짧은 식으로 고치기

    덧셈과 뺄셈이 섞여 있어요. 짧은 식 하나로 고쳐 볼까요?

    (+2) - (+6) + (-4) - (-9)
    ① 조건 확인
    더하기·빼기 기호와 수의 부호를 하나로 정리해요. 같으면 +, 다르면 - 예요.
    ② 식 세우기
    -(+6) → 기호와 부호가 다르니 -6
    +(-4) → 다르니 -4
    -(-9) → 같으니 +9
    → 2 - 6 - 4 + 9
    ③ 계산하기
    오른쪽으로 2칸, 왼쪽으로 6칸과 4칸, 다시 오른쪽으로 9칸 가면 +1

    맨 앞의 (+2)는 앞에 기호가 없으므로 그대로 2로 써요.

    예제 2. 두 정수의 뺄셈

    빼기 기호 뒤에 음수가 오는 뺄셈이에요. 짧게 쓴 뒤 수직선에서 읽어 볼까요?

    (-4) - (-9)
    ① 조건 확인
    빼기 기호와 -9의 부호가 둘 다 - 로 같아요.
    ② 식 세우기
    -4 + 9
    ③ 계산하기
    0에서 왼쪽으로 4칸 갔다가 오른쪽으로 9칸 가면 +5

    -(-9)를 그대로 -9로 두면 -13이 나와요. 기호와 부호부터 정리해요.

    한 걸음 더

    같은 덧셈을 셈돌로 다시 보고, 분수 계산에 꼭 필요한 통분을 만나요.

    여기도 스크롤만 내리면 그림이 저절로 움직여요.

    셈돌로 다시 보기

    수직선 말고 다른 방법도 있어요. 3 - 4 는 + 셈돌 3개와 - 셈돌 4개를 모은 것과 같아요.

    + 셈돌 1개와 - 셈돌 1개 = 0
    + 셈돌 하나와 - 셈돌 하나는 짝을 지어 사라지고, 남은 셈돌이 답이에요. 수직선에서 갔다가 되돌아오는 것과 같은 이야기를 셈돌로 본 거예요.

    부호가 같은 두 수는 짝이 생기지 않아서 셈돌이 그대로 쌓여요.

    분수는 분모부터 같게

    1/3 과 1/6 은 한 칸의 크기가 서로 달라요. 칸의 크기가 다르면 몇 칸인지 셀 수 없어요.

    분모를 같게 맞추는 것 = 통분 (분모의 최소공배수로)
    1/3 → 위아래에 똑같이 2를 곱하면 2/6
    식 통분 계산
    1/3 + 1/6 2/6 + 1/6 3/6 = 1/2
    1/2 - 3/4 2/4 - 3/4 -1/4
    분모를 같게 맞출 때 분자에도 같은 수를 곱해요. 맞춘 뒤에는 분모는 그대로 두고 분자만 더하고 빼요.

    기호와 부호 정리 → 통분 → 계산, 이 순서면 분수도 정수와 똑같아요.

    심화 예제. 분수가 섞인 식

    두 수의 뺄셈이에요. 부호와 분모를 차례로 정리해 볼까요?

    (-2/3) - (-1/2)
    ① 조건 확인
    빼기 기호와 -1/2 의 부호가 둘 다 - 로 같으므로 짧게 쓰면 -2/3 + 1/2 이에요.
    ② 식 세우기
    분모 3과 2의 최소공배수는 6이므로 -4/6 + 3/6
    ③ 계산하기
    분모는 6 그대로 두고 분자만 계산하면 -4 + 3 = -1 이므로 -1/6

    통분할 때 분자에 2와 3을 곱하는 것을 빠뜨리면 전혀 다른 값이 나와요.
