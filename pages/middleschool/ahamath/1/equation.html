등식과 방정식

= 로 이어진 식을 읽고, 식을 참이 되게 하는 값을 찾아요. 저울처럼 양쪽에 똑같이 하면 균형이 그대로라는 것도 알아봐요.

    개념 익히기

    등식 → 방정식과 해 → 항등식 → 등식의 성질 → 저울로 풀기 순서로 만나요

    = 로 이어지면 등식

    등호 = 를 사용하여 나타낸 식을 등식이라고 해요. 등호의 왼쪽을 좌변, 오른쪽을 우변, 둘을 함께 양변이라고 불러요.

    식 등식? 좌변 우변
    2 + x - 7 × = 가 없어요
    5x + 3 = 8 ○ 5x + 3 8
    2 × 8 < 3 × 8 × < 는 등호가 아니에요
    7 + 3 = 73 ○ 7 + 3 73
    7 + 3 = 73 은 틀린 말이지만, = 로 이어져 있으니 등식이에요. 참·거짓과 상관없이 = 가 있으면 등식이에요.

    그러면 문자가 들어 있는 등식은 언제 참이 될까요?

    아하! 를 찾아라

    고대 이집트의 파피루스에는 모르는 수를 '아하'라고 부른 문제가 있어요.

    아하와 아하의 2배의 합에 1을 더하면 4이다.

    아하를 x 라고 하면 x + 2x + 1 = 4 예요. x 에 수를 하나씩 넣어 볼까요?

    x 좌변 x + 2x + 1 우변 참 / 거짓
    -1 -2 4 거짓
    0 1 4 거짓
    1 4 4 참
    2 7 4 거짓
    x 의 값에 따라 참도 되고 거짓도 되는 등식을 방정식, 문자 x 를 미지수라고 해요.
    방정식을 참이 되게 하는 값을 해(또는 근)라 하고, 해를 구하는 것을 방정식을 푼다고 해요. 이 방정식의 해는 x = 1 이에요.

    그런데 어떤 수를 넣어도 언제나 참인 등식도 있어요.

    언제나 참인 등식, 항등식

    x + 2x = 3x 에 수를 넣어 보면 좌변과 우변이 늘 같아요.

    x 좌변 x + 2x 우변 3x
    -1 -3 -3
    0 0 0
    2 6 6
    x 에 어떤 값을 넣어도 항상 참인 등식을 항등식이라고 해요.
    좌변이나 우변을 간단히 정리했을 때 양변이 똑같은 식이 되면 항등식이에요. x + 2x 를 정리하면 3x 이죠.

    이제 방정식의 해를 수를 하나씩 넣지 않고 찾는 방법을 알아볼까요?

    저울처럼, 양쪽에 똑같이

    저울이 균형을 이룬다는 것은 양쪽 무게가 같다는 뜻이에요. 등식도 좌변과 우변이 같아요. x + 2 = 5 를 저울에 올려 볼까요?

    a = b 이면
    양변에 같은 수를 더해도 a + c = b + c
    양변에서 같은 수를 빼도 a - c = b - c
    양변에 같은 수를 곱해도 ac = bc
    양변을 0이 아닌 같은 수로 나누어도 a/c = b/c
    이 네 가지를 등식의 성질이라고 해요. 양변에 똑같이 하면 등식은 계속 참이에요.

    이 성질로 방정식을 풀어 볼까요?

    등식의 성질로 방정식 풀기

    2x + 4 = 10 을 저울에 올렸어요. x 하나만 남을 때까지 양쪽에 똑같이 해요.

    등식의 성질을 써서 x = (수) 꼴을 만들면 그 수가 해예요.
    구한 해를 처음 식에 넣어 확인해요. 2 × 3 + 4 = 10 이니 맞아요.

    정리 카드로 한 번 더 볼까요?

    한눈에 정리해요

    등식 = 를 사용하여 나타낸 식 (거짓이어도 등식)
    좌변 · 우변 · 양변
    방정식 x 의 값에 따라 참·거짓이 달라지는 등식
    x + 2x + 1 = 4
    해 (근) 방정식을 참이 되게 하는 값
    x = 1
    항등식 어떤 값을 넣어도 항상 참인 등식
    x + 2x = 3x
    등식의 성질 양변에 같은 수를 더하고, 빼고, 곱하고, 0이 아닌 수로 나누어도 등식은 그대로
    방정식은 저울이에요. 양쪽에 똑같이 하면서 x 하나만 남겨요.

    대표 예제

    풀이가 ① ② ③ 순서로 하나씩 나타나요

    예제 1. 방정식일까, 항등식일까

    다음 등식은 방정식일까요, 항등식일까요?

    3(x + 1) = 3x + 3
    ① 정리하기
    좌변의 괄호를 풀면 3x + 3
    ② 양변 비교
    좌변 3x + 3, 우변 3x + 3 으로 똑같은 식이에요.
    ③ 결론
    어떤 x 를 넣어도 참이므로 항등식

    정리한 뒤 양변이 다르면 방정식이에요. 예를 들어 3x + 3 = 3x + 1 은 항등식이 아니에요.

    예제 2. 등식의 성질로 풀기

    등식의 성질을 차례로 써서 방정식을 풀어 볼까요?

    -7x - 5 = 9
    ① 양변에 5 를 더해요
    -7x - 5 + 5 = 9 + 5 이므로 -7x = 14
    ② 양변을 -7 로 나눠요
    -7x ÷ (-7) = 14 ÷ (-7) 이므로 x = -2
    ③ 확인하기
    -7 × (-2) - 5 = 14 - 5 = 9 로 우변과 같아요.

    -5 를 없애려면 5 를 더해야 해요. 빼면 -10 이 되어 더 멀어져요.

    한 걸음 더

    등식의 성질을 쓸 때 조심할 점과, 방정식과 항등식을 가르는 기준을 더 깊이 살펴봐요.

    0 으로는 나눌 수 없어요

    한 친구가 이렇게 말했어요. "2x = x 의 양변을 x 로 나누면 2 = 1 이 나와!"

    2x = x 의 해는 x = 0 이에요. 그러니 양변을 x 로 나눈 것은 0 으로 나눈 것과 같아요. 등식의 성질에서 나누는 수는 0 이 아니어야 해요.

    해가 여러 개여도 항등식은 아니에요

    x² - x - 1 = 5 에 x = 3 과 x = -2 를 넣으면 둘 다 참이에요. 그러면 항등식일까요?

    x 좌변 x² - x - 1 우변 참 / 거짓
    3 5 5 참
    -2 5 5 참
    0 -1 5 거짓
    항등식은 모든 값에서 참이어야 해요. 거짓이 되는 값이 하나라도 있으면 방정식이에요.

    심화 예제. 항등식이 되는 조건

    다음 등식이 x 에 대한 항등식이 되도록 a, b 의 값을 정해 볼까요?

    ax + 3 = 2x + b
    ① 조건 확인
    항등식이면 좌변과 우변이 똑같은 식이어야 해요.
    ② 짝 맞추기
    x 의 계수끼리 a = 2, 상수항끼리 3 = b
    ③ 답하기
    a = 2, b = 3

    x 의 계수는 x 의 계수끼리, 상수항은 상수항끼리 짝을 지어요.
